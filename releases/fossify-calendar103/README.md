# カレンダー 月表示・ウィジェット色分け v1.0.3

Fossify Calendar `org.fossify.calendar` 1.12.1 (24) 用。アプリ内の1か月表示で、日曜日の曜日・日付を赤に揃えます。当日の曜日の強調色や週末色の設定にかかわらず、日曜は赤、土曜は青、祝日の日付は赤を使います。祝日と土曜日が重なる日は赤を優先します。

今日の日付の文字は、アプリ内の月表示では白、ホーム画面の1か月ウィジェットでは黒です。アプリ内の今日の丸印は日曜・祝日が赤、土曜が青で、それ以外は元の色を維持します。今日を選択した場合も塗りつぶした丸印を残し、選択状態や操作は変更しません。

- 青 `#2196F3`、赤 `#FF0000`、アプリ内の今日の文字 `#FFFFFF`、ウィジェットの今日の文字 `#000000`。
- ウィジェットの表示は v1.0.2 と同じです。土曜の曜日・日付を青、祝日の日付を赤にする既存処理を維持します。
- 祝日はアプリ管理の祝日、祝日種別のカレンダー、または「祝日」「日本の祝日」等の明示的な祝日カレンダーにある終日イベントから判定します。通常予定の色だけでは判定しません。
- 前後月の日付の薄さ、通常の日付・予定の色、印刷用表示を維持します。
- アプリだけを起動した場合にも祝日情報を読み込みます。描画中にUIスレッドからデータベースを読みません。
- ウィジェット設定画面のプレビューは変更対象外です。

Morphe ManagerでHiro Morphe Patchesを v1.0.325 に更新し、元のカレンダー1.12.1に「月表示とウィジェットの土曜を青・祝日を赤」を適用してください。単独版と統合版のどちらか一方を使います。インストール後、アプリを開き直すと再描画されます。

添付された実APKへの適用・再構築、色分け・祝日・今日・印刷表示のホストテスト、既存統合パッチの保持を検証しています。Android実機での表示は未確認です。APK本体、予定データ、アカウント情報は配布物に含みません。

`src/build.py --base baseline324.mpp --tools tools --work work --dist dist --apk original-base.apk` でローカル検証付きビルド。CIでは実APKを再配布せず、同一ソースからの再ビルドとホストテスト、公開前に検証済みMPPとのバイト一致を確認します。
