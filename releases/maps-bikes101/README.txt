microG Maps 地図上の自転車マークを非表示 v1.0.1
Hiro Morphe Patches v1.0.370

変更内容
前版v1.0.0を適用しても灰色の自転車マークが残るという報告への修正版です。
画像URLだけでなく、Maps内部で使う画像名そのものも判定します。
従来のポイント描画と、ネイティブ描画用の地図スタイルを読み込む経路を追加し、
自転車の絵柄を含むマーク全体を非表示にします。
共通の丸背景だけを一括削除する処理ではなく、自転車を参照する表示だけが対象です。
店名検索・検索ピン、起動時現在地、カテゴリ行非表示、戻る終了の実装を保持します。
地図全体の描画方式は強制変更しません。
修正前の表示設定を再利用しないよう、オンライン地図のキャッシュを分離します。
初回はオンライン地図を再取得します。旧キャッシュとオフライン地図は消去しません。

使い方
1. Morphe ManagerでHiro Morphe Patchesをv1.0.370へ更新します。
   単独版 Maps_Hide_Bicycle_Marks_v1.0.1.mppも使用できます。
2. 対応するmicroG Maps 26.36.04.973607363（1068763346）のAPKを選びます。
3. 「地図上の自転車マークを非表示」を選び、パッチを適用します。
4. 生成したAPKをインストールします。

前版v1.0.0が入った確認済みAPKから、そのまま修正版へ更新できます。
既存改造済みAPKでは今回の項目だけを選んでください。
元APKから作る場合は、必要な既存4項目も一緒に選択できます。
統合版と単独版を重ねて選ばず、どちらか一方を使用してください。
Managerのソース更新だけでは、インストール済みアプリには反映されません。
旧版の処理に未知の変更があるAPKと、修正版適用済みAPKへの再適用は拒否します。

検証の範囲
実際のAPK2種を使った適用・再構築、旧版からの更新、5項目の同時適用、
別アプリを含む既存パッチの保持、元のコードと全リソースの保持を検証します。
地図スタイルの検証では、自転車を参照する表示だけの変更とその他のデータ保持を確認します。
保存済み地図データをネイティブ描画へ返す確認済みの経路にも対応します。
未知のデータ形式は変更せず、元の処理へ渡します。
Android実機・エミュレーター上で、今回のスクリーンショットのアイコンが消えることと、
描画速度・安定性は未確認です。コード検証の成功と画面確認は区別しています。
具体的な対象処理、入力ハッシュ、試験結果は同梱QAとソース内の検証記録を参照してください。
