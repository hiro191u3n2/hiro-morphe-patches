# ULike v1.9.89 — Finish検証の無駄とメモリ不足時の処理を修正

公開済みULike v1.9.88／Hiro Morphe Patches v1.0.221を固定基準に、単体v1.9.89／総合版v1.0.222を公開します。

## 修正範囲

- Finishの旧GPU・新32／64／128行の全候補が終了した場合、次のCPU基準画像作成とdigestを省きます。候補が一つでも残る場合は独立した2回の全出力一致と2回の実出力速度計測を維持します。取消確認、失敗分類、不一致記録、後処理は継続します。
- 保存後のFinishで追加作業メモリを拒否された場合だけ、回収可能な未使用native scratchを安全に解放し、同じ予算上限で一度再確認します。使用中のGPUセッション、画像、CPU作業領域の所有権を維持します。要求量、ヒープ、各native所有量、予約、回収前後を有限スカラーとして記録し、背景検証に撮影ID・世代と画像寸法を付けます。
- 前段と補正のCPU選択理由を、実際の分岐から渡します。前段のGPU候補切替理由を最終採用とは分け、モデル検証コピーの予約要求量・取得済み画素量と実際の予約判断を記録します。診断のために認定やキュー判断を再実行しません。

## 保持と検証

画素計算、強度、肌・輪郭・暗部の保護、解像度、HEIF、全12 native、認定キーと不一致記録、転送込み5%速度条件を維持します。512MiBのGPU作業上限、64MiBの余裕、96MiBの検証保持上限、取消と再試行上限は引き上げません。

公開.88の全2234ソースをtests1989/source-scope88.jsonで固定します。凍結した履歴試験には、明示した新しい診断APIと変更対象に限る互換処理を使用し、現行コードを実行します。source逆適用は保存確認専用です。新しい回帰検証は全候補終了、残存候補の認定、取消・所有権、メモリ予算と回収、実CPU理由、撮影ごとの分離と診断故障を実行します。

JDK21.0.8+9、Morphe1.16.0、Android/D8、NDKr27cを固定します。declare1989.py → build1989.py → validate1989.py → finalize1989.py → publication/publish1989.pyで再構築・公開します。ULike5.6.2(740)の原本APKSへの実適用と完成APKの静的検査を行い、その検証済みMPPとCIのMPPを完全一致させます。Android実機の撮影・画質・処理時間は未測定です。
