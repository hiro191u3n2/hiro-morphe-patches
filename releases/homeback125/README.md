# X の戻る終了と次回ホーム起動の再修正 v1.1.15

総合版は Hiro Morphe Patches v1.0.259、基準は公開済み v1.0.258 です。対象は提供された X 12.19.1-release.0（com.twitter.android）です。

## 原因と修正

v1.1.14 で追加した X 本来の `l1.goBack()` の判定まで届かない Android の戻る経路がありました。対象 MainActivity でシステム戻る処理の登録を抑止する条件が残り、Android 13 以降の標準終了へ進むと、タスク削除とホーム復帰情報の保存が行われませんでした。

- 対象の従来 MainActivity で、アプリ自身のコールバックがない場合に補助のシステム戻る処理を登録します。既存のコールバックがある間はそれを優先し、子画面・入力・予測型ジェスチャーの開始・進捗・取消を保持します。未処理の標準フォールバックだけを X 本来の戻る処理へ渡します。
- 専用の再入防止マーカーにより、フォールバックから戻る処理を重ねて呼ぶことを防ぎます。
- 同期的な戻るキー配送の途中で呼ばれる `onUserInteraction()` が同じ操作の判定を取り消さないようにします。後の別操作や画面遷移の無効化は維持します。
- X が明示的に終了を選んだ場合は、事前の入力欄判定を理由にタスク削除を取り消さないようにします。対象画面・タスク・操作の一致確認は維持します。

ホーム・検索・通知・チャットのトップ画面での戻る終了ではタスクを削除し、ホーム復帰情報を保存します。次回の通常起動は前回タブを復元する前にホームを指定します。通知やリンクの明示的な移動先は保持します。

別実装の `com.x.android.main.MainActivity` と従来の4タブの関係は `evidence/` に別途記録します。端末上での実際の Activity とサーバー設定は未確認です。

## 検証と公開

旧版のキー配送・システム戻るの失敗再現に加え、新規のキー・システム・明示終了の回帰試験を行います。既存のホスト試験、本番 Android SDK コンパイル、DEX 構造と他パッチ保持、合成 APK の全パッチ工程も確認します。実際の X APK に対する単体／総合 MPP の適用、指定箇所以外のコード・資源の保持、既知の v1.1.13／v1.1.14 からの更新を `publication/local-apk-validation.json` と `evidence/` に記録します。2回の CI ビルドとローカルで固定した MPP／QA が一致した場合だけ公開します。

Instagram のリール終了修正、ULike v1.9.108、他アプリのパッチと資源を保持します。ユーザーの APK と検証用 APK 本体は公開ソースや CI に含めません。Android 実機での画面操作・終了後のタスクカード・次回起動は未確認です。

## 適用

単体は `OneBack_Exit_NoRecents_v1.1.15.mpp`、総合版は `Hiro_Morphe_Patches_v1.0.259.mpp` です。Morphe Manager のソース更新後、X の「戻る1回で終了・履歴削除」を再適用して、同じ署名キーで更新インストールしてください。ソース更新だけではアプリ本体の処理は変わりません。

OneBack 未適用の対応 APK と、コードが完全一致する v1.1.13／v1.1.14 から更新できます。未知の旧版や変更済みコードへの上書きは中止します。
