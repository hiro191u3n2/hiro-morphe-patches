# OneBack v1.1.23 — Instagramの外部プロフィールリンク

Instagram 452.1.0.53.64で、ブラウザのリンクから開いた別アカウントの最初のプロフィール画面を、戻る操作の終了地点として扱います。今回の対象例は`https://www.instagram.com/yoasobi_staff_/`です。総合パッチはv1.0.309、基準は公開済みv1.0.308です。

## 動作

- ブラウザのプロフィールURLから開いたプロフィールで戻ると、Instagramを終了してInstagramの履歴を削除します。
- そのプロフィールから開いた投稿・リールは、先にプロフィールへ戻ります。戻った同じ操作で終了せず、次の戻る操作を受けます。
- コメント欄、キーボード、ダイアログなどは、Instagram本来の戻る処理が先に扱います。
- 呼び出し元ブラウザのタスクを削除しません。Instagram内で通常開いたプロフィールを一律に終了対象にはしません。

認識には、外部プロフィールURLを解決するネイティブ経路で作られたプロフィールの識別情報を使用します。プロフィール画面であることだけ、画面の文字、時間経過だけを根拠に終了させません。ネイティブ処理が戻る操作を処理した場合は、その結果を優先します。

自分自身のプロフィールへ進む別の生成経路は、今回の対象に含めません。プロセスや画面の再生成後など、リンクから作られた画面の識別情報を確認できない場合は、Instagram本来の戻る処理に委ねます。

Instagramが起動中で、MainActivityの既存モーダル内へ外部リンクのプロフィールが開かれる経路も対象です。現在のモーダルと登録されたプロフィールの関係を確認した場合に限ります。二画面表示、別のFragmentManagerへ経路を切り替える設定、確認できない階層などは、本来の戻る処理に委ねます。

## 適用

Morphe Managerの既存ソースを更新して、**パッチ適用前のInstagram 452.1.0.53.64**に「戻る1回で終了・履歴削除」を適用します。ソースの更新だけでは、インストール済みアプリ内のパッチは更新されません。このInstagram452用修正は、OneBack適用済みAPKへの上書きには対応しません。古いOneBackのバージョンにかかわらず、OneBackを適用していない原本から作り直してください。別のパッチソースを同時選択する通常の手順は変わりません。

Pikoなどの別パッチは変更していません。総合v1.0.308の非対象ローダー、拡張、リソース、通知文と既存のアップグレード参照を保持します。

## 検証

`src/build.py`は実Android SDKでコンパイルし、既存のInstagram/X/TikTok/Trip.com回帰、新しい外部プロフィール回帰、ネイティブBackラッパー、DEX/リソース保存と実Morpheローダーのメタデータを検査します。外部プロフィールのために変更するランタイム以外は、命令・例外処理・注釈・フィールド等を照合し、一致するクラスの元の定義を保持します。

公開処理は、最終の単体・総合MPPの両方を原本Instagram APKへ適用した記録と、その生成APKのネイティブ処理保存・外部プロフィールフック監査を要求します。2回のローカルビルドと2回のCIビルドは同じMPP/QAのバイトである必要があります。

生成APKでは、変更対象外のZIPリソースとネイティブライブラリをバイト単位で照合します。`resources.arsc`はMorpheが再構成するため、原本のリソースID・型・設定・値と文字列/スタイル情報を検査し、同じSDKで基準v1.0.308を適用した出力とも意味上の一致を要求します。文字列・drawableの一部の名前正規化は既存SDKの処理であり、今回の修正で新しく加えた変更ではありません。

通常の投稿グリッドは、プロフィール直下のViewPagerで選択された子Fragmentとして識別します。ネイティブの選択位置、キャッシュ、主Fragment、親子関係が一致し、タブ移動や未処理の画面遷移がないことを確認します。原本で確認した通常グリッドと起動中のモーダル経路の構造・検査範囲は`PROFILE_TAB_CONTRACT.md`に記載しています。

これはホスト回帰と生成APKの検査です。Android 17 / Samsung SM-S948Qでの画面操作・実機確認は行っていません。原本APK、生成APK、Instagramのネイティブメソッド全文は公開資産に含めません。

ビルドと公開の手順は`publication/BUILD_LOCAL.md`にあります。
