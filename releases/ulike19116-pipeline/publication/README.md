# ULike v1.9.116 / Hiro Morphe Patches v1.0.283

公開済み単体v1.9.114と統合版v1.0.282を固定ハッシュで取得する。統合版のULike関連27エントリが単体v1.9.114と一致することを確認し、他アプリの更新をバイト単位で保持する。公開直前に配布先の現行版が進んでいれば新しい基準から統合版を再構築する。

## 変更範囲

前段native1955では判定で使用されないlag計算のみを除去し、必要な相関評価と演算順序を保持する。Strong CPU native1958では既存NEONのキャッシュ内4画素読取りをまとめ、画像端・透過・非キャッシュ経路を維持する。これらのv1.9.115変更を継承し、host/arm64のraw bits、JNI、別基準と否定対照で再検証する。

今回追加するのは、強ノイズ→補正GPU連結の保存後速度比較におけるStrong実行計画の照合である。ワーカー数・区間行数・GPU/CPU実採用区間数が揃わない場合は既存の非速度不安定経路へ送る。全画素一致条件、候補最遅対既存最速の5%短縮条件、再試行の上限を維持する。これにより比較不能な試行を恒久的な速度未達と誤認しない。対象端末での高速化は未確認。

標準Strong GPUと既存profile6/7の選択・準備・認定経路を維持する。新regional GPU候補はsoftware GLESの全Stage比較で安定した短縮を確認できなかったため、`GpuRegionalDefault19115`とnested classを配布MPPのDEXへ収載しない。既存のoptional reflectionは欠落時にfalse/no-opを返し、新候補の自動準備・追加検証・採用を行わない。

研究用ソース、厳密除算、専用補間パス、実JNI/GLESによる強制実行の品質・メモリ試験は検証資料として残す。これらの正の結果は配布版の自動採用を証明しない。必須release gateは、実配布DEXと適用後APKからhelper本体・全nested class・直接参照が除外されていること、承認した5箇所だけのoptional reflection、実missing-helper状態の既存経路維持と追加処理0を別に要求する。将来の採用には並列Strong全体を含む有効な速度条件が必要であり、今回の256行単位の判定を全Stageや保存全体の短縮へ読み替えない。

v1.9.115で追加した保存後CPU基準2回のStrong準備・区間処理とnative/Java実結果の診断を継承する。署名計算をStrong処理時間へ含めず、画像処理・画像コピー・試行を追加しない。診断値はGPU連結のStrong計画照合に使うが、時間そのものを速度認定へ足さない。

画質設定、解像度、保存形式、総保存時間の計測範囲を維持する。v1.9.114の既存restrict指定と補正マスク最適化は継承し、今回の新機能とは扱わない。

## 再構築と検証

Temurin21.0.8+9、Android NDK r27c、固定ハッシュのMorphe Desktop1.16.0・Android35・D8、NumPy2.3.5を使用する。

1. `src/declare19101.py`で全ソース・本番ヘルパー・公開スクリプトを固定する。
2. `src/build19101.py`でGPU1960・NR1955・Strong CPU1958を再構築し、旧公開ELFの同一NDK再構築、変更範囲、JNI ABI、完全DEX、他アプリ保持、ヘルパー参照を確認する。3ライブラリとも公開v1.9.114のソースからの完全ELF再構築一致と、レビュー済み限定差分を含む現行ソースからの独立した完全ELF再構築一致を要求する。
3. `src/host_audit19101.py`で新旧の出力、実JNI/GLES、arm64エミュレーション、認定条件、取消、メモリ・所有権の回帰試験を実行する。厳密な旧版復元の検査と現在の実ソースを使う出力比較を区別する。
4. `src/apply_original19101.py`で未改造ULike5.6.2(740)APKSへ単体版・統合版をそれぞれ独立に適用し、FULL DEX、リソース再構築、arm64、元native保持、適用後メソッドを確認する。`src/combine_application19115.py`で両適用証拠を完成物のハッシュへ結び付ける。
5. `src/finalize19101.py`と`src/validate19101.py`で実行証拠を配布MPPのSHA-256へ結び付ける。旧版や失われた作業物の適用証拠は流用しない。
6. `publication/publish19101.py --local-only`、`--preflight-only`で完成物を確認する。19101のスクリプト名と既存schemaは互換のため保持するが、版値は1.9.116/1.0.283で確認する。

Galaxy実機での保存時間・画質は未計測。保存公開まで2,000ms以下という目標の達成は未確認であり、ホストやエミュレーションの速度から実機の速度短縮を主張しない。

## 公開

ローカル検証の完了と外部公開の完了を区別する。公開可否が確認できない状態では、公開済みを示すreceiptを作成しない。

2026-10-24に完成済みのULike v1.9.116／統合版v1.0.283について、ユーザーから明示的な公開承認を受けた。以前の自動承認レビューによるブロックは履歴として保持し、manifestのユーザー承認と確認不要の状態を公開直前に検査する。この記録だけでは公開済みを意味しない。

公開時は既存タグや配布branchを上書きしない。公開直前のmain/dev、元MPP、ULike_ACTIVEを照合し、競合時は新しい統合版へ再構築する。固定commitの資産を再取得して照合し、main/devへの更新は直接子commitとatomic leaseで行う。

原本APKS・生成APK・個人写真・診断ログ・ツールチェーンは公開せず、ソース・試験・匿名化した構造証拠だけを公開する。
