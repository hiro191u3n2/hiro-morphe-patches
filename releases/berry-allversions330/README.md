# Berry Browser 全バージョン表示

Hiro Morphe Patches v1.0.330／Berry BFCache復帰補正 v1.0.4。

Morphe Managerに表示されるBerry Browserの5パッチを「全バージョン」表示へ統一します。従来の4パッチは既に全バージョン表示で、新たに加えたBFCache復帰補正の対応バージョン情報だけを変更します。変更対象はパッチプロバイダーの互換性メタデータと配布バージョンです。既存機能、BFCache補正、対象コードの検査、拡張機能ファイルは維持します。将来の全バージョンへの適用成功を保証する変更ではありません。

公開済み統合版v1.0.329と単独版v1.0.3をSHA-256で固定し、表示用のバージョンリストのみ変更します。JVMクラスとAndroid DEXの両方を更新し、DEXにのみ含まれる既存プロバイダーも維持します。

`build/` に再現可能な変更プログラム、`publication/` に検証と公開手順、`payload/` にレビュー済み検証結果と説明を収録します。公開ワークフローは2回ビルドして一致を確認し、凍結済みSHA-256との一致を確認した後でリリースとManagerのmain/dev更新情報を更新します。

実機でのManager画面操作は未確認です。
