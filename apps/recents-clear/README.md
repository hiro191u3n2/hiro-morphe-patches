# 履歴クリア v1.6.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.6.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版には同じ署名で上書き更新できます。

## 履歴を開いてから削除操作までの待ち時間を短縮

- 履歴を開く要求が戻った直後に、新しい画面をすぐ確認します。
- 通知が届かない場合の確認間隔を、履歴表示要求から最初の300msは8ms、1000msまでは16msに短縮しました。通知が届けば即時に再確認します。
- ウィンドウ変更通知を受け取る設定を実行中だけ有効にし、終了時に元へ戻します。
- ボタンIDが親、文字が子に分かれた構造も、次回からボタンIDで直接検索できます。所属・表示・有効状態・文字・近いクリック先を毎回確認します。
- 明示的に操作が拒否された時だけ、16ms後、さらに32ms後、さらに128ms後に再確認します（最大4回）。成功後は繰り返しません。

v1.5.0の起動時の固定待ち撤廃も維持しています。アイコン長押しの「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。「診断」で直近の結果を確認できます。

常駐・保護アプリへの追加終了処理、クイック設定タイル、黒い覆い、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。

ビルド・署名・マニフェストと実際のサービスコードを動かすホストテスト91項目で検証しています。実機での削除・速度は未検証です。8msは確認間隔の設定値であり、削除完了時間ではありません。端末側の描画・アニメーションによる待ち時間は残ります。
