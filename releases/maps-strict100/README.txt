microG Maps 店名検索の絞り込み v1.0.0
Hiro Morphe Patches v1.0.367

機能
Morphe Managerに「店名検索を厳密にする」を追加します。
「ランダ」で検索した場合、ランダ／RANDAの店舗を残し、店名の合わない
ダイアナ、銀座ワシントンなどの検索結果をピン・一覧から絞り込みます。
全角・半角、英字の大小、ひらがな・カタカナ、支店名を考慮します。
「銀座 ランダ」「ランダ 銀座」のような地域語付き検索にも対応します。
靴屋・喫煙所・カフェなどの既知カテゴリ語、住所、経路、座標は通常検索を使います。
検索語とその応答を一緒に扱い、別の検索の条件が混ざらない構成です。

対象
microG Maps 26.36.04.973607363 / versionCode 1068763346
パッケージ: org.ungoogled.android.apps.maps.microg
以前提供されたグーグルマップ v2.8.5 / v2.8.7の対象コードを確認しています。
Google Mapsのパッチ画面にも表示しますが、版番号だけでは互換と判断せず、
検索処理・応答モデル・protobuf処理が一致するAPKだけを受け付けます。

使い方
1. Morphe ManagerでHiro Morphe Patchesをv1.0.367へ更新します。
   単独版 Maps_Strict_Search_v1.0.0.mppを読み込む方法もあります。
2. 対応するmicroG MapsのAPKを選びます。
3. 新項目「店名検索を厳密にする」を選択し、パッチを適用します。
4. 作成したAPKをインストールします。
ソースの更新だけでは、インストール済みアプリには反映されません。

既存の改造と併用
現在地表示・カテゴリ行非表示・戻る終了を適用したAPKへ追加する場合は、
今回の「店名検索を厳密にする」だけを新しく選んでください。
元のAPKから作る場合は、必要な既存3項目も一緒に選択できます。
統合版には起動時現在地v1.0.4、カテゴリ行非表示、戻る終了を保持しています。
同じ検索絞り込みパッチの重ね掛けは受け付けません。
統合版と単独版は、どちらか一方を使ってください。

判定の範囲
日本語と英語の別名は登録した組み合わせが対象です。すべてのブランドを
自動翻訳・自動推測するものではありません。未登録の店名は正規化した文字列で判定します。
カテゴリ語や地域語は語彙と文の形で判定するため、未登録の種類・特殊な地域名・
珍しい支店表記では意図どおりに絞れない場合があります。
名称を取得できない結果や、未対応の補助表示は誤って消さないため保持します。
名前が判定できる結果がすべて不一致なら、空の結果を返します。
Googleから取得できなかった店舗を追加して探す機能ではありません。
対象は検索結果のピン・店舗一覧です。ベース地図の地名・駅名・通常の施設表記は対象外です。

実装と検証
入力検索語を画面から拾わず、その検索リクエストの応答処理へ組み込みます。
従来形式・新形式・関連する補助店舗を同じ条件で絞ります。
店名を絞った検索では、無関係なピンが混ざりうる地図専用レイヤーを外し、
Maps自身の絞り込み済み店舗一覧から描画する経路を利用します。
元の応答・子データ・リストは書き換えず、必要な部分をコピーします。
別の検索や通常のカテゴリ検索のデータはそのまま使います。
対象外スキーマでは元の応答へ戻し、検索語・位置情報を含まない警告だけを1回出します。

検証結果の詳細はQA_Maps_Strict_Search_v1.0.0.jsonを参照してください。
店名判定・応答処理のホスト試験、実APKへの適用、既存3項目との併用、
変更範囲・元のコードとリソース保持、Managerでの選択項目を確認しています。
Android実機・エミュレーター上の地図表示は未確認です。
ホスト試験やAPK構造検証を、端末画面での成功と同一視していません。
