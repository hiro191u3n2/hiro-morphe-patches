# ULike v1.9.40 / 総合 v1.0.173

ULike v1.9.39を基準に、黒い部分のダブルタップ、撮影表示、連続した手動撮影の受付を修正します。

黒い部分をダブルタップしてもカメラを切り替えません。通常のカメラ切替ボタンは従来どおりです。撮影開始時の白い点滅を、白枠と濃い縁、薄い暗転を約240ms表示する処理に置き換えます。描画オーバーレイは操作を遮らず、保存写真には入りません。表示条件を満たさない場合は元の撮影表示を使います。

前版では、Androidの画像バッファをJavaヒープの残量だけで判定するため、フル解像度の写真を独立して保持できても撮影受付が閉じたままになる条件がありました。JavaのYUV作業領域とネイティブ画像・システムメモリの予算を分け、実際の残量と圧力を確認します。写真の保持上限は4枚です。画像のコピーは元の構成・色空間・寸法・密度・アルファ・乗算状態を確認し、美顔処理済み画像と撮影ごとの補正設定・メタデータを保持してから次の撮影を許可します。

画像処理と保存は一列に実行し、解像度、合成枚数、美顔、色処理、ノイズ低減、シャープ処理、保存の圧縮品質と画素計算を変更しません。カメラの準備判定は維持します。メモリ不足や安全なコピーができない画像形式では保存を待ちます。押していない写真を自動撮影したり、撮影要求を後から再生したりしません。

インカメラ起動復旧、倍率表示、撮影領域、ネイティブ高速化処理、他アプリのパッチはv1.9.39／総合v1.0.172から保持します。

`src/build1940.py`は固定したMPP・ツールチェーンでビルドし、未変更のコードと新しいフックの差分を検証します。`src/validate1940.py`は未改造ULike 5.6.2（740）APKSへ単体・総合版を適用し、再構築・型解析・実APKのABIを検査します。`src/finalize1940.py`は検証したMPPと配布するMPPのハッシュを一致させます。

Galaxy実機での撮影間隔・連続撮影・表示と画質は未測定です。元APKS、再構築APK、写真、署名鍵は公開物に含めません。
