SwiftKey Beta v1.8.7 / Hiro Morphe Patches v1.0.290

追加内容
SwiftKey の「レイアウトとキー」に「上フリックで長押し文字を入力」を追加しました。
初期設定はオフです。オンにすると、日本語 QWERTY の対応するキーを短く上方向へフリックして、指を離したときに長押し用の数字・記号を入力できます。
画像の日本語 QWERTY 配列では、たとえば q の上フリックで 1、a の上フリックで @ を入力します。
文字は固定の対応表ではなく、実際のキーに設定された長押し入力から取得します。長押しで複数候補を開くだけのキー、機能キー、パスワード欄は対象外です。
途中で横へなぞった場合はグライドへ渡します。既に開いた長押しメニューを上フリックに置き換えません。

保持した内容
通常のタップ、従来の長押し、日本語 QWERTY グライド入力との競合を検査します。
日本語辞書、使用頻度による候補の並べ替え、Samsung 絵文字、キー入替、改行、貼り付け・削除保護、絵文字検索欄と「AI の作成」を個別に非表示にする設定を保持しています。
SwiftKey の JVM 実行用パッチコードと Android 向けパッチコードも保持します。ほかのアプリのパッチは変更していません。

検証範囲
設定とジェスチャーのホスト試験、既存コード・辞書の比較、単体版と総合版の SwiftKey 内容の一致、旧・現行 Morphe の実際の読み込み処理によるパッチ選択と依存関係を検査します。
公開前に独立した2回のビルドと公開ファイルのハッシュを照合します。
実機での画面表示・入力動作、および未改造 APK への全工程の適用は未確認です。ホスト試験は端末での操作感を確認したものではありません。

適用方法
1. Morphe Manager の Hiro Morphe Patches を 1.0.290 に更新します。
2. 未改造の Microsoft SwiftKey Beta 9.13.16.4 (1236271168) に SwiftKey のパッチを適用します。
3. 以前と同じ署名で上書きインストールし、SwiftKey の「レイアウトとキー」から「上フリックで長押し文字を入力」をオンにします。
改造済み APK を入力として再パッチしないでください。Morphe のソース更新だけでは、インストール済みの SwiftKey は変更されません。
アンインストールやアプリデータの削除は不要です。
