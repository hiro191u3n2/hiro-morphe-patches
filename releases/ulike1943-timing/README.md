# ULike 1.9.43 / Hiro Morphe Patches 1.0.176

シャッター後の追加撮影によって、保存する写真の構図と撮影時刻が後の画像へ置き換わる経路を修正します。

- 最初の撮影画像を構図・時刻・撮影情報の基準として保持します。
- 露光条件の再計画による最初の画像の破棄と撮り直しを止めます。
- 大きな動きや不確かな動きを検出した場合は、追加撮影を終了して最初の画像を使用します。
- 静止時の最大４枚のノイズ低減、1.9.42の画質処理、保存解像度・形式、1.9.41の撮影受付表示を保持します。

変更する実行ヘルパーは `BurstCapture1933` と `FusionPixels1933` のみです。ネイティブ撮影メソッド、カメラ起動・レンズ・プレビュー、保存エンコーダー、他アプリのパッチは前版を保持します。

検証は実際のヘルパーを使ったホスト回帰、再現可能なDEX生成、元のULike5.6.2（740）APKSへの単体・総合パッチ適用とAPK再構築、型・参照・ABI検査を実行します。実行結果は配布QAとソース内の証跡に記録します。

Galaxy実機での動作、シャッター押下から最初の露光までの時間、写真の見た目は未測定です。この修正は最初の撮影後に基準画像が後の時刻へ移る問題を扱います。

Morphe Managerでパッチソースを更新後、未改造ULike5.6.2（740）へ「高画質撮影・質感美肌・素材通信を復旧」を再適用し、作成されたアプリを更新インストールしてください。ソース更新だけではインストール済みULikeは変わりません。単体・総合のどちらか一方を使用します。

元APKS、再構築APK、写真、署名鍵は配布しません。
