# Amazon 商品検索の評価件数順 v1.0.2

対象は添付された Amazon ショッピング 32.19.0.100（versionCode 1243250306、Amazon v1.23.1 適用済み）です。
単独版は `Amazon_Review_Count_v1.0.2.mpp`、統合版は `Hiro_Morphe_Patches_v1.0.350.mpp` です。

v1.0.1 で検索結果の表示が乱れ、スクロール後に並び順が維持されないという報告に対応します。提供された約19秒の録画では、終盤の16〜19秒付近で、それぞれ件数順になっている2つの商品列の表示が切り替わり、フィルターバーが点滅する様子を確認しました。端末上の直接の原因を確定したものではなく、v1.0.2 の実機上での改善確認は未実施です。

v1.0.1 のコードには、最大の単一商品グループだけを対象にすること、操作・スクロール中の移動抑制と表示位置の保持がないこと、状態表示の属性を毎回書き込むこと、評価件数が一時的に消えると直前の値を失うことを確認しました。今回の変更とホストテストは、これらの経路を対象にしています。

指で操作している間やスクロールが続いている間は商品移動を延期し、動きが落ち着いてから並べ替えます。同じ表示形式でまとめられる通常検索商品は、追加読み込みの区切りをまたいで評価件数順に整理します。見ていた商品の位置補正、装飾だけの更新で繰り返し並べ直さない処理、同じ商品で評価件数が一時的に消えた場合の保持を追加します。

v1.0.1 と同じ6箇所のネイティブフックを保持します。読み込み・ページ完了に加え、`MShopWebViewClient.doUpdateVisitedHistory` と `InteractionWebFragment.onFragmentPostShown` を検証付きでフックします。元の広告非表示や価格履歴を含む既存処理を保持し、6メソッドへ合計8命令を追加します。

検索画面では v1.0.2 の状態表示を出し、商品待機中、件数を判定できない場合、並べ替えできた場合を区別します。読み込まれた通常の商品を表示上の評価件数で並べ替えます。評価件数には星だけの評価が含まれ、文章付きレビューの件数とは一致しません。Amazon 側へ件数順も指定しますが、全検索結果を取得した厳密な順位は保証しません。実機での表示・操作は未確認です。

## 適用

元の添付 APK を選び、「商品検索を評価件数の多い順に表示」だけを適用してください。v1.0.0／v1.0.1 を適用した APK への重ね掛けは受け付けません。単独版と統合版のどちらか一方を使用し、以前と同じ署名で作成したアプリを上書きインストールします。ソース更新だけではインストール済みアプリは変わりません。

## 再現ビルド

JDK 21.0.13、`publication/baseline.json` の固定された統合349、`src/build.py` の SHA-256 と一致する4ツールを使用します。`morphe.jar` は旧 Java パッチ API のコンパイル専用で、適用・検証には公式 Patcher 2.2.0 を含む `morphe-2.2.jar` を使います。

```sh
npm ci --ignore-scripts --no-audit --no-fund --prefix src/runtime-tests
python3 src/build.py --base baseline349.mpp --tools tools --work build-a --dist dist-a --apk supplied.apk
python3 src/build.py --base baseline349.mpp --tools tools --work build-b --dist dist-b
```

各ビルドは新しい作業ディレクトリと空の出力先を指定します。JDK を別途指定する場合は `--java-home /path/to/jdk-21.0.13` を追加します。配布 MPP の全バイトが2回のビルドで一致することを確認します。

`--apk` を指定したビルドは、単独版と統合版を Patcher 2.2.0 の `STRIP_FAST` で実際に適用します。生成した DEX のクラス一覧と変更箇所、既存メソッド、ランタイム、APK の全非DEX資源を照合します。Java の起動条件、URL、ガード、二重適用拒否と、DOM の旧版失敗再現・並べ替え・状態表示をホストテストで確認します。

レイアウト位置の補正は、テスト用の矩形・スクロール値を使った合成ジオメトリで検証します。DOM の試験はホスト上で実行し、実ブラウザでの描画試験や Android 実機での操作試験を行ったものではありません。

統合349から置換するのは `app/hiro/amazonreviews/patches/` と `extensions/amazon_review_sort.mpe` だけです。他パッチのクラスと資源は保持します。APK 適用結果は `QA_Amazon_Review_Count_v1.0.2.json` に記録します。元 APK、実機の検索内容、アカウント情報を公開物に含めません。
