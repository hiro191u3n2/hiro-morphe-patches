# ULike v1.9.36 / 総合 v1.0.169

ULike v1.9.35 を基準に、前面カメラでの再起動時に映像が開始されない経路と、カメラ切り替え時に倍率ボタンの非表示が遅れる経路を修正する再現ビルドです。前面プレビューの開始要求と実際の画像受信を区別し、同じ所有者・世代の起動だけを期限付きで確認します。倍率表示は、ネイティブの切り替えが受理された時点でも更新します。

前面起動の待機・再試行は5秒の範囲です。開始要求が受理されても2秒間画像が届かない場合は、同じカメラ・表示入力を保ったプレビュー停止・再開を1回だけ試みます。停止開始には残り1.5秒以上を必要とし、停止後の対応する再開は最大2回です。すでに開始したネイティブ停止処理が期限を超えた場合も、安全な同一所有者の再開だけを完了させ、停止したままにしないようにします。実際の終了・前後切り替え・所有者変更は復旧を取り消します。

画質処理・保存品質・解像度・合成枚数と、既存の S2・S3・S4・S5・S6・S7・S8・S16・T1 を維持します。画像処理の ARM64 ライブラリーも v1.9.35 と同一です。

`src/build1936.py` は固定した元 MPP と Java ツールを使用し、変更範囲外のコードと他アプリの一致を検証します。`src/validate1936.py` は単体・総合 MPP を未改造 ULike 5.6.2(740) APKS に適用し、再構築・DEX 型解析・呼び出し契約を検証します。`src/finalize1936.py` はその検証済みバイナリと再現ビルドの SHA-256 一致を要求します。

公開ワークフローは両 Manager フィードと最新の承認済み ULike 系統を確認し、他アプリを保持した総合版を公開します。実機での黒画面再現・解消確認は行っていません。添付画面だけから端末上の原因を断定せず、確認できたコード上の問題と検証範囲を RELEASE_NOTES.txt と QA JSON に記録します。

撤回済み10bit経路や削除済み診断表示・原本保管機能は復活させません。元APKS、再構築APK、ユーザー写真、署名鍵は公開物に含めません。
