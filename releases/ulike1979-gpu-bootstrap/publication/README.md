# ULike v1.9.79 — GPU利用再開と保存後の検証進行

## 今回の修正

GPUが未認定のまま全区間CPUへ退避する状態を直すため、従来GPU経路の起動時の照合を、回数を制限して進めます。GPUの採用には独立した2回の全出力一致を要求します。最適化シェーダーとGPU・CPU配分候補の追加認定は、保存後の待機中に実行します。未認定、不一致、キャンセル、メモリ不足や失敗に対するCPU退避を保持します。

保存後の検証が待機し続けないよう、現在の処理・保存状態を再確認します。新しい撮影の開始を早く通知して背景検証を中断します。「直近の撮影・工程別処理時間」には現在の待機数・実行中・採用状況を添え、写真ごとの時間と記録済みスナップショットを変更しません。

解像度、ノイズ強度、質感・肌・ハロー・暗部の保護、シャープネス、保存形式と圧縮設定を保持します。実際の不一致を記録した拒否情報と画質認定を維持し、認定がない経路を無条件で使用しません。カメラの操作・保存制御、他アプリのパッチ資源と既存履歴も保全します。
