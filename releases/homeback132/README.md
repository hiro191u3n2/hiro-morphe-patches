# OneBack v1.1.25 — Instagramの適用時検査の誤検出を修正

Instagram 452.1.0.53.64にPikoを併用した際、`Instagram 452 external profile native body changed: LX/003Q;->A04`で停止する問題を対象とした更新です。総合パッチはv1.0.312、基準は公開済みv1.0.311／OneBack v1.1.24です。配布するOneBackランタイムのバイトは保持し、パッチ適用時の検査・変換処理を修正します。

## 原因

前版の完全なネイティブメソッド検査は、例外処理の表現方法まで同一であることを前提にしていました。原本の`003Q.A04`には234命令、13レジスタ、3つの保護区間があります。同じクラスを編集用の`MutableClass`にすると、複数の例外ハンドラーを持つ区間が分割され、同じ例外処理を5個のエントリで表す場合があります。

Pikoの`Customize navigation bar`は同じ`003Q`クラスの別メソッド`A07`を変更します。その結果、命令を変更していない`A04`も編集用の表現で検査され、前版のハッシュが一致せず停止しました。公開済みPiko 3.11.0-dev.3とHiro 1.0.311の実適用でも、報告と同じ`A04`エラーを再現しています。

## 修正

ネイティブメソッドの検査では、開始位置と長さが完全に同じ保護区間の例外ハンドラーだけをまとめて比較します。命令、レジスタ、保護範囲、例外型、ハンドラーの順序と移動先の検査は維持します。元から固定していた原本のハッシュも変更しません。処理の意味が変わる差分や、任意の他パッチの変更を受け入れる仕組みではありません。

また、先行パッチにより既に編集用になっているクラスは、OneBackが処理を始める時点で不変のコピーに固定します。これにより、OneBack自身の後続の編集が検査用の入力へ混ざり、同じ処理内で再検査した際に結果が変わることを防ぎます。

このコピーは、編集元のメソッド分類キャッシュを初期化せずに作成します。コピー後に追加するブリッジや補助メソッドが出力DEXから欠落しないことも、最終単体MPPを用いた4種類のSDKの回帰検査と、実際の出力APKの独立監査で確認します。

## 保持する内容

基準版のOneBackランタイムは93クラス、167,500バイト、SHA-256 `28a898a2a3d301203213efa460b39bb61676506ed639b6a120140899a1f6f612`です。全クラスの定義を検査した後、拡張ファイルの元バイトをそのまま使用します。実装変更、新規クラス、既存クラス削除は認めません。

v1.1.24の外部プロフィール認識、別プロフィールからの戻り、同じ操作で続けて終了しない保護、IME・コメント・ダイアログの優先処理を保持します。`HiroBack131`の診断ログもランタイムとともに保持します。非対象パッチのローダー、拡張、メタデータ、資産と既存のアップグレード参照も保持します。

## 検証範囲

公開ゲートでは、元の適用失敗の再現、編集用クラスの表現差の回帰、最終MPPの原本APKへの適用、対象のPiko併用、出力の処理・リソース保持、独立ビルドの一致を必須にしています。組み合わせのパッチ選択・順序・実行環境は最終QAに記録します。

報告されたManager 2.3.0-dev.7の公式APKと、その中の`patcher-host.jar`をそれぞれ固定SHA-256で検証して使用します。これにはPatcher 2.1.0-dev.4が含まれます。ローダーメタデータの検査は既存3種類にこの実行環境を加えた4種類で行います。近い版のDesktop実行環境を、報告されたPatcherの代用とは扱いません。

Managerの実際の選択キーを使い、次の4ケースを順に検査します。

| 組み合わせ | 公開に必要な結果 |
| --- | --- |
| PikoのCustomize navigation bar＋旧Hiro 1.0.311のOneBack | navigation適用後、同じ`003Q.A04`エラーを再現 |
| PikoのCustomize navigation bar＋最終単体OneBack 1.1.25 | 選択した2パッチが全て完了 |
| Pikoの対象版向け初期選択64個 | 選択した64パッチが全て完了 |
| 同じPiko64個＋最終総合1.0.312のOneBack | 選択した65パッチが全て完了 |

プロセス終了コードに加え、パッチごとの結果、完了イベントと生成APKを検査します。さらに、Piko64個を適用した出力と65個の出力を比較して、OneBackのフック以外のDEX、Manifest、リソース、ネイティブライブラリが保持されることを独立に監査します。Pikoが変更したversionCode・リソース名・値も比較の基準に含めます。部分実行の記録、別MPPの記録、原本APKだけの検査では公開できません。

Piko併用出力のリソース表では、スタイルのないグローバル文字列プールのインデックスだけが入れ替わる場合があります。文字列・出現回数・エンコーディングフラグが同じで、全リソースの名前・ID・設定・フラグ・参照解決後の値も完全一致する場合に限り許可します。同じ文字列を残して参照先の値を変える差分は拒否します。リソース表全体のバイト一致は主張しません。

68個という個数だけでは、利用者が選んだ全パッチとオプションは特定できません。実際に検証した選択だけをQAに記録し、全てのPiko機能や全ての組み合わせの成功を主張しません。また、APKへの適用成功は、Android 17 / Samsung SM-S948Qでの画面操作や、以前報告されたBack動作の解消を証明するものではありません。物理端末での操作確認は行っていません。

## 適用

対象はOneBack未適用のInstagram 452.1.0.53.64です。Morphe ManagerでHiroソースを更新し、「戻る1回で終了・履歴削除」を含む必要なパッチを原本に再適用して、生成APKをインストールします。

検証用原本は`com.instagram.android`、versionCode385811006、143,237,227バイト、SHA-256 `22f20062d16997e26009e73b0425974efef8ac69c76dd8912ee8a091213c39e2`です。原本APK、生成APK、Instagramのネイティブメソッド全文は公開資産に含めません。

ランタイムと適用時検査が依存する契約は`PROFILE_TAB_CONTRACT.md`、ビルドと公開手順は`publication/BUILD_LOCAL.md`にあります。最終の実行結果は公開QAを参照してください。
