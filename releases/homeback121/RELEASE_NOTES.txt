OneBack Exit No Recents v1.1.11 / Hiro Morphe Patches v1.0.250

Instagram のホーム／リールで Android の戻る操作を処理する、現在画面と終了条件の判定を更新。
Instagram 自身の現在のコンテナーとリールのページを確認し、共通の戻る処理とネイティブな戻る処理が参照する状態をそろえる。表示中のリールは有効なページ位置にかかわらず終了対象とし、リール以外のページや現在状態が不明な場合はアプリ本来の処理を保つ。
リールの常設フッターやキャプションの判定範囲を、そのコンテンツの範囲に限定。背後に残る大きな画面によって、フッターが開いているコメント欄と判定される条件を修正。
コメント欄、入力欄、キーボード、ダイアログ、別パネル、判定できない状態ではアプリ本来の戻る処理を優先し、同じ戻る操作で続けて終了しないようにする。

今回提供された Instagram 447.0.0.55.81 の APK は、配布版 v1.1.10 のランタイム 63 クラスと完全一致し、2 つのネイティブフックも正しい位置に存在することを確認。継承元の起動・キー入力・戻る処理と、プラットフォームのコールバック登録も静的に確認した。このコードを基に実行時の判定条件を見直した。

削除対象は Android の「最近使ったアプリ」に表示されるタスクのカード。Instagram 内やサーバー上の閲覧履歴を削除する機能ではない。
現行の総合版 v1.0.249 を基に、共通の戻る操作パッチを v1.1.11 に更新。ULike v1.9.105 を含むほかのパッチの収録内容と、無関係なローダークラス・収録ファイルを保持。
Morphe Manager の更新対象は Instagram。

配布前の必須検証：固定 Android SDK による本番コードのコンパイル、既存と追加の回帰試験、4 つの提供済み APK の全既存フックに対する新版ランタイムの互換性、現行総合版 v1.0.249 の公開ランタイム API と他パッチの保持。
単体版・総合版の配布 MPP を Morphe の全適用工程に通し、出力の 2 フック・分岐先・元のメソッドの保持・ランタイム全体の一致も検証する。ここで使う入力は、提供済みの古い APK のメソッドを保持した実行できない構造検証用データであり、未改造の元 APK ではない。
反例は、配布ランタイムと D8 で一致する本番コードを使い、同じホスト試験で前版と新版を比較する。前版との意図的な挙動差を、すべて利用端末の不具合とみなすものではない。配布前に固定したローカル成果物と、独立した 2 回の CI ビルドの MPP および QA の完全一致を必須とする。最終試験数とハッシュは同梱 QA に記録する。

提供済み APK はすべてパッチ適用済み。未改造の元 APK への適用、Android 実機での画面操作・終了・履歴表示、別パッチとの同時適用による動作は未確認。
端末上で問題が発生した瞬間の画面階層・実行経路は未取得。コードとホスト上のモデルで再現・改善した条件が、その端末での唯一の原因であるとは確定していない。

適用時は Morphe Manager のソースを総合版 v1.0.250 に更新し、Instagram の未改造の元 APK へ「戻る1回で終了・履歴削除」を含めて再パッチ・更新インストールする。ソースの更新だけではインストール済みアプリの処理は変わらない。
