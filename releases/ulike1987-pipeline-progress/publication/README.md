# ULike v1.9.87 — モデル準備・補正・仕上げ検証の最適化

公開済みULike v1.9.86／Hiro Morphe Patches v1.0.219を固定基準とし、単体v1.9.87／総合版v1.0.220を公開します。

## 修正

- CPUの最初の空間・領域モデル読取りで検証用の画素を取得し、同じ領域の再読取りを省きます。完了済みのGPU用読取りはGPU実行失敗後のCPU処理にも再利用します。保持量を配列確保前に予約し、CPUとGPUの時間には追加処理を公平に含めます。
- GPU認定も検証機会もない補正では、GPU用のマスク走査・RAW4ポリシー展開／再圧縮を省きます。既存GPU認定と登録可能な検証は保持します。
- 仕上げの検証を優先度付きの原子的予約へ移行します。画像コピー前にキュー枠と保持メモリを確保し、取消・例外・登録拒否で解放します。

## 検証と保持

全画素の計算・画質・解像度・HEIF設定、全12 native、画質認定キー、不一致記録、独立した2回の全出力一致、5%の速度条件、撮影ごとのコピー回数、保持上限を維持します。既存の予測保持と仕上げ実CPU比較、カメラ・保存・他アプリのコードを保持します。公開.86の全2157ソースをtests1987/source-scope86.jsonで固定します。歴史的な試験は変更せず、今回の限定した変更を逆適用する保存検査と、現在の本体を実行する動作検査を分離して検証します。

JDK21.0.8+9、Morphe1.16.0、Android/D8、NDKr27cを固定。declare1987.py → build1987.py → validate1987.py → finalize1987.py → publication/publish1987.pyで再構築・公開します。原本ULike 5.6.2(740) APKSへの実適用と完成APKの静的検査をローカルで行い、そのMPPとCIの再構築MPPを完全一致させます。端末での撮影・最終画質・体感速度は未測定です。
