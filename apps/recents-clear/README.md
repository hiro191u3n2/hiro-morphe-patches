# 履歴クリア v1.5.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.5.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版には同じ署名で上書き更新できます。

## 今回の修正

- 手動起動時の120ms待ちを撤廃。接続済みの通常起動は、自身の画面を閉じてすぐ履歴の表示処理へ進みます。
- 再起動後の1秒待ちを撤廃。設定がONならロック解除・画面点灯後に1回実行します。
- 削除ボタンの操作が拒否された時だけ、32ms後、さらに128ms後に新しい画面情報を確認して再試行します。成功後は繰り返しません。
- 成功したボタンIDの直接検索を維持します。

画面情報が未取得、または自身の画面が残っている時は待機します。端末側の描画・アニメーションによる待ち時間は残ります。

アイコン長押しの「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。「診断」で直近の結果を確認できます。常駐・保護アプリへの追加終了処理、クイック設定タイル、黒い覆い、端末全体のアニメーション設定変更はありません。

ビルド・署名・マニフェスト検証、サービスの模擬テスト78項目が成功しています。実機での削除動作・速度は未検証です。APKにはネット通信権限がありません。
