# Hiro TikTok Link Direct v1.0.0

TikTokで共有された動画リンクを開くときの、再生ボタン・フォロー案内付きの小窓を省略する追加パッチです。
対象は **global TikTok 47.4.3 / `com.zhiliaoapp.musically` / versionCode `2024704030`** です。

項目名は **「共有リンクの小窓を省略して動画を直接再生（TikTok 47.4.3）」** です。
共有動画の小窓を表示する専用判定だけを変更し、3つの既存利用箇所の動画遷移・後処理を保持します。
一般のダイアログやプレーヤーの動作を変更するランタイムは追加しません。

このディレクトリは新しい追加項目の対応ソースと公開手順です。
既存の総合 v1.0.306 に追加し、既存のTikTok改造、OneBack、日本語化と他アプリのパッチを保持します。
過去の実装を再コンパイルして上書きしません。

## 配布物

- `TikTok_LinkDirect_v1.0.0.mpp`: 新しい追加項目だけを収録。
- `Hiro_Morphe_Patches_v1.0.307.mpp`: 既存総合 v1.0.306 と追加項目を収録。

Morphe Managerで総合ソースを更新し、未改造の元APKに追加項目を含めて再パッチしてください。
以前と同じ署名設定で更新インストールしてください。ソースの更新だけではインストール済みアプリは変更されません。
