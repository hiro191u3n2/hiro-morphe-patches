TikTok：メッセージ・プロフィールのルートタブで戻るを押すと、終了ではなくアプリ自身のホームタブへ移動します。移動した同じ戻る操作では終了せず、ホームで次の戻るを押したときにタスクを終了し、最近使ったアプリから削除します。日本向け・通常パッケージが対象です。個別チャット・プロフィール編集・設定・コメント欄・キーボード・ダイアログは通常の戻る操作を優先します。ホームタブの認識が不明または曖昧な場合は、誤終了を避けるためその操作では終了しません。

Trip.com：ホームを判定できた場合の即時終了に加えて、ホームのUIを判定できなくても公開Backディスパッチャーで戻るを観測し、本来の戻る処理へ渡します。本来の戻る処理が正常に戻った後、最大1.5秒の範囲で同じActivityの遅延終了・バックグラウンド移動・停止を追跡し、アプリ自身のタスクを履歴から除外して削除します。同期呼び出し中だけ終了を判定していた前版の取りこぼし対策です。ホームキー、別操作、アプリ内画面遷移、画面回転、画面消灯・ロック、再表示で追跡を解除します。削除は元の自アプリタスクIDに限定して最大3回再試行し、新たに開いたタスクや他アプリは削除しません。

Instagramのホーム・リールでの終了、Xのホーム限定終了は維持します。ULikeを含む終了パッチ以外の資源・ローダーを保持します。
