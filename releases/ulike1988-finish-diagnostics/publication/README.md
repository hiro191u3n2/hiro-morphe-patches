# ULike v1.9.88 — 仕上げ失敗分類と処理内訳の診断

公開済みULike v1.9.87／Hiro Morphe Patches v1.0.220を固定基準に、単体v1.9.88／総合版v1.0.221を公開します。

## 修正範囲

- 実行・比較未完了の仕上げGPU候補を速度不足として扱う不具合を修正。実際の全出力一致2回と出力速度計測2回が成立した候補だけ速度で判定し、未完了・メモリ・CPU基準異常・取消などを区別します。非画質失敗の待ち時間と再試行上限は維持します。
- 旧GPU・32／64／128行候補の停止工程を有限スカラーで記録。GPU命令前の拒否と、実行／読戻し／全出力比較の未完了を判別できる情報を残します。
- 撮影別に前段・モデル準備・補正の各処理単位の時間、実際のCPU/GPU採用、観測できた拒否理由、コピー成立を記録。固定長データ、背景除外、終端不変、診断故障の非干渉を維持します。

## 保持と検証

画素計算・処理順・画質と強度・解像度・HEIF設定、全12 native、認定キー、不一致記録、2回の全出力一致と転送込み5%速度条件、撮影ごとのコピー回数、96MiB保持上限を維持します。公開.87の全2189ソースをtests1988/source-scope87.jsonで固定します。履歴試験は変更せず、今回の意図した差分だけに対するレビュー済みadapterを使い、実際の.88コードを実行する新規検証を追加します。

JDK21.0.8+9、Morphe1.16.0、Android/D8、NDKr27cを固定。declare1988.py → build1988.py → validate1988.py → finalize1988.py → publication/publish1988.pyで再構築・公開します。原本ULike5.6.2(740)APKSへの実適用と完成APKの静的検査を行い、そのMPPとCIのMPPを完全一致させます。Android実機の撮影・画質・処理時間は未測定です。
