# ULike v1.9.42 / Hiro Morphe Patches v1.0.175

ULike v1.9.41／総合版 v1.0.174 を基準に、弱い残留ノイズや少し大きな粒状成分の低減を強めます。

- 平坦部で弱いノイズへの処理がほぼゼロになる判定を見直します。NRのOFF・強度0と、ノイズが検出されない画像は保護します。
- 少し広い範囲も使って、細かな粒と周辺に連なった粒を低減します。
- 輪郭や文字に加え、周期的な細部の保護判定を拡張します。
- 分割処理の境界を検証し、最終保存まで処理が届くことを確認します。

v1.9.41 の約320msのシャッター表示を引き継ぎます。撮影受付・撮影枚数・保存キュー・保存解像度・形式・美顔と色処理・起動復旧・画面配置・レンズ処理は保持します。他アプリのリソースも基準の総合版と同一です。

## 検証範囲

固定した JDK 21.0.8 とツール群で再構築し、ホストでノイズ低減・文字と周期的な模様・不透明度・飽和画素・分割処理・設定OFF・保存経路を検証します。単体・総合版の両方を未改造ULike5.6.2（740）の完全なAPKSへ適用し、分割APK結合・再構築・arm64-v8a出力・DEX整合性・型解析・実APKのメソッド整合性を検証します。実行結果とMPPのSHA-256は `evidence/validation.json` と `QA_ULike_v1.9.42.json` に記録します。

Galaxy実機での画質・表示・保存時間は未確認です。合成画像の試験や、正解画像のない実写の分散低下だけでは、髪・布・壁紙の質感を完全に保持した保証にはなりません。非sRGB・F16・ゲインマップ画像の既存の代替経路は保持し、処理形式を推測して変更しません。

## 適用

Morphe Managerでパッチソースを更新し、未改造ULike5.6.2（740）へ「高画質撮影・質感美肌・素材通信を復旧」を再適用して、作成したアプリを更新インストールしてください。ソース更新だけではインストール済みアプリは変わりません。単体と総合はどちらか一方を使用します。アプリデータ削除は不要です。

## 再現用資料

`src/build1942.py` が固定した基準MPPとツール群から新しいMPPを生成し、`src/validate1942.py` が元APKSへの適用を検証します。`src/finalize1942.py` は配布MPPと適用試験のハッシュを照合して、検証結果とソースを梱包します。`manifest.json` が配布物、変更範囲、実行結果を固定し、`publication/` のワークフローが再ビルド・照合後に公開します。

元APKS、再構築APK、利用者の写真や切り抜き、署名鍵は公開用のソース・配布物に含めません。
