# 履歴クリア v1.16.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.16.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。旧版と同じ署名で上書き更新できます。

## 履歴を開いた後の処理を共通化して待ちを削減

ボタン検索に使う保存情報を履歴操作の前に読み込みます。履歴を開く要求が返った直後は、古い画面情報を解放してそのまま新しい画面を一度確認します。アイコン・自動実行のどちらも同じ処理を使います。確認用の予約は描画同期による待ちを回避する方式にしました。

報告されたv1.15の記録では、履歴を開く要求からクリックまで、自動実行1539ms・アイコン42msでした。一方、自動実行の画面取得とID検索は計8msで、両方ともクリック1回でした。約1.5秒の発生箇所は旧版の集計だけでは分からないため、履歴要求の応答・状態確認・保存情報の読み込み・処理待ちなどを個別に記録するようにしました。

## 更新・設定・診断

上書き更新後に端末を再起動してください。既存の「再起動のたびに1回実行」の設定は引き継ぎます。アイコン長押し→「設定」で変更できます（初期OFF）。アイコン長押し→「診断」→「診断をコピー」で、自動実行とアイコン実行の記録を一緒に確認できます。

今回の修正APKについて実機の表示時間は未検証です。実際のActivity・サービスを使う220項目の模擬テストを通過しましたが、アイコン時と同じ見え方になった、履歴が見えなくなったという実機確認を意味しません。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。
