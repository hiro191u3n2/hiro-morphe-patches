# Instagram の現在画面と戻る判定 v1.1.11

Hiro Morphe Patches v1.0.250。配信中の総合版 v1.0.249 を基に、Instagram のホーム／リールで Android の戻る操作を処理する条件を更新します。

## 今回確認したこと

今回提供された Instagram 447.0.0.55.81 の APK（SHA-256 `d5291dcb5f3f5252dff05b98b4fefba121369d3a1c74635190cb8ed8047757a7`）には、配布版 v1.1.10 と完全一致するランタイム 63 クラスが入っています。リール本体と MainActivity に追加した 2 つのフックも、それぞれ正しい位置に 1 個ずつ存在します。継承元の起動処理、キー入力、戻る処理、プラットフォームのコールバック登録も静的に確認しました。

この APK のコードを基に、現在の画面と終了を抑止する条件の判定を見直します。前版のホスト試験では、Instagram の実際のコンテナー構造を十分に再現できていませんでした。また、単純な合成 APK への適用成功は、Instagram 固有の 2 つのフックが入ることの証明にはなっていませんでした。

## 変更内容

- Instagram 自身の現在のコンテナーとリールのページから、表示中のホーム／リールと別画面を区別します。画面名や保持されている別タブだけで現在画面を決めません。
- 共通の戻る処理が参照する状態と、Instagram のネイティブな戻る処理が参照する状態をそろえます。表示中のリールは有効なページ位置にかかわらず終了対象とし、リール以外のページや現在状態が不明な場合はアプリ本来の処理を保ちます。
- リールの常設フッターやキャプションの判定範囲を、そのコンテンツの範囲に限定します。背後に残った大きな画面が、フッターをコメント欄と誤判定させる条件を修正します。
- コメント欄、入力欄、キーボード、ダイアログ、別のパネル、判定できない状態では、アプリ本来の戻る処理を優先します。同じ戻る操作でパネルを閉じた後に続けて終了することを防ぎます。

終了対象と確認できたホーム／リールでは、タスクを終了して Android の「最近使ったアプリ」のカードを削除する設計です。Instagram 内やサーバー上の閲覧履歴を削除する機能ではありません。前版の 2 つのネイティブフックの位置は維持します。

## 検証と限界

配布前の必須条件は、固定した Android SDK による本番ランタイムのコンパイル、既存試験と今回の回帰試験、4 つの提供済み APK の既存呼び出しとの互換性、現行総合版 v1.0.249 の公開ランタイム API の保持です。今回の提供 APK のコード一致・フック位置・起動と入力の経路は、新しい版の検証記録へ明示して収録します。過去の v1.1.10 の記録を新しい試験結果へ書き換えません。

単体版・総合版の配布 MPP を実際に読み込み、Morphe の全適用工程を通す試験も必須にします。この試験には、提供済みの古い APK から 3 メソッドをそのまま複製した、**実行できない構造検証用のデータ**を使います。古い終端ラッパーへの参照を残したデータであり、未改造の元 APK や実行可能な Instagram APK ではありません。出力の 2 つのフック、分岐先、元のメソッドの保持、配布ランタイム全体との一致を検証します。別パッチとの同時適用試験には当たりません。

フッター／キャプションの反例は、同じホスト試験を前版と新版の本番コードで比較します。ホスト用クラスを D8 に通し、それぞれの配布・固定ランタイムと一致することも確認します。ローカルで固定した MPP と QA は、独立した 2 回の公開 CI ビルドの結果と完全一致した場合だけ配信します。具体的な最終試験数とハッシュは同梱 QA に記録します。

これらは静的解析、ホスト上のモデル、構造検証です。Android 実機での画面操作、終了、履歴削除は未確認です。問題が起きた瞬間の画面階層やイベントの実行経路も取得していません。モデルで再現・改善した条件が、その端末での唯一の原因であるとは確定していません。

## 適用方法

Morphe Manager のソースを総合版 v1.0.250 に更新し、Instagram の未改造の元 APK に「戻る1回で終了・履歴削除」を含めて再パッチして、更新インストールしてください。インストール済み APK の処理は、ソースの更新だけでは変わりません。パッチ済み APK への重ね掛けは既存の検出処理で中止します。

単体版は OneBack Exit No Recents v1.1.11 です。総合版 v1.0.249 の無関係な収録ファイルとローダークラスは保持します。ULike v1.9.105 を含む他パッチの収録内容を変更せず、今回の更新通知は Instagram を対象とします。
