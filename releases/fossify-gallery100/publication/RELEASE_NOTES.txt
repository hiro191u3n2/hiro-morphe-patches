Fossify Gallery No Recents v1.0.0 / Hiro Morphe Patches v1.0.257

Fossify Gallery で Android の戻る操作によってアプリを終了するとき、「最近使ったアプリ」のタスクカードも削除します。
画像やフォルダーから上の画面へ戻る操作、選択状態やダイアログを閉じる操作は、アプリ本来の動作を維持します。

公式の Fossify Gallery 1.14.0（org.fossify.gallery）を対象に、単体 MPP と総合 MPP をそれぞれ実際に適用し、終了箇所、ランタイム、指定箇所以外のコード・資源の保持を検証します。Android SDK でのコンパイルとホスト試験を行い、独立した 2 回の CI ビルドがローカルで固定した MPP／QA と完全一致した場合だけ公開します。Android 実機での画面操作・終了・タスクカード削除は未確認です。

総合版 v1.0.256 の既存のパッチクラスと資源を保持して、新しい Fossify Gallery 専用パッチを追加します。ULike v1.9.108、OneBack v1.1.14 を含む既存パッチの変更はありません。Morphe Manager の更新対象は Fossify Gallery です。

Morphe Manager のソースを v1.0.257 へ更新し、対応する Fossify Gallery APK に「戻る終了時に履歴を削除」を適用して、これまでと同じ Morphe 署名キーでインストールしてください。ソースの更新だけでは、インストール済みアプリの動作は変わりません。
削除対象は Android の「最近使ったアプリ」に表示されるタスクカードです。写真やアプリ内の閲覧データは削除しません。
