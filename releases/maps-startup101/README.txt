パッチ名
起動時に現在地を表示

前版からの修正
起動途中の地図モード NONE を中止条件にしていた不備を修正しました。
現在地処理の呼出しだけで完了扱いにしていた処理を置き換えました。
位置情報が取得され、地図を描画する準備ができてから本来の地図移動処理を使います。
実際の地図中心が取得した現在地の近くにあることを2回確認して完了します。
ボタン表示の有無・有効状態は移動条件にしません。

動作
通常のアイコン起動時、画面の復帰後に約1秒の準備待ちを行います。
地図・現在地の準備を最大60秒待ちます。
現在地追従が有効で、地図中心が取得した現在地から50m未満にあり、ズーム13以上の場合に移動済みと判定します。
遠く離れている場合は現在地へ移動し、広域表示は標準的なズーム15にします。
現在の傾き・方角を保ち、コンパス追従をボタンの連打で切り替えることはありません。
表示の復元などで初回の移動が反映されなかった場合、操作されていなければ1回だけ再試行します。
画面を触った時点で待機・再試行を中止します。
外部リンクで指定された場所、経路表示、ナビゲーションを優先します。
GPS設定・Androidの位置情報権限を変更する機能ではありません。

使い方
1. Morphe ManagerでHiro Morphe Patchesをv1.0.361へ更新するか、
   Maps_Startup_Location_v1.0.1.mppを読み込みます。
2. 旧版の起動時現在地パッチを入れる前のmicroG Maps APKを選択します。
3. 「起動時に現在地を表示」を選び、パッチを適用します。
4. 作成したAPKをインストールします。
5. 端末の位置情報をオンにし、アプリへの位置情報使用を許可して起動します。

カテゴリ行の非表示
統合版には従来の「検索欄の下のカテゴリ行を非表示」も収録しています。
元APKで両方を選んで適用できます。単体版と統合版はどちらか一方を使用してください。
ソースの更新だけではインストール済みアプリには反映されません。

検証と限界
APKへの適用、旧版の停止条件を含む生成DEXの実行命令、ライフサイクルの処理、
元のコード・リソース保持、既存カテゴリ非表示との併用を検証済みです。
今回の添付APKは、既知の旧パッチだけを厳密に除いた検証入力にして、新版を適用します。
これは検証用の処理であり、公開MPPの重ね掛け対応を意味しません。
起動・中断の58ケース／416項目、生成DEX命令の50ケース／848項目を検証しました。
同じ生成コードを旧SDKとSDK 2.2で実行し、両方で成功しています。
QA_Maps_Startup_Location_v1.0.1.jsonに実施結果を記録しています。

前回エミュレーターがAPK導入前に接続失敗したため、その制約を継続して明記します。
