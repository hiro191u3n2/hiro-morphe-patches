TikTok：他ユーザーのプロフィール画面などで「戻る」が無反応になる経路を修正。前版で、タスク内の子Activityの標準戻るまで終了ガードが遮断する条件と、戻るアイコンの親Viewにクリック処理がある場合に対象を認識できない条件を確認しました。子画面の標準戻るを保持し、戻る／閉じるの意味を確認できたアイコンから実際のクリック可能な親へ処理を渡します。フラグメントの戻り先が実在する場合は、保存済み状態を書き換えず公開APIで1階層戻る経路を追加しています。

TikTokのホーム以外は終了させず、アプリ内ホームへ戻す方針を維持します。画面を閉じてホームへ復帰した同じ操作で終了することは許可しません。ホームを確認できた後の別の戻る操作で、タスク終了と最近使ったアプリからの削除を実行します。未知の画面に対して座標を推測して押す処理や、未知のランチャーの再起動は追加していません。ホーム復帰を確認できない構成では、元の画面へ1段階戻るだけ、または画面にとどまる可能性があります。

Instagramのキーボード表示時は先にキーボードの操作を優先。コメントや他のパネルがないホーム・リールでは、別の戻る操作で終了・履歴削除します。ストーリーズ、プロフィール、検索などの既存の通常戻る動作は維持します。コメントの閉じる操作ではタスク／最近使ったアプリのカードを削除しません。ログイン情報、投稿、メッセージやコメント本文を削除する変更ではありません。
