# ULike v1.9.118 / Hiro Morphe Patches v1.0.285

公開済み単体v1.9.117と統合版v1.0.284を固定ハッシュで取得する。統合版のULike関連エントリが単体版と一致することを確認し、統合版で他アプリの全エントリをバイト単位で保持する。公開直前に配布先の現行版が進んでいれば、その新しい基準から再構築して検証し直す。v1.9.114の単体MPPも独立した過去native再構築証拠として固定取得する。配布物の継承元ではない。

## 変更範囲

アプリ初期化の時点で既存の2秒静穏期間を開始し、標準GPU準備と重ねる。GPUの数値処理に関わるJava・native・shaderは公開済みv1.9.117とバイト同一に保つ。同一アプリ・端末・driver・処理指紋で保存したtile8のEXACT+FAST認定を復元できれば、起動直後の最初の撮影でprofile7を採用する。拒否、証拠の片方欠落、指紋不一致、新規インストールは復元不可とし、固定70例と縦横各2回の速度比較を通過するまで標準GPUへ退避する。撮影開始で未完了の背景検証を中断し、撮影保存の前段に待機を増やさない。認定証拠のない新しい環境では初回tile8を保証できない。

強ノイズ・モデルのGPU回収内訳を保持する。診断値はGPUカーネル単独の時間や撮影全体の短縮を意味しない。GPUの新しいシェーダーや連結候補を無条件に採用しない。

保存後のGPU連結については、既存経路と候補のStrongワーカー数、区間行数、実GPU/CPU区間数が揃う場合だけ速度を比較する。全画素一致と候補5%以上短縮の条件は維持する。前段native1955、Strong CPU native1958、GPU native1960と数値処理Javaはv1.9.117の公開版に対しバイト同一を要求する。

`GpuRegionalDefault19115`とnested classは配布DEXに含めない。研究用のregional GPU・厳密除算・専用補間パスの検証資料は継承するが、それを写真での自動採用証拠とは扱わない。既存の画質設定、入力・出力寸法、保存形式、保存所有権とメモリ予算を保持する。

## 再構築と検証

Temurin21.0.8+9、Android NDK r27c、固定ハッシュのMorphe Desktop1.16.0・Android35・D8、NumPy2.3.5を使用する。

1. `src/declare19101.py`で本番ヘルパー、全ソース、公開スクリプトと公開済みMPPを固定する。
2. `src/build19101.py`で公開済みv1.9.117を単体基準、v1.0.284を統合基準としてGPU1960・NR1955・Strong CPU1958を独立に再構築する。固定したv1.9.114のELFとソースの逆変換による継承証拠、v1.9.117からの限定差分、JNI ABI、完全DEX、他アプリ保持、ヘルパー参照を検査する。
3. `src/host_audit19101.py`で旧版へのソース逆変換、実JNI/GLES、arm64、起動時中断、認定の速度・全画素条件、所有権、メモリ予算と既存経路の回帰を実行する。
4. `src/apply_original19101.py`で未改造ULike5.6.2(740)APKSへ単体版と統合版を別々に適用する。適用後のFULL DEX、リソース、arm64、元native保持とメソッドを調べ、完成MPPのハッシュに証拠を結び付ける。
5. `src/finalize19101.py`と`src/validate19101.py`で新しい実行証拠を完成MPPのSHA-256へ結び付ける。過去版の適用証拠は流用しない。
6. `publication/publish19101.py --local-only`と`--preflight-only`で公開資産、main/dev、現行配布MPPを照合する。19101というスクリプト名とschemaは互換のため保持し、実版値は1.9.118/1.0.285と照合する。

Galaxy実機でのこの版の保存時間と画質は未計測。保存公開まで2,000ms以下という目標の達成は、ホストやエミュレーションの速度だけからは判定しない。

## 公開

ユーザーは今回の改造完了後の自動公開を指示している。公開は完成した資産の再構築、ホスト検証、元APKSへの適用、固定SHA、現行main/devへの事前照合をすべて通過した場合だけ行う。失敗時は公開済みを示すreceiptを生成しない。

既存タグと配布branchは上書きしない。固定commitの資産を再取得して照合し、main/devの更新は直接子commitとatomic leaseで行う。元APKS・生成APK・個人写真・診断ログ・ツールチェーンは公開せず、ソース・試験・匿名化した構造証拠だけを公開する。
