TikTok 47.5.3 対応 v4.0.0 / 総合パッチ v1.0.280

対象はグローバル版 TikTok 47.5.3（com.zhiliaoapp.musically、versionCode 2024705030）です。署名を確認した未改変の実APKを使用して、過去の Hiro 製 TikTok パッチの接続先を作り直しました。

今回の対応

・「戻る1回で終了・履歴削除」v1.1.20：47.5.3 のタブ判定・ホーム切り替え先に接続し直しました。ホーム以外ではホームへ戻り、ホームでは終了して履歴から削除する処理です。一時表示のオーバーレイを考慮します。TikTok に Instagram の処理を適用しません。
・フィード左下の文字・再投稿欄を非表示：47.5.3 の対象コンポーネントに接続します。
・フィード下部の CapCut・エフェクト誘導枠を完全遮断：47.5.3 の対象枠と再表示の経路を処理します。
・動画のシークバーを常時表示：47.5.3 のシークバー判定に接続します。
・シーク中の動画プレビューサムネイルを表示：47.5.3 のプレビュー判定に接続します。
・フォロー中のストーリーズ件数を非表示：47.5.3 の対象表示に接続します。
・TikTok 怪しい通信だけ遮断：47.5.3 の通信先文字列と対象リソースを検査して適用します。ELF 形式のライブラリは等長置換し、ZIP／DEX 形式の .so は各形式の整合性を保って再構築します。
・「TikTok設定を日本語化」：従来の日本語化パッチを同梱し、上流 Settings と組み合わせた 47.5.3 実APKで設定画面への接続を検証しました。日本語化の辞書・実装は v1.0.0 と同じです。

適用方法

1. Morphe Manager 2.1.0-dev.2 の「設定」→「パッチ処理」→「エキスパート モード」をオンにし、確認画面で「有効化」を押します。
2. 単体「TikTok_47.5.3_Hiro_v4.0.0.mpp」または総合「Hiro_Morphe_Patches_v1.0.280.mpp」のどちらかを読み込みます。Metra 設定の日本語化も使う場合は、icysymmetra/tiktok-patches-for-morphe v0.9.0-dev.1 のソースも有効にします。
3. パッチ未適用の TikTok 47.5.3 の完全な APK を選びます。すでにパッチを適用した APK に重ねて適用しないでください。
4. Hiro ソースの必要な項目を選びます。日本語設定を使う場合は、Metra 側の「Settings」を手動で有効化し、Hiro 側の「TikTok設定を日本語化」も一緒に選びます。日本語化は既定では未選択です。端末またはアプリの言語を日本語にします。
5. 選択内容を確認して適用し、選択した全項目が成功したことを確認します。

未選択の「Settings」が見つからない場合は、検索条件を消し、一覧上部の選択件数／フィルターのバッジをタップして「選択されたパッチのみを表示」を解除します。Hiro のネイティブ機能6個と戻る処理は、Metra Settings がなくても適用できます。

検証範囲

署名確認済みの実APKに、単体 MPP のネイティブ機能6個＋戻る処理の7パッチ、および総合 MPP の Hiro 製8パッチ＋上流 Settings の9パッチをそれぞれ適用し、失敗パッチが0件・各工程が成功であることを確認します。公開処理はこの2ケースの実行記録、出力 APK のハッシュ、ネイティブ処理・戻る処理・通信処理・設定接続の監査がすべて揃った場合だけ進みます。

ローカル2回と CI 2回のビルド結果が、実APKで検証した MPP とバイト単位で同じであることを要求します。元の APK と生成した APK は配布しません。検証記録と対応するソースを同梱します。

Android 17 / Samsung SM-S948Q を含む実機上の表示・操作・通信は未確認です。パッチ適用とコード接続の検証は、実機で全機能が動作することの保証ではありません。別のパッケージ、別バージョン、別の APK 構造への対応は追加していません。構造が一致しなければ処理を止めます。

上流パッチの制限

別途、上流 Metra v0.9.0-dev.1 の全136パッチを 47.5.3 に試した調査では124パッチが適用扱い、12パッチが失敗しました。この部分成功の出力は公開対象外です。「適用扱い」はそのパッチの実機動作確認を意味しません。今回の Hiro 版は次の上流12パッチを修正していません。

AMOLED dark theme / Block P2P video relay / Comment tools / Feed text sizes / Hide Play Store update offer / Hide inbox items / Hide search suggestions / Lift text length limits / Mute feed videos / Remove LIVE extras / Remove unused language packs / Show follow status

上流の全パッチを選択しても成功するというリリースではありません。今回の日本語化との組み合わせで検証する上流パッチは Settings です。

総合版は v1.0.279 を基準に TikTok 用の対象実装を更新し、その他のアプリのパッチと ULike の運用設定を維持します。Morphe Manager の更新対象は TikTok のみです。
