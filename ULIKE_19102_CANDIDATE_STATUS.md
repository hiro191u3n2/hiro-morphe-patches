## Implemented scope

1. Keep full resident image capacity while reserving CPU transfer capacity for at most 256 rows, at both actual allocation and preflight. For 4080 by 3060 this is 4,177,920 transfer bytes; for 3060 by 4080 it is 3,133,440. This corrects admission accounting; it does not shrink the image or promise the same reduction in actual GPU allocation.
2. Permit already-ready default Strong and model GPU routes only inside the owned, uncancelled whole-output benchmark. Retain the independent CPU oracle and reject reference changes during comparisons/timing. Do not wait on or recursively enqueue startup workers from that background job.
3. Hash canonical numerical/native dependency identities rather than diagnostic review metadata. Explicitly classified diagnostic files remain outside the compute identity. Unknown runtime/native files still require classification. Numeric/admission changes still invalidate identity; this real .102 change conservatively requires requalification once. There is no blind migration of .100/.101 speed certificates and no semantic exemption for arbitrary edits inside numerical classes.
4. Register uncaught operational terminal failures in the actual failure/retry ledger before removing the job owner. Preserve cancellation and prevent double registration of an already-recorded terminal outcome.
