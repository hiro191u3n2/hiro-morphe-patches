# Aurora Store favourite startup and Back fix v1.0.1

Aurora Store 4.8.4 (76), package com.aurora.store. Startup shows Favourite Apps with Main underneath, allowing native Back navigation to return to normal Home and preserving detail navigation.

Both official-signed and F-Droid builds receive standalone and combined application checks under legacy and Patcher 2 toolchains (eight applications). The new tool is Desktop 1.19.0-dev.4 / Patcher 2.0.0-dev.12; Patcher dev.13 itself has not been executed.

This release replaces Aurora patch/runtime entries in Hiro Morphe Patches v1.0.265 to produce bundle v1.0.266 and standalone v1.0.1. Other patches and resources remain preserved. No APK is published. Physical Android UI execution has not been performed.
