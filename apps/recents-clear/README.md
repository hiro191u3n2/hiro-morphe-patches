# 履歴クリア v1.8.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.8.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版へ同じ署名で上書き更新できます。

## 再起動後の初回を早める準備

ユーザー補助サービスをDirect Bootに対応させました。最初のロック解除前からAndroidがサービスを接続できるようにし、解除後の接続待ちを減らすことを狙った変更です。

ロック解除前に画面を読み取ったり、履歴を操作したりすることはありません。解除通知を受けて既存の設定を確認し、「再起動のたびに1回実行」がON・画面点灯・ロック解除済みの条件がそろった時に1回実行します。設定や実行済み記録の保存先は変更せず、旧版の設定を引き継ぎます。

解除待ちの定期ポーリングは追加していません。解除と接続が重なる場合、重複通知、サービスの再接続、設定OFFを確認するテストを含みます。診断には「初回ロック解除前のサービス接続」を追加しています。

## 使い方と検証範囲

アイコンを押すとそのまま消去します。アイコン長押しの「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。「診断」で直近の結果を確認できます。

v1.7.0のボタンID・文字検索、不要な全体探索と先読みの削減、履歴表示要求直後の即時確認を維持しています。ボタンの検出とクリックの処理自体は同じです。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。

ビルド・署名・マニフェストと実際のサービスコードを動かすホストテスト123項目で検証しています。実機での再起動後の復帰・削除・速度は未検証です。端末側のサービス接続・ランチャー初期化・削除アニメーションにも時間がかかるため、アイコン操作と同じ速さになる保証はありません。

仕様の根拠：[Android Direct Boot](https://developer.android.com/privacy-and-security/direct-boot) / [Androidのユーザー補助接続処理](https://android.googlesource.com/platform/frameworks/base/+/master/services/accessibility/java/com/android/server/accessibility/AccessibilityManagerService.java)
