# Amazon 評価件数順 v1.0.8

Amazon 評価件数順パッチ v1.0.8 / Hiro Morphe Patches v1.0.356

対象：最初に添付された Amazon ショッピング32.19.0.100 / Amazon v1.23.1のAPK
パッチ名：商品検索を評価件数の多い順に表示

確認できた不具合と修正
・空の検索語通知を検索終了と誤判定し、検索処理を停止させていました。元APKと同じく空の通知は無視し、実際の画面終了で停止します。
・追跡情報やURL末尾のハッシュが変わるだけで検索中の状態が失われていました。検索条件の変化と追跡用表記の変化を分けます。
・検索画面へ戻った際、検索語が保存されていない経路で再開できませんでした。画面表示の通知から再開します。
・Amazonが扱う単数形keywordパラメーターに対応していませんでした。Java・JavaScript両方の検索識別に追加します。
・検索の通知が新しい商品DOMより先に届くと、旧商品の構成を固定し、新商品を除外していました。読み込み済みの商品が追加・更新・置換された際は、操作が落ち着いてから自動で並べ直します。新たな自動先読みは行いません。
・一部の商品枠や検索の外側に追加された通常商品一覧を見落としていました。商品リンク・画像・商品名・評価表示と繰り返しの枠構造から認識し、同じ表示形式の商品をまとめて並べます。

範囲
最初の検索は約100商品を目安に最大20秒先読みします。操作で中断できます。取得できた、評価件数を確認できる商品が対象です。Amazonの全検索結果を取得した順位ではありません。件数には星だけの評価も含みます。
追加商品や件数変更は自動で再整理します。スクロール・タッチ中は並べ替えを延期し、操作後は可能な範囲で見ていた位置を保ちます。件数不明は推測せず、状況を表示します。

使い方
Morphe ManagerのHiro Morphe Patchesを1.0.356へ更新するか単独MPPを読み込み、最初のAmazon v1.23.1のAPKへ今回の「商品検索を評価件数の多い順に表示」だけを適用してください。
v1.0.0〜v1.0.7適用済みAPKへの重ね掛けは受け付けません。単独版と統合版はどちらか一方を選びます。作成したAPKをインストールしてください。

検証について
上記はv1.0.7のソースと実APKの呼出順序に基づき、実行可能なホスト試験で再現した不具合です。今回のユーザー端末でどれを踏んだかは確定していません。
実際のAmazonアプリのDOMは取得できておらず、DOM試験は合成データです。Android実機での検索・順序・操作・更新マークは未確認です。
既存の広告非表示・価格履歴と他アプリのパッチを保持します。元APK、画面録画、検索語や商品情報を公開物へ含めません。
