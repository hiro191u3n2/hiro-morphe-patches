# ULike v1.9.106 / Hiro Morphe Patches v1.0.248

公開済み単体v1.9.105と総合版v1.0.247を固定ハッシュで取得する。他アプリの変更はバイト単位で保持する。

## 変更範囲

保存後の既存経路とCPU基準の不一致が確定し、固定したStrong入力によるGPU出力の再現まで確認した場合だけ、不一致の1画素についてCPU・診断用GPUプログラムの中間値を比較する。浮動小数点のビット列と最初に観測した差を記録する。診断専用プログラムの出力も既存GPU行と厳密に比較し、再現できない場合に元の差の原因と断定しない。

GPUプログラム60は診断専用で、通常撮影は既存プログラムを使用する。元の60プログラムのネイティブ選択値と前処理後のシェーダーを固定した公開版ソースと比較する。CPU/GPUの通常画素演算と丸め規則は変更しない。診断結果から画質・速度認定を書き込まず、既存の厳密な採用条件を維持する。

## 再構築と検証

Temurin21.0.8+9、Android NDK r27c、Morphe Desktop1.16.0、Android35/D8の固定ハッシュ、Python3.12系とNumPy2.3.5を使用する。

1. `src/declare19101.py`で本番ヘルパー、全ソース、公開スクリプトを固定する。
2. `src/build19101.py`で単体・総合MPPを構築する。完全DEX、既存ABI、他アプリ、ヘルパー参照、通常撮影への診断混入防止を確認する。GPU nativeは同一NDKによる正方向再構築と、変更した2ソースと指紋を公開版へ戻す逆方向再構築で完全ELFを照合する。NR nativeは公開版と同一バイトを継承する。
3. `src/host_audit19101.py`で現在ソースの既存試験と今回追加した診断試験を実行する。
4. `src/apply_original19101.py`で私有の未改造ULike5.6.2(740)APKSへ完成MPPを実際に適用し、FULL DEXとリソース再構築、arm64、元native保持、適用後メソッドを確認する。
5. `src/finalize19101.py`と`src/validate19101.py`で今回の実行証拠を配布MPPのSHA-256へ結び付ける。
6. `publication/publish19101.py --local-only`、`--preflight-only`の後に公開する。既存互換のためスクリプト名とschema名に19101が残るが、版値は1.9.106/1.0.248で照合する。

この版は差分演算の特定を進める診断追加であり、Android実機での±1階調差解消・速度短縮は未確認。ホスト一致やAPK適用成功をGalaxyでの解消・保存2,000ms以下達成の証拠にしない。

## 公開

検証済みdraft資産を公開し、固定commitの配布ファイルを再取得して一致確認後、main/devの両HEADを照合して直接子commitをatomic pushする。他の変更を保持する。既存release/tag/配布branchを上書きしない。
原本APKS、生成APK、個人写真・診断ログ、ツールチェーンは公開しない。ソース・テスト・匿名化した構造証拠のみ公開する。
