Hiro Morphe Patches v1.0.320 / OneBack v1.1.29

これは戻る操作の経路を調べるための診断版です。初回と 2 回目で動作が違う問題を解消したと確認できた版ではありません。

既存の戻る処理に到達すると、HB320 で始まる 2 行の短い診断コードを一時表示します。同じ処理中に通った複数のフックは 1 回の表示にまとめ、Activity が終了しても表示できるよう application context を使います。同じコードを端末内ログの HiroBack320 タグにも出します。

追加診断コードは固定の区分と数値のみです。URL・プロフィール名・投稿内容・入力内容などは含めず、自動送信しません。既存の戻る判断を変えず、どの登録・安全条件・処理結果を通ったか観測します。独立した診断テストは 20 ケース・182 アサーションが成功しました。既存 28 ソースの実行判断を AST 逆変換で照合し、診断呼び出し 33 個・観測 wrapper 15 個以外の変更がないことと、4 個の変更注入を拒否することを確認しました。追加診断のプライバシー検証も成功しています。全 36 host suite が成功し、194 ソースを固定した独立ビルド 2 回の MPP・QA JSON はバイト一致しました。元 APK 単独 1/1 と、Piko 3.11.0-dev.3 の default 64 選択との併用 65/65（両ソース順）の適用が成功し、各出力の 6 監査と runtime 101 定義・native hook 12 個の保持検証が成功しました。

利用するには Morphe Manager で Hiro ソースを更新し、クリーンな Instagram 452.1.0.53.64 APK に「戻る1回で終了・履歴削除」を選択して再パッチし、出力 APK をインストールしてください。ソース更新だけではインストール済みアプリは変わりません。

確認する内容：同じブラウザリンクについて、最初に開いて戻った時と、もう一度開いて戻った時の HB320 の 2 行、および移動先（ホーム・ブラウザ・同じ画面）を記録してください。ホームから追加で戻った場合は、そのコードも別に記録します。表示がなければ「表示なし」で構いません。共有に必要なのはコードと移動先だけで、リンク先やプロフィール内容は不要です。コードの詳細は同梱 README に記載しています。

実機未確認。診断コードや終了処理の記録だけで、問題の解消や OS による終了完了を断定しません。Piko 併用は両ソース順を指定しても Manager の実際の実行順は同じでした。各出力は個別に検証済みですが、任意の追加選択を含むすべての組み合わせを検証したものではありません。
