# Amazon 評価件数順 v1.0.7

Amazon 評価件数順パッチ v1.0.7 / Hiro Morphe Patches v1.0.355

対象：Amazon ショッピング 32.19.0.100（最初に添付された Amazon v1.23.1 のAPK）
パッチ名：商品検索を評価件数の多い順に表示

変更内容
・アプリの検索内容更新を直接受け取り、URLが同じまま検索結果が変わる経路でも並べ替えを開始・更新します。
・ページ読み込み通知が後から来ても、検索内容更新の情報を取り消さないようにします。
・検索画面を閉じる通知で並べ替えを停止し、ホームなどへ切り替わった後に処理を残さないようにします。
・既知の商品一覧クラスや data-asin がないモバイル表示でも、検索画面と確認できた場合に商品リンク・評価表示・繰り返しのカード構造から一覧を認識します。
・既存の広告非表示、価格履歴、他アプリのパッチを保持します。

動作範囲
検索直後に約100商品を目安に先読みし、読み取れた評価件数の多い順で一覧を固定します。追加分・件数未確認分は待機し、「追加分を含めて並べ直す」でまとめ直します。
先読みは最大20秒で、画面に触れると中断します。取得数は検索結果や通信状況によって変わります。
評価件数には星のみの評価を含みます。文章付きコメントだけの件数ではありません。未取得の商品を含むAmazon全検索結果の順位ではありません。

使い方
1. 単独MPPを読み込むか、Morphe ManagerのHiro Morphe Patchesを1.0.355へ更新します。
2. 最初に添付されたAmazon v1.23.1のAPKへ「商品検索を評価件数の多い順に表示」だけを選んで適用します。
3. 出力APKをインストールします。ソース更新だけではインストール済みアプリは変わりません。
v1.0.0～v1.0.6の評価件数順パッチ適用済みAPKへ重ねて適用せず、元の添付APKから作成してください。単独版と統合版はどちらか一方を使用します。

検証範囲
元APKの検索イベントと呼出経路を解析し、欠けていた経路を追加しました。端末で発生した不具合の真因がこの経路だったと断定したものではありません。
APKへのパッチ適用、元のコード・資源保持、検索識別と並び順のホスト試験を実施する版です。合成DOMの試験は実機の検索結果を再現した証拠ではありません。
Android実機での検索・表示順・操作と、端末上の更新マークは未確認です。
検索語や商品情報の記録・外部送信は追加しません。元APKと画面録画は公開物に含めません。

## Build

```sh
python3 src/build.py --base baseline354.mpp --tools tools --work build --dist dist --apk supplied.apk --java-home /path/to/jdk21
```

`publication/baseline.json` identifies the immutable baseline. The supplied APK is private and is never included.
