# Fossify Gallery 戻る終了時の履歴削除 v1.0.0

Fossify Gallery 1.14.0（`org.fossify.gallery`）の Android の戻る操作でアプリを終了するときに、「最近使ったアプリ」のタスクカードを削除します。Hiro Morphe Patches v1.0.257 に追加するパッチです。

アプリ自身が使う AndroidX の戻る処理へ追加します。検索を閉じる操作、グループ化したフォルダー内の移動、写真表示から一覧へ戻る操作を先に処理し、実際にタスクの入口から退出する場合だけ `finishAndRemoveTask()` を呼び出します。「全メディアを表示」の入口も対象にします。アプリを使用中のタスクカードを常に非表示にする設定や、プロセスを強制終了する処理は追加しません。

公開公式 APK への単体・総合パッチの適用、変更する命令と元の処理の保持、ランタイムの一致、既存パッチの全クラスと資源の保持を検証します。ソースとツールを固定して独立した二度のビルドを照合します。Android 実機での画面操作やタスクカードの表示は未確認です。

Morphe Manager でソースを更新し、Fossify Gallery の「戻る終了時に履歴を削除」を適用して、従来と同じ署名キーで更新インストールしてください。単体ファイルは `Fossify_Gallery_NoRecents_v1.0.0.mpp`、総合ファイルは `Hiro_Morphe_Patches_v1.0.257.mpp` です。ソースの更新だけではインストール済みのアプリは変わりません。

写真・動画・フォルダー、アプリ内の閲覧履歴は削除しません。他アプリの既存パッチは基準の総合版 v1.0.256 から保持します。
