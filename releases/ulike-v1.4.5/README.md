# ULike v1.4.5 / Hiro Morphe v1.0.83

v1.4.4で残っていた端末登録・設定初期化の停止を修正します。AppLog$ActionReaper.run()は元の実装へ戻し、ActionQueueItemは設定・端末登録等の8種類だけを受付けます。操作履歴・ページ閲覧・各種ログ・Google広告ID更新・ユーザー識別子更新は通しません。解析ログ送信・プッシュ・AppsFlyer停止は維持します。端末登録/設定取得の通信と付随する端末・アプリ情報の送信は許可されます。全追跡遮断や通信先の許可リストを保証するものではありません。

24.5MP切替、HEIF専用DCIM/Camera保存、高画質・質感美肌、原本保管、3:4位置と黒背景は変更していません。

**Managerのソース更新だけではULikeは変わりません。** 更新後に未改造ULike 5.6.2（740）の分割APK一式へ「高画質撮影・質感美肌・素材通信を復旧」（説明文v1.4.5）を適用し、生成したULikeをインストールしてください。旧パッチとの重ね適用はしないでください。今回、データ削除は必要条件ではありません。アンインストールが必要になった場合は、アプリ内の写真・下書き・設定等を事前に退避してください。

単独MPPはMorphe Desktop 1.13/1.16で元APKSへ適用・再構築成功。未署名のビルド試験です。前版との比較は33,174クラス・212,407メソッドで変更2メソッド、DEX/署名以外の4,070項目同一。61メソッド契約と受付ガード22条件をホストで検証しました。

統合MPPはv1.0.82から他アプリのコード・資源を保持。統合版単体のDesktop読み込みは前版と同じExtensionHook共有依存不足で失敗しており、依存関係は変更していません。端末Managerでの適用は未確認です。

実機の起動・フィルター一覧・素材取得・適用・通信観測は未確認です。端末登録停止はコード上確認した不備であり、今回の通信エラー原因の確定ではありません。

配布はコミット固定Raw URLを維持します。旧chatgpt.site配信元は更新しません。
