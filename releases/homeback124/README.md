# X の4タブから戻る終了・次回ホーム起動 v1.1.14

Hiro Morphe Patches v1.0.256 に含む修正版です。ホーム・検索・通知・チャットのトップ画面で Android の戻る操作を押すとタスクを終了し、「最近使ったアプリ」のカードを削除します。通常の次回起動はホームを表示するようにします。

## 対象と方針

- 検証対象は `com.twitter.android` / `12.19.1-release.0`。今回の提供 APK には他の Morphe パッチが入っていますが、OneBack の旧ランタイムはありません。
- 従来はホームか、X 自身が終了する場合だけを対象としていました。今回は X の `l1.goBack()` で子画面などの処理が済んだ後、ホームへ切り替える直前に終了処理を追加します。4つのタブは X 自身の選択中 URI で判定します。
- 個別の投稿・会話・入力など、下位画面での戻る操作とは区別します。
- 次回通常起動は、前回のタブを復元する処理より先に `page=twitter://timeline/home` を指定します。通知・リンクの明示的な移動先は保持します。
- 基準は公開済み総合版 v1.0.255。ULike v1.9.108、Instagram のリール終了処理、その他のパッチを保持します。

## 検証

新規24ケース／147アサーションで、4タブの終了・タスク削除・別プロセスを想定した次回ホーム起動、子画面の優先、ジェスチャーのキャンセルなどを確認します。今回の X APK に対する単体／総合 MPP の適用、終了と通常起動のフック、ランタイム全体、変更対象以外のコード・資源を監査し、`publication/local-apk-validation.json` と `evidence/` に記録します。

ホスト試験、合成 APK の全パッチ工程、コード・資源の保持検証を行い、2回の CI 再ビルドとローカルの MPP／QA が一致した場合だけ公開します。ユーザーの APK と検証用の出力 APK は公開ソースや CI に含めません。継承した Instagram の過去の証拠は X の検証には使いません。

Android 実機での画面操作、終了後のタスクカード、通常の次回起動は未確認です。公開・CI の完了は公開記録で別途確認します。

## 適用

成果物は単体 `OneBack_Exit_NoRecents_v1.1.14.mpp` と総合 `Hiro_Morphe_Patches_v1.0.256.mpp` です。Morphe Manager のソース更新だけではアプリ本体は変わらないため、X の「戻る1回で終了・履歴削除」を適用して更新インストールしてください。今回提供された OneBack 未適用の対応 APK と、正確に一致する OneBack v1.1.13 からの更新に対応します。それ以外の旧版・変更済みランタイムには、OneBack 未適用の同じ対応 APK を使用してください。
