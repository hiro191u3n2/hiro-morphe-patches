# 履歴クリア v1.13.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.13.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版と同じ署名で上書き更新できます。

## 再起動後の準備待ちを修正

解除や点灯の通知が実際の準備完了より早いと、その後の確認を予約せず止まる経路を修正しました。再起動番号の一時的な取得失敗も、実行済みと区別して再確認します。

準備済みの場合はすぐ実行します。準備途中の場合だけ100ms間隔・最大15秒で再確認し、画面内容のイベントでは期限を延長しません。期限後は定期確認を止め、次の点灯・解除などの通知を待ちます。設定OFF・消灯・手動実行・サービス終了では不要な確認を取り消します。ロック中に履歴操作はしません。

「再起動のたびに1回」の設定を維持し、同じ起動中の重複実行を防ぎます。アイコンと共通の消去処理と、画面起動が届かない場合の復帰処理も維持しています。

## 更新・設定・診断

上書き更新で既存設定を引き継げます。アイコン長押し→「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。有効なら次回以降の再起動・最初のロック解除後に自動実行します。

アイコン長押し→「診断」→「診断をコピー」で、現在の起動番号・実行済みの番号・接続／待機状態と直近の実行記録を確認できます。自動起動しなかった場合は、アイコンから手動消去する前に診断を確認すると、その時の状態を残せます。

模擬Android環境で実際のActivity・サービスのコードによる188項目、およびビルド・署名・マニフェストの検証を通過しました。設定と学習済みボタン情報を保持した連続3回の再起動、2回目だけ準備が遅れる条件、起動番号の一時的な取得失敗、再確認の期限と重複防止を確認しています。実機での自動起動・削除・表示時間は未検証です。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。
