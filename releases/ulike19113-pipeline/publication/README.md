# ULike v1.9.113 / Hiro Morphe Patches v1.0.274

公開済み単体v1.9.112と総合版v1.0.272を固定ハッシュで取得する。他アプリの変更はバイト単位で保持する。

## 変更範囲

案①は強ノイズGPUの追加候補profile6に限定し、近傍画素に共通する計算結果を再利用する。共有化の対象は `GX_POW2_EXACT78 && GX_TILE_WIDTH == 0 && GX_STRONG_MODE == 3` の経路のみ。通常の標準方式profile4を維持する。既存のAdaptive1998認定で完全な画素比較を通過し、データ転送を含むGPU処理全体が基準GPU経路より10%以上速い場合だけprofile6を採用する。

案②は前段nativeの `lag()` にある互いに独立したa/bのエネルギー合計のみを、AArch64 NEONの別々のbinary64レーンで計算する。各レーンの加算順序と倍精度、既存のスカラーフォールバックを維持する。ホスト／エミュレーションの計測変動を受け、入力再利用と平方値キャッシュの候補は除外した。画素結果を維持し、画質を下げる近似や演算精度の変更は採用しない。

v1.9.112の画質設定、入力・出力解像度、保存形式、撮影と保存の契約、作業領域の容量上限と所有権、取消を維持する。全画素一致2回と速度の採用条件を緩和しない。工程別計測、既存経路と候補の比較表示、過去履歴と今回結果の区別を維持し、診断記録だけで認定を復元しない。

## 再構築と検証

Temurin21.0.8+9、Android NDK r27c、Morphe Desktop1.16.0、Android35/D8の固定ハッシュ、Python3.12系とNumPy2.3.5を使用する。

1. `src/declare19101.py`で本番ヘルパー、全ソース、公開スクリプトを固定する。
2. `src/build19101.py`で単体・総合MPPを構築する。GPU1960とNR1955を今回のソースから再構築し、完全DEX、既存JNI ABI、他アプリ、ヘルパー参照を確認する。更新したnativeの2行のみをインストーラーへ反映し、残る10行とトランザクションの保護を維持する。GPU1960とNR1955以外のnative資産は公開版と同一バイトを継承する。
3. `src/host_audit19101.py`で現在のソースに対して既存の試験群と今回追加した回帰試験を新たに実行する。公開版の独立した基準との画素比較、実JNI/GLES、arm64エミュレーション、認定条件、取消・所有権、容量上限を確認する。更新したnativeは旧ELFとのバイト一致ではなく、変更範囲の制限と実行した差分比較で検証する。
4. `src/apply_original19101.py`で私有の未改造ULike5.6.2(740)APKSへ完成MPPを新たに適用し、FULL DEXとリソース再構築、arm64、元native保持、適用後メソッドを確認する。前版MPPの適用証拠は再利用しない。
5. `src/finalize19101.py`と`src/validate19101.py`で今回の実行証拠を配布MPPのSHA-256へ結び付ける。
6. `publication/publish19101.py --local-only`、`--preflight-only`の後に公開する。既存互換のためスクリプト名とschema名に19101が残るが、版値は1.9.113/1.0.274で照合する。

v1.9.113のAndroid実機での速度短縮は未確認。ホスト一致、エミュレーション、APK適用成功を実機での速度短縮・保存2,000ms以下達成の証拠にしない。

## 公開

検証済みdraft資産を公開し、固定commitの配布ファイルを再取得して一致確認後、main/devの両HEADを照合して直接子commitをatomic pushする。他の変更を保持する。既存release/tag/配布branchを上書きしない。
原本APKS、生成APK、個人写真・診断ログ、ツールチェーンは公開しない。ソース・テスト・匿名化した構造証拠のみ公開する。
