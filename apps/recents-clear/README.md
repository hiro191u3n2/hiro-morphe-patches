# 履歴クリア 1.18.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.18.0.apk)

自動起動の待機・再開の仕組みを修正しました。自動消去は1.12方式、アイコンからの消去は1.16方式を維持します。

- SystemUI由来のロック解除通知を受け取れるよう修正。
- 15秒で確認を打ち切らず、未実行なら間隔を空けて確認を継続。
- 点灯通知の欠落、ユーザー補助の割り込み、一時的な画面取得エラーから復帰。
- UI操作をまだ一度も試みていないと確認できる処理は、実行済み記録を戻して再開。
- 同じ再起動での重複実行を防止。設定OFF・サービス終了で待機を解除。

同じ署名で上書き更新できます。「再起動のたびに1回実行」をONのまま再起動し、ロックを解除してください。設定と診断はアイコン長押しから開けます。

235項目の模擬テストを通過。保存済みの旧1.17コードと同じ条件で比較し、旧版が止まった10条件と、3回連続の遅い起動からの復帰を確認しました。実機・エミュレーターの再起動検証は未実施です。今回の端末でどの条件が起きたかは未確定です。

Android10以降／ユーザー補助方式。Shizuku・root不要。常駐アプリの強制終了、クイック設定タイル、画面を覆う処理はありません。履歴画面自体は開きます。ユーザー補助が未接続の場合や、UI操作を試みた後の失敗まで成功を保証するものではありません。
