# 履歴クリア v1.12.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.12.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版へ同じ署名で上書き更新できます。

## 再起動後の自動実行が止まる問題を修正

v1.11.0では、画面が起動して消去処理に進む前に「今回の再起動では実行済み」と記録していました。画面起動が届かない場合や、その間にサービスが終了した場合、消去が一度も動かなくなる経路を修正しました。

通常は引き続きアイコンと同じアプリの入口から消去します。画面起動が拒否された場合や250ms以内に受け渡されない場合には、ユーザー補助サービスから共通の消去処理に復帰します。通常の起動には待ち時間を加えません。遅れて画面が起動しても、消去を重複実行しません。

実行済みの保存は消去開始の直前へ移しました。消去開始前のロック・消灯では操作せず、再び使用可能になるまで待ちます。開始後は従来どおり再起動ごとに最大1回の試行です。

## 更新・設定・診断

上書き更新で既存設定を引き継げます。アイコン長押し→「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。有効な場合は次回の再起動・最初のロック解除後に自動実行します。「診断」では、自動実行とアイコン実行それぞれの直近の記録と、起動時の復帰経路を確認・コピーできます。

実際のActivity・サービスのコードと模擬Android環境による173項目、およびビルド・署名・マニフェストの検証を通過しました。旧v1.11の実際のコードと比較し、起動要求が届かない・起動が例外で拒否される・受け渡し前にサービスが再接続する3条件で、消去が1回だけ実行されることを確認しました。実機での自動起動・削除・表示時間は未検証です。端末起動直後の負荷やOSの画面遷移により表示時間が異なる場合があります。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。
