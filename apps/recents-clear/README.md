# 履歴クリア v1.11.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.11.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版へ同じ署名で上書き更新できます。

## 自動起動をアイコンと同じ起動・消去処理へ統一

再起動後の自動実行も、アイコンを押した時と同じアプリの入口を起動します。アプリ自身の画面を閉じてから、共通の履歴消去処理へ進みます。自動起動専用の先読みと、サービスから直接消去を始める経路を廃止しました。

「再起動のたびに1回実行」の設定を維持し、最初のロック解除後に一度だけ起動します。設定OFF・画面ロック・消灯時の自動操作中止と、重複した起動の防止も維持しています。画面の起動に失敗した場合は、直接消去へ戻らず診断に失敗を記録します。

1.10.0で修正した通常取得への切り替え、操作拒否時だけの再確認を共通で使用します。成功したクリックは繰り返しません。

## 更新・設定・診断

上書き更新で既存設定を引き継げます。アイコン長押し→「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。「診断」では、自動実行とアイコン実行それぞれの直近の記録を確認・コピーできます。

実際のActivityとサービスのコードを動かすホストテスト162項目（起動・ライフサイクル23項目を含む）、およびビルド・署名・マニフェストで検証しました。実機での自動起動・削除・表示時間は未検証です。同じ入口と消去処理を通っても、端末起動直後の負荷やOSの画面遷移により表示時間が異なる場合があります。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。
