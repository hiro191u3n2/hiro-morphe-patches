Berry Browser 3.83.93.1対応修正 v1.3.1 / Hiro Morphe Patches v1.0.272

【修正内容】
前版ではMorphe上の対応表示を全バージョンに変更しても、既存パッチの依存処理に3.83.74専用の版チェックが残っていました。このためBerry 3.83.93.1に「ダブルタップから指を離さず片手ズーム」を適用すると停止していました。

今回は適用処理を修正し、3.83.93.1と従来3.83.74の対象コードを確認してから変更します。「プレビュー作成を後回しにして表示中タブを優先」「共有先ブラウザの表示を個別に切替」「ダブルタップから指を離さず片手ズーム」の既存3項目が対象です。対象メソッド・命令・リソース等が一致しない入力は適用を止めます。Managerでの全バージョン表示は維持しますが、将来の全バージョンに対する動作保証ではありません。

MPP内の4つの拡張データは前版とバイト単位で一致します。共有先切替は、APKに組み込む補助クラスのアプリ参照を対象版の構造に合わせて変更します。MessageQueueの実装と他アプリのパッチは保持します。MPPにはAndroid用DEXとManagerのJVM実行用クラスを収録します。

【検証範囲】
保存済みの3.83.74と、公開配布版から取得した3.83.93.1（383931）の元APKを検証しました。入力APKのハッシュ、配布MPPのハッシュ、適用試験結果を結び付けて記録しています。新しいAPKはユーザー端末から取得したファイルそのものではありません。
3.83.74と3.83.93.1の最低API32版について、単独・総合MPPをMorphe Desktop 1.16.0および1.19.0-dev.19で適用し、APKを再構築する8通りの試験がすべて成功しました。いずれもBerryの4項目すべてを選択しています。
3.83.93.1は最低API32・29・26の3バリアントを確認しました。3種とも配布元の同一署名で、アプリのclasses.dexはバイト単位で一致しています。最低API29・26版はmanifestとresources.arscがAPI32版と異なるため、総合MPPとMorphe Desktop 1.19.0-dev.19で4項目すべての適用・APK再構築を各1回追加検証し、両方とも成功しました。合計10回の実APK適用・再構築が成功し、各入力のminSdkVersionも保持されました。
公式Morphe Manager 2.0.0-dev.16のホストでは、配布する総合MPPからBerryの4項目が選択され、全バージョン対応のメタデータが保持されていることを確認しました。
公開CIは同じMPPを2回再ビルドして一致を確認し、公式Managerホストでのパッチ選択、合成APKによる適用・再構築試験、保存済みの実APK適用証拠との一致を確認します。私有APKや元APKを公開CIに含めません。正確な試験対象と実行方式は同梱QAに記録します。
APKへの適用と静的な構造確認はAndroid実機での操作確認とは異なります。実機のスクロール、共有先の操作、片手ズーム、保存、起動時間は未確認です。

【MessageQueueについて】
前版のAndroid 17向けMessageQueue設定・診断処理をそのまま保持します。確認した3.83.74と3.83.93.1はいずれも元からtargetSdkVersionが37です。この修正による新たなロックフリー化や高速化を測定したものではありません。Android 16以前への移植機能もありません。

【導入】
Morphe ManagerのソースをHiro Morphe Patches v1.0.272へ更新し、Berry Browserの元APK/APKSに必要なパッチを再適用してください。従来と同じ署名キーで更新インストールしてください。
パッチソースの更新だけではインストール済みBerryに反映されません。前回適用に失敗した処理を、更新後のソースでやり直してください。
