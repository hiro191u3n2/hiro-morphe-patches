# Instagram リールの戻る終了・履歴削除 v1.1.10

Hiro Morphe Patches v1.0.249。配信中の総合版 v1.0.247 を基に、Instagram の戻る操作を修正する版です。

## 動作

- 通常のリール画面で Android の戻るボタン／戻るジェスチャーを確定すると、タスクを終了し「最近使ったアプリ」からカードを削除します。
- コメント欄、キーボード、別のパネルが開いている場合は、その画面を閉じる操作を優先します。同じ戻る操作で続けてアプリを終了させません。
- リールの上に開いたプロフィールなど、別画面での戻る操作はアプリ本来の画面戻りを保ちます。

## 修正の根拠

Instagram 447.0.0.55.81 の提供済み APK を解析したところ、MainActivity の戻る処理には、リール本体の `onBackPressed()Z` へ進む前に AndroidX の戻る処理を呼んで終了する分岐があります。前版のリール本体だけへの追加フックではこの分岐を捕捉できません。今回、MainActivity のネイティブなポップアップ／ダイアログ処理の後にも、表示中のリールを確認して終了するフックを追加します。

現在選択されているフラグメントは、実 APK で確認したアクセサーから取得します。リール内のポップアップやパネルについてもネイティブの状態を読み取り、画面上の名前だけでは見つからない表示を含めて、閉じる操作を優先します。

また、前版の画面判定では、リールの背後に残った非アクティブなフラグメント内のコメント表示が、開いているコメント欄と判定される条件がありました。表示順、ライフサイクル、可視範囲を確認し、リールに完全に覆われた背後の画面を区別します。前面のコメント欄や判定できないパネルは引き続き終了を抑止します。

これらは APK のコードと再現用の模擬画面で確認した条件です。利用端末で発生した瞬間の画面階層は取得していないため、端末上の原因確定や実動作の解消を示すものではありません。

## 検証

既存のホスト試験、今回の回帰試験、提供済み APK の DEX への新フック挿入と元処理の保持、既存ランタイム呼び出しとの互換性、単体版・総合版の Morphe 合成 APK 適用を検証します。ローカルの固定 SDK ビルドと、独立した 2 回の公開 CI ビルドで MPP と QA が一致した場合だけ配信を更新します。具体的な試験結果とハッシュは同梱 QA に収録します。

提供済み APK は既にパッチ適用済みです。未改造の元 APK への適用と Android 実機での画面操作・終了・履歴削除は未確認です。

## 適用方法

Morphe Manager のソースを総合版 v1.0.249 に更新し、Instagram の未改造の元 APK に「戻る1回で終了・履歴削除」を含めて再パッチして、更新インストールしてください。ソースの更新だけでは、インストール済みの Instagram の処理は更新されません。

単体版は OneBack Exit No Recents v1.1.10 です。ULike v1.9.105 を含む、ほかのパッチの収録内容を保持します。今回の更新通知は Instagram を対象とします。
