OneBack Exit No Recents v1.1.14 / Hiro Morphe Patches v1.0.256

X（旧 Twitter）のホーム・検索・通知・チャットのトップ画面で Android の戻る操作を押したときに終了し、「最近使ったアプリ」のカードも削除する修正です。通常の次回起動はホームを表示するようにします。
X 自身の Back 処理でメニュー・入力・子画面の処理が済んだ後、ホームへ切り替える直前に終了処理を追加しました。選択中の4タブは X 自身の URI で判定します。個別の会話などは先に戻り、戻るジェスチャーのキャンセルでは終了しません。次回通常起動では最後のタブの復元より先にホームを指定し、通知・リンクの明示的な移動先は保持します。

検証対象は提供された X 12.19.1-release.0（com.twitter.android）です。他の Morphe パッチ適用済み・OneBack 未適用の APK に、単体・総合の MPP をそれぞれ適用しました。241,847 クラス・893,509 メソッドの元の処理を照合し、予定した変更とランタイム75クラスの一致を確認しています。両出力 APK の全 ZIP entry 内容は一致し、資源テーブルの復号内容の差分はありません。新規24ケース／147アサーションで4タブの終了・次回ホーム起動などを検証しました。

基準は総合版 v1.0.255 です。ULike v1.9.108、Instagram のリール戻る修正を含む他アプリのパッチと資源を保持します。Morphe Manager の更新対象は X／Twitter とし、過去の変更履歴と ULike の公開ポリシーを維持します。
公開前には本番 Android SDK でのコンパイル、既存・追加のホスト試験、DEX 構造と保持検証、5パッケージ×単体／総合版の合成 APK 適用、提供された X APK への適用監査を行います。ローカルで固定した MPP／QA と独立した2回の CI ビルドが完全一致した場合だけ公開します。
ユーザーの APK と検証用の出力 APK 本体は公開ソースや CI に含めません。最終の試験結果とハッシュは QA と今回の検証記録に保存します。

Android 実機での画面操作・終了・タスクカードの削除・次回起動は未確認です。

Morphe Manager のソース更新後、X の「戻る1回で終了・履歴削除」を適用し、従来と同じ署名キーで更新インストールしてください。ソースの更新だけではインストール済み X の処理は変わりません。OneBack 未適用の対応 APK と、正確に一致する OneBack v1.1.13 からの更新に対応します。それ以外の旧版・変更済みランタイムには、OneBack 未適用の同じ対応 APK を使用してください。
削除対象は Android の「最近使ったアプリ」のタスクカードです。X 内の検索・閲覧履歴やサーバー上のデータは削除しません。
