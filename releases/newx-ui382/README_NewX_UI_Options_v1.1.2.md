# NewX UI Options v1.1.2 / Hiro Morphe Patches v1.0.382

v381適用後にスクロールがさらに重くなったとの報告を受け、v381の表示回数整形の変更を取り下げました。**v380のコードへ戻す復元版**です。Managerで更新として受け取れるよう、配布番号をv382、UI設定の番号をv1.1.2にしています。

統合MPPはv380、UI設定MPPはv1.1.0と、`META-INF/MANIFEST.MF`を除くすべてのコード・リソースが一致します。新たな最適化は加えていません。Android実機での復元後の体感は未確認です。

## 導入

1. Morphe ManagerでHiro Morphe Patchesを **v1.0.382** に更新します。
2. 未改造の **X 12.43.0-prod.01のAPKM一式** を選びます。
3. **Piko 3.12.0-dev.1またはdev.2のNewX用項目** と、Hiroの **「NewX: 表示設定を追加（おすすめ・上下固定・120Hz・表示回数）」** を選択します。
4. パッチを適用し、生成したAPKをインストールします。

ソース更新だけではインストール済みXは戻りません。単独MPPもPiko NewXと一緒に使います。統合MPPと単独MPPで同じ追加機能を重複選択する必要はありません。

## 継続する設定

設定場所は **X内のPiko設定 → Hiroの表示設定** です。4項目は個別に切り替えられ、名前・保存キー・保存済みの値を保持します。新規導入時の初期値はすべてオンです。

| 設定 | 動作 |
|---|---|
| 表示回数を省略せず表示 | 元の数値から3,000のような全桁表記へ変更します。いいね・返信・リポスト数は変更しません。 |
| チャットのおすすめを非表示 | おすすめ見出し・連絡先同期案内・推薦ユーザー一覧を隠します。既存の会話と検索は保持します。 |
| 上下のタブを固定 | スクロール時に上部バーと下部タブを表示したままにします。 |
| 120Hzを優先 | 同じ解像度の対応モードを優先して、Xの画面に120Hzを要求します。 |

表示回数・チャット・上下固定の変更後はXを再起動してください。120Hzの変更は設定画面からXへ戻った際に反映されます。120HzはOS側の制限を受けるアプリからの優先要求です。

## 検証範囲

v382のdev.2構成を改めて適用・APK再構築し、復元ペイロードとv380の一致を検証しました。結果と配布ファイルのSHA-256は `QA_NewX_UI_Options_v1.1.2.json` と `QA_build382.json` に記録しています。

dev.1・dev.2＋Clone・単独UI構成の適用根拠は、コードが一致するv380時点の4構成の検証記録です。v382で4構成すべてを再試験したという意味ではありません。元の記録は公開済み `QA_NewX_UI_Options_v1.1.0.json` と、ソース内の `verification/baseline380-validation.json` に保持しています。実機の最終表示・操作・スクロール感・120Hz到達は未確認です。

`NewX_UI_Options_v1.1.2_sources_and_QA.zip` はv380の実装ソース、復元スクリプト、検証記録を収録します。v381の性能レビュー・ベンチマーク、添付画像・動画、元APKと展開物・解析ダンプ、コンパイラは含めません。機能フォルダーにあるホストQAは復元元v380時点の記録です。

## 再作成

正確な入力名・取得元・SHA-256は `toolchain.json` を参照してください。Python 3.12を使い、公開済みv380統合MPPとUI v1.1.0を用意します。

```bash
python3 rollback.py
python3 verify_packages.py --case dev2
```

`rollback.py` は既存ZIPレコードを保持し、マニフェストだけをv382／v1.1.2へ更新します。`integrate.py` も同じ復元処理を呼びます。新しいコンパイル結果で元コードを置き換えません。`build.py` はv380実装の参考ビルド用であり、公開v382を作る手順は `rollback.py` です。APK適用検証にはJava 21、Morphe Desktop 2.2.0／Patcher 2.4.0と未改造のX APKMが必要です。
