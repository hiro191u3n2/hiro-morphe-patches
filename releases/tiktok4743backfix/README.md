# Hiro TikTok 47.4.3 戻る修正 v4.2.0

**単体 v4.2.0 / 総合 v1.0.282 / OneBack v1.1.22。** TikTok 47.4.3 の「戻る1回で終了・履歴削除」を修正し、47.5.3 を Hiro 製 TikTok 8項目の対応対象から削除します。

- [TikTok_47.4.3_Hiro_v4.2.0.mpp](https://github.com/hiro191u3n2/hiro-morphe-patches/releases/download/tiktok-v4.2.0/TikTok_47.4.3_Hiro_v4.2.0.mpp)
- [Hiro_Morphe_Patches_v1.0.282.mpp](https://github.com/hiro191u3n2/hiro-morphe-patches/releases/download/tiktok-v4.2.0/Hiro_Morphe_Patches_v1.0.282.mpp)

## 原因と修正

前版は 47.4.3 のホーム移動 API を認識できても、終了を決める段階で画面上のホーム表示などに依存していました。表示文字が取得できない画面や、保持された画面状態では、ホームで戻る操作をしても終了処理へ進めない経路が残っていました。ホーム移動 API の名前や呼び出し先が正しいだけでは、この問題を検出できません。

修正版は、TikTok 本来の一時画面の判定を通過した後の戻る境界へ接続します。表示文字に依存する終了判断を除き、同じ戻る操作の再入とキーの繰り返しも処理します。

| 操作開始時の状態 | 意図する動作 |
| --- | --- |
| ホームの通常画面 | 1回の戻るで終了し、最近使ったアプリから削除 |
| プロフィールなどホーム以外 | ホームへ移動。同じ操作では終了せず、次の戻るで終了 |
| コメント・一時画面・入力中の画面 | TikTok 本来の戻る処理で閉じる。閉じる操作を終了と重ねない |
| キーの繰り返し・同じ操作の再入 | ひとつの戻る操作を重複処理しない |

実装とホストの回帰検査は `src/oneback` にあります。Android 実機で操作した証拠は含みません。

## 47.5.3 の除外範囲

以下8項目の対応メタデータと実行時検査から 47.5.3 を外します。匿名の依存パッチも検査し、互換性の強制無視で選択しても拒否します。日本語化も旧版の全バージョン許可を撤去します。

| 項目 | この版の対象 |
| --- | --- |
| 怪しい通信だけ遮断 | `com.zhiliaoapp.musically` 47.4.3 |
| フィード左下の文字・再投稿欄を非表示 | 同上 |
| CapCut・エフェクト等の誘導枠を完全遮断 | 同上 |
| 動画のシークバーを常時表示 | 同上 |
| シーク中のプレビューサムネイルを表示 | 同上 |
| フォロー中のストーリーズ件数を非表示 | 同上 |
| 戻る1回で終了・履歴削除 | 47.4.3 を修正。既存の 46.2.3 と他アプリの経路を保持 |
| TikTok設定を日本語化 | `com.zhiliaoapp.musically` 47.4.3。上流 `Settings` が必要 |

Morphe は extension を入れてからそのパッチの execute block を呼ぶため、native UI と日本語化では、extension を持たない先行依存が対象を検査します。除外した版に runtime を挿入してから拒否する順序にしません。

内部の `tiktok4753` namespace と extension ファイル名は既存 ABI のため維持します。この名称は対応版の宣言ではありません。公開済みの旧タグ・旧リリースの履歴は改変しません。

## 適用方法

1. Hiro ソースを総合 **1.0.282** に更新するか、上記の単体 MPP を読み込みます。通常はどちらか一方を使います。
2. パッチ未適用の **TikTok 47.4.3 / `com.zhiliaoapp.musically`** の完全な APK を選びます。
3. 「戻る1回で終了・履歴削除」と必要な項目を選択します。native 6項目の末尾表記は **`（TikTok 47.4.3）`** です。
4. 日本語化を使う場合は、[icysymmetra の v0.9.0-dev.1](https://github.com/icysymmetra/tiktok-patches-for-morphe/releases/tag/v0.9.0-dev.1) の **`Settings`** と Hiro の **`TikTok設定を日本語化`** を同時に選びます。端末またはアプリの言語を日本語にします。
5. 適用後、選択した全項目の成功を確認します。

## 実 APK の検証と公開条件

署名確認済みの原本を使い、以下を別々の意味で検証します。47.5.3 は拒否検査用の入力です。

| 入力・構成 | 必須の結果 |
| --- | --- |
| 47.4.3 ＋ 単体の native 6項目と OneBack | 7項目の適用・再構築・出力監査が成功 |
| 47.4.3 ＋ 総合の Hiro 8項目と上流 Settings | 9項目の適用・再構築・出力監査が成功 |
| 47.5.3 ＋ 単体の Hiro 8項目を強制選択 | 全項目が明示的な版検査で拒否され、出力 APK なし |
| 47.5.3 ＋ 総合の Hiro 8項目を強制選択 | 同上 |

加えて、上流全136項目と、ユーザーの画像で選択されていた Hiro 3項目（通信保護・OneBack・日本語化）の計139項目を、総合 MPP・3GBヒープ・既定オプション・互換性の強制無視なしで検査します。139項目の全適用・全工程成功と、出力の OneBack / Settings / 日本語化監査が公開条件です。上流120項目の内訳は不明のため、正確なユーザー構成の再現や全139機能の実機確認は主張しません。

47.4.3 の検証では互換性判定を強制無視しません。出力の native 呼び出し・分岐、OneBack の接続、privacy、クラス・メンバーの保持、Settings と日本語化を監査します。47.5.3 は各MPPの8項目を1項目ずつ強制選択し、失敗を無視して続行しない計16回の検査です。失敗を成功件数へ含めず、拒否専用の schema と証拠で管理します。

| 原本の識別情報 | 47.4.3：適用対象 | 47.5.3：拒否検査だけ |
| --- | --- | --- |
| versionCode | `2024704030` | `2024705030` |
| bytes | `474921201` | `476733983` |
| SHA-256 | `af7cbe2b00d33ff1339730f6abb8ed7e387a83b27ff2b16748b8f41e6fc87e0b` | `6670ca3f93bfea379658cad3c27f05d3a380b23a0d82569cce684b7453e8ff3e` |

両原本の署名証明書 SHA-256 は `9041803e91bcb814b4b4399fb5c85a91640b755e5e8ba76813814bf4cf2ab5ba` です。

さらに、画面ラベルに依存しない戻る処理のホスト回帰、廃止した 47.5.3 API の認識拒否、Morphe 3 SDK での loader と実行検査を必須とします。2回のローカルビルドと2回の CI ビルドが、上記の実 APK 検証に使った MPP と QA をバイト単位で再現した場合だけ公開します。

統合版の無関係な loader、runtime、リソースと ULike の運用設定を保持します。日本語化は loader の対象版検査を変更し、2,181項目の辞書 runtime を基準版のまま保持します。元 APK と生成 APK は公開しません。

**Android 17 / Samsung SM-S948Q を含む実機の表示・操作・通信は未確認です。** 出力監査とホストの回帰検査は、実機操作の代わりを意味しません。任意の上流選択やユーザーの個別構成すべてを再現したとは主張しません。前版 v4.1.0 の全144項目の結果を、この版の結果として転用しません。
