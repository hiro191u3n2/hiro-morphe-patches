ULike v1.9.47／総合版 v1.0.180 の公開手順

この公開処理は ULike v1.9.45／総合版 v1.0.178 の固定チェックサムを基準にします。main・dev のどちらかの公開版、ダウンロード先、ULike_ACTIVE.json または HEAD が進んだ場合は停止し、別の改造を上書きしません。

manifest.json は実際に検証した単体・総合 MPP、QA、ソース ZIP、説明、チェックサムの 6 点のサイズと SHA256 を固定します。時間表示の回帰テスト、品質処理の保持、元 APKS への適用検証が済んだ成果物だけを公開します。CI は固定した JDK 21.0.8 と Morphe／Android／D8 でソースを再ビルドし、元 APKS 適用検証が識別した MPP と一致したことを確認します。ネイティブライブラリは v1.9.45 と同一で、NDK 再ビルドは行いません。元 APKS、再構築 APK、写真、署名鍵は公開成果物・CI に含めません。

公開前のローカル検証:

    python3 releases/ulike1947-diagnostics/publication/publish1947.py \
      --dist DIST --repo . --expected releases/ulike1947-diagnostics/manifest.json \
      --baseline INPUT/Hiro_Morphe_Patches_v1.0.178.mpp \
      --standalone-baseline INPUT/ULike_HQ_Texture_Online_v1.9.45.mpp --local-only

GitHub 上の確認だけを行う場合は --preflight-only を指定します。公開時は GitHub Release の各ファイルをダウンロードして SHA256 を再確認し、固定コミットの MPP ダウンロード先を作成します。main と dev の Manager 配信情報・ULike の更新履歴・ULike_ACTIVE.json を同時更新し、公開後のダウンロード結果も確認します。

設定画面には撮影ごとの合成、ノイズ除去、補正、圧縮、保存の経過時間を表示します。一部の工程は並行・入れ子で実行されるため、各工程の合計は「全体経過」と一致しません。「補正」は保存画像の追加処理・変形・リサイズ・ウォーターマーク等です。ULike標準のネイティブ美顔処理と撮影待機は工程別計測の対象外です。「圧縮」はエンコーダー開始から終了までを指し、準備・初期化を含みません。未計測工程があるため、この5項目だけで全体の待ち時間を説明できるとは限りません。「全体経過」は計測開始から処理終了までを指し、厳密なシャッターボタンから保存完了までの時間ではありません。未実行・未完了・失敗を実測 0 ms と扱わず、以前保存された旧「追加処理」記録を現在の測定結果として表示しません。

画質計算・解像度・保存形式・圧縮設定は維持します。Galaxy 実機での速度、表示と撮影動作は未確認です。Morphe Manager でソースを更新した後、元 ULike 5.6.2（740）へパッチを再適用し、作成されたアプリを更新インストールする必要があります。パッチソース更新だけではインストール済み ULike は変わりません。
