# ULike v1.9.35 / 総合 v1.0.168

ULike v1.9.34 を基準に S2・S3・S4・S5・S6・S7・S8・S16 と T1 を実装する再現ビルドです。画像の値、解像度、撮影・合成枚数、補正強度、保存品質を維持し、重複処理・転送・メモリー生成を減らします。T1 は保存と次の撮影受付を分離する処理です。

`src/build1935.py` は固定した元 MPP と Java ツール、arm64 ネイティブビルドを使用します。`src/validate1935.py` は単体・総合 MPP を実際の未改造 APKS に適用して再構築・DEX型解析・ネイティブ組込みを検証します。`src/finalize1935.py` はその検証済みバイナリと再現ビルドの SHA-256 一致を要求します。

公開ワークフローは両 Manager フィードと最新の承認済み ULike 系統を確認し、他アプリを保持した総合版を公開します。実機画質・撮影・保存時間の測定は行っていません。詳細は RELEASE_NOTES.txt と QA JSON を参照してください。

撤回済み10bit経路や削除済み診断表示・原本保管機能は復活させません。元APKS、再構築APK、ユーザー写真、署名鍵は公開物に含めません。
