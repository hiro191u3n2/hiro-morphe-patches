# Berry Browser 構造自動検出 v1.4.0

Hiro Morphe Patches v1.0.331に収録するBerry Browser用パッチです。固定されたアプリのクラス名・メンバー名への依存を減らし、WebViewやAndroid APIとの接続関係から適用先を自動検出します。Morphe Managerの全バージョン表示は維持します。

パッチ先を一意に確定できた場合に実際の処理を適用します。実装の大きな変更や曖昧な候補まで無条件に成功扱いするものではありません。

BFCache完了判定のフックは、対応するWebView本体を照合するよう修正します。拡張ファイルのバイト列は保持しますが、この修正後の表示動作は実機未検証です。

未改造3.83.74と、元APKのクラス・メンバー名を変えた検証入力で適用を確認します。後者は自動検出のための人工的な入力であり、実際の3.84.12ではありません。3.84.12そのものとAndroid実機の動作は未検証です。最終的に完了した試験と候補ファイルのSHA-256は`QA_apply331.json`に記録します。

`src/`はパッチ定義、`build/`は再現可能なビルドとDEX保持検証、`qa/`は試験用コード、`publication/`は公開処理です。元APK・署名キー・ユーザーデータは公開物に含めません。MessageQueue実装、既存の5つの拡張ファイル、他アプリのパッチは保持します。

公開ワークフローは2回のビルド一致、凍結済みファイルのハッシュ一致、実APKと名前変更入力の適用証跡を確認した後にリリースを作成し、Managerのmain/dev更新情報を一括更新します。
