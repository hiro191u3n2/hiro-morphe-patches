# ULike v1.9.41 / Hiro Morphe Patches v1.0.174

ULike v1.9.38／総合版 v1.0.171 を基準に、採用されたノイズ対策4項目と撮影受付の表示を改造したリリースです。

- 平坦部を優先して残留ノイズを減らし、輪郭・文字や周期的な細部を保護します。
- 細かな粒と少し大きな粒を異なる範囲で処理します。
- ノイズ量を見てシャープ処理を抑え、粒の再強調を減らします。
- 最終保存経路を点検し、回転・拡縮後の画像座標にノイズ分布を合わせます。既存の保存フックと二重処理防止を保持します。
- 撮影受付時に白枠・濃い縁・薄い暗転を約320ms表示します。表示は操作を遮らず、保存画像へ入りません。

保存解像度・形式・圧縮設定・美顔と色処理・起動復旧・画面配置・レンズ処理・撮影受付・保存キューは v1.9.38 を引き継ぎます。他アプリのリソースは v1.0.171 と同一です。

## 検証と限界

固定した JDK 21.0.8 とツール群でビルドし、ホスト回帰テスト20,891アサーションを確認します。単体・総合版の両方を未改造ULike5.6.2（740）の完全なAPKSへ適用し、分割APK結合・再構築・arm64-v8a出力・DEX整合性・型解析・実APKのメソッド整合性を検証します。実行結果と適用したMPPのSHA-256は `evidence/validation.json`、配布物の検証結果は `QA_ULike_v1.9.41.json` に記録します。

実機の画質・撮影表示・保存時間は未確認です。合成画像による試験は、細かな髪・低コントラストの布や壁紙の質感を完全に保持する保証にはなりません。非sRGB・F16・ゲインマップを含む画像の既存の代替経路は保持しますが、実機での画像形式別の適用は未確認です。

## 適用

Morphe Managerでパッチソースを更新し、未改造ULike5.6.2（740）へ「高画質撮影・質感美肌・素材通信を復旧」を再適用して、作成したアプリを更新インストールしてください。ソース更新だけではインストール済みアプリは変わりません。単体と総合はどちらか一方を使用します。アプリデータ削除は不要です。

## 再現用資料

`src/build1941.py` が固定した v1.9.38／v1.0.171 のMPPとツール群から新しいMPPを生成し、`src/validate1941.py` が元APKSへの適用を検証します。`src/finalize1941.py` は配布MPPと適用試験のハッシュを照合して、検証結果とソースを梱包します。`manifest.json` が配布物、変更範囲、実行結果を固定し、`publication/` のワークフローが再ビルド・照合後に公開します。

元APKS、再構築APK、利用者の写真、署名鍵は配布物に含めません。
