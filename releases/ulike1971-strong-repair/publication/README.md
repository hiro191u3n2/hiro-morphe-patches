ULike v1.9.71 / Hiro Morphe Patches v1.0.204

公開済み .70 / .203 を基準に、強ノイズGPUの再照合経路と追加分のメモリ予約、失敗段階の診断を修正します。画質照合・CPU退避と、既存の画素計算、GPUシェーダー、カメラ復旧、保存、他アプリを維持します。

ソースを固定して5つのJavaファミリーとGPUネイティブ1個だけを再構築します。ほかの11ネイティブ、重要な画素処理、すべての非対象クラス、ネイティブ登録処理の逆変換、単体・総合版の一致、制御したGPU境界と実際のネイティブ管理処理の検証を公開条件にします。CI成果物のMPPはローカル検証済みのSHAと完全一致する必要があります。

Galaxy実機の失敗はホストで再現できておらず、原因特定や800msへの復帰は未検証です。元APKSへの今回の適用も未実施です。初回の画質確認ではCPU照合の時間がかかり、GPU失敗時は継承CPU処理へ退避します。

「直近の撮影・工程別処理時間」の「処理時間・GPU使用状況を表示」で区間数と候補試行数を確認できます。ログ共有・Download/ULikeへの診断ZIP保存を維持します。ログへ写真や画像配列を含めません。

main/devのフィードを同時に更新し、公開済みファイル・SHA・診断資料・配布先を照合します。元アプリ、APK、写真、鍵、ユーザーのログは公開しません。
