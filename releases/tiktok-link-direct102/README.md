# Hiro TikTok Link Direct v1.0.2

共有動画リンクの既存パッチを更新する版です。対象は **global TikTok 47.4.3 / `com.zhiliaoapp.musically` / versionCode `2024704030`** です。

項目名は前版と同じ **「共有リンクの小窓を省略して動画を直接再生（TikTok 47.4.3）」** です。同じ項目を更新し、重複する別項目は追加しません。

v1.0.0 の小窓省略を維持し、対象の通常共有動画リンクでは、おすすめフィードを先に開く経路を外して、TikTok 本来の動画詳細画面へ進めます。短縮リンクの解決前にホームを先行起動する処理も省略します。

v1.0.2 では、共有リンクから開いた対象動画で戻る操作をしたときの終了処理を追加します。アプリ本来の戻る判定を優先し、リンク動画の表示状態と終了条件が確認できた場合に、TikTok 自身の画面・タスクとプロセスを終了します。判定を終えていない状態やコメント欄などの操作を、一律にアプリ終了へ置き換えません。

同じ共有リンク判定を通って作られた動画画面では、表示時の横移動アニメーションも省略します。動画を取得する処理や再生開始を待つ処理は引き続き TikTok 本来のものです。

対象にするのは、TikTok が解決した通常の単一動画 URI（`aweme/detail/動画ID`、または `detail` / `item` / `musical` の `id` 指定）に、共有リンクの印である `utm_campaign=client_share` が付く場合です。後者はパスが空または `/` で、URI 自体の `id` が先頭に0を付けない正の1～20桁の数字の場合に限ります。共有リンクの印は URI 自体と入れ子の `params_url` を確認します。通知・type40・コメント向けの既存判定を先に通し、グループ招待・検索詳細・ドラマ・フィード挿入禁止・タブ指定が付いたリンクは元の処理を使います。

リンク先の解決、元の URL と動画 ID、ログインなどの確認、動画取得と再生には TikTok 本来の処理を使います。URL 解決と動画データの取得には通信時間がかかるため、待ち時間がなくなる保証はありません。Android 実機での表示順、再生開始時間やタップ操作は未確認です。

## 配布物

- `TikTok_LinkDirect_v1.0.2.mpp`: 更新した共有リンク項目だけを収録。
- `Hiro_Morphe_Patches_v1.0.310.mpp`: 公開済み総合 v1.0.309 の共有リンク項目を更新。

Morphe Manager で総合ソースを更新し、未改造の元 APK に同じ共有リンク項目を含めて再パッチしてください。以前と同じ署名設定で更新インストールします。ソースの更新だけではインストール済みアプリは変更されません。

## 保持する範囲

前版の共有リンクローダー5クラスを、既知の名前と SHA-256 に一致した場合だけ置き換えます。共有リンク以外の DEX ローダー定義、JVM クラス、既存のランタイム、リソースと旧ライセンス通知を保持します。新しい版の通知は別パスへ追加します。

既存のTikTok機能、OneBack、日本語化や他アプリの実装を再コンパイルして差し替えません。総合版の名前付きパッチ数が増えず、同じ共有リンク項目が1個だけ存在することを実際の Morphe ローダーで検査します。

共有リンク専用の `extensions/hiro_tiktok_link_direct.mpe` を追加します。実装の名前空間は `app.hiro.tiktoklink.runtime` に限定し、既存の OneBack v1.1.23 のローダーとランタイムはそのまま保持します。追加する処理は共有リンクの画面遷移と戻る終了を担当し、動画取得やネットワーク処理の待ち時間は元の TikTok の処理に従います。

## 検証と対応ソース

元APKへの適用と出力コードの監査は、配布するMPPそのもののSHA-256に結び付けます。小窓省略・動画遷移・戻る終了の3監査と、実際にコンパイルした専用ランタイムのホストテストを必須にします。

元APKへの実適用は、基準v1.0.309のOneBackのみ、単体の共有リンク項目のみ、総合の共有リンク項目のみ、総合の共有リンク項目とOneBack併用の4通りです。併用出力は基準OneBackのみの出力と比較し、既存の戻る処理を保持することも確認します。独立した2ビルドと、凍結済みのローカル出力を再現するCIビルドを使用します。これらはAndroid実機の操作確認ではありません。

詳細は [publication/BUILD_LOCAL.md](publication/BUILD_LOCAL.md) を参照してください。元のTikTok APKおよび生成APKは、リポジトリや公開資産に含めません。
