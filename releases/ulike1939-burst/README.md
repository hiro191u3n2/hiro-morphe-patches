# ULike v1.9.39 / 総合 v1.0.172

ULike v1.9.38を基準に、手動シャッターの反応と連続タップ時の次撮影受付を改善します。

撮影準備が整っている写真モードでは200ms・500msの固定タップ制限を緩和し、元の撮影処理をそのまま呼び出します。通常撮影画面の長押し録画判定は各タップに対応させ、前のタップの判定が次のタップで誤発動しないようにします。元の長押し時間は維持します。撮影済み画像と設定を独立して保持できる場合は、画素処理と保存が完了する前に次の手動撮影を受け付けます。画像処理・保存は一列に実行し、保持する写真数とメモリ量を制限します。

解像度、合成枚数、美顔、色処理、ノイズ低減、シャープ処理、保存の圧縮品質は変更しません。メモリや画像形式の条件を満たさない場合は従来の直列処理を維持します。自動で撮影を繰り返す機能や、押した時刻より後で撮影要求を再生する機能は追加しません。

インカメラ起動復旧、倍率表示、撮影領域、ネイティブ高速化処理、他アプリのパッチはv1.9.38／総合v1.0.171から保持します。

`src/build1939.py`は固定したMPP・ツールチェーンでビルドし、変更していないコードと新しいフックの差分を検証します。`src/validate1939.py`は未改造ULike 5.6.2（740）APKSへ単体・総合版を適用し、再構築・型解析・実APKのABIを検査します。`src/finalize1939.py`は検証したMPPのハッシュと配布するMPPを一致させます。

Galaxy実機でのシャッター応答時間・連続撮影・画質は未測定です。元APKS、再構築APK、写真、署名鍵は公開物に含めません。
