# Berry Browser 診断ログ削除 v1.4.5

Hiro Morphe Patches v1.0.339 に収録する Berry Browser 用パッチです。
利用者の依頼により、調査用に追加した描画記録機能を削除します。表示崩れそのものの修正を確認した版ではありません。

## 変更点

- 画面上の「描画記録」ボタン、記録ダイアログ、コピー機能を削除。
- 復帰後・スクロール後・手動検査時の画像、viewport、スクロール位置、WebView提供元などの診断採取を削除。
- 診断専用のリスナー、タイマー、記録保持、JavaScript評価と追加BFCacheランタイムの診断ログ出力を削除。

読み込み停止を直した復帰完了処理、文書の照合、回数・時間制限付きの描画復帰処理を保持します。BFCache・オートページャーの設定と元の4パッチは維持します。今回新しい再描画方式や原因未確定の回避処理は追加しません。

## 適用方法

1. Morphe Manager の Hiro Morphe Patches を 1.0.339 に更新します。Berry 専用ソースの場合は 1.4.5 を使います。
2. 未改造の Berry Browser の APK/APKS に、元の4パッチと「バックフォワードキャッシュの復帰処理を補正」の計5パッチを適用します。
3. 以前と同じ署名キーで更新インストールします。統合版と専用版を重複選択しません。

ソースの更新だけでは、インストール済みアプリのログ機能は消えません。再パッチして更新インストールしてください。アンインストールやデータ消去は不要です。

## 保持と検証

統合版の基準は公開済み 1.0.338 です。ULike v1.9.125 を含む他アプリ、Berry の元の4拡張、対象外のパッチと資源を保持します。

次のローカル検証が完了しています。

- 保持したランタイム5試験群は、89シナリオ・334アサーションに成功。
- 診断クラス・UI・ログ出力の削除と、既存処理の明示的な診断削除以外のソーストークン一致を確認。
- Android SDK 35 の実ライブラリでコンパイル成功。診断専用のスタブ定数は残っていません。
- ランタイムを2回、専用版と統合版を各2回構築し、成果物と構築QAのバイト一致を確認。
- 元の Berry 3.83.74 と識別子を改名した試験用APKへ、専用版・統合版の計4適用が成功。公開済み1.0.338の適用結果とネイティブ処理を比較して保持を確認。
- ネイティブ構造ガードの異常系19件と、元APK・改名APKの正常系が成功。

独立レビューは最終ソース12ファイルのハッシュに結び付けています。個別の結果と検証範囲は `payload/`、`qa/native_audit/`、`audits/no-logs/REVIEW.md` を参照してください。
実際の Berry 3.84.12 の APK、Android 実機での動作と表示崩れ解消は未検証です。

`runtime/` は実行本体と試験、`src/` はパッチ定義、`build/` は MPP 構築、`qa/` は適用・保持・ログ削除の検証、`publication/` は公開処理です。元の APK、署名キー、利用者のスクリーンショットは公開しません。
