- 確認の予約を描画同期に待たされにくい方式へ変更しました。

同じ署名で上書き更新できます。自動実行は「再起動のたびに1回実行」をONのまま再起動し、ロックを解除してください。設定と診断はアイコン長押しから開けます。

Android10以降／ユーザー補助方式。Shizuku・root不要。常駐アプリの強制終了、クイック設定タイル、画面を覆う処理、端末全体のアニメーション設定変更はありません。履歴画面自体は開きます。
