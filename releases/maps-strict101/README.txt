microG Maps 店名検索・ピン表示修正 v1.0.1
Hiro Morphe Patches v1.0.368

今回の修正
v1.0.0で店舗一覧は店名どおりに絞れても、地図の検索ピンが表示されないという
ランダ／スナイデルの報告に対応しました。
前回は地図専用の検索データを外し、一覧側からピンを描く経路を使っていましたが、
一覧に複数店舗があっても、その描画経路の候補が空になる場合がありました。
v1.0.1は元の地図用ピン情報を保持し、一覧の店舗IDと照合して絞り込みます。
追加結果の結合後にも、絞り込み済みの地図データを残します。
元の座標・ピンのスタイル・描画メタデータを使用します。

検索の扱い
「店名検索を厳密にする」の名称と店名判定は維持しています。
ランダ／RANDA、スナイデル／SNIDELなどの登録別名、全角・半角、英字の大小、
ひらがな・カタカナ、支店名を考慮します。
靴屋・喫煙所・カフェなどの既知カテゴリ語、住所・経路・座標は通常検索です。
別の検索語や後続ページの条件を混線させず、元の応答を直接書き換えません。

対象
microG Maps 26.36.04.973607363 / versionCode 1068763346
パッケージ: org.ungoogled.android.apps.maps.microg
提供済みのグーグルマップ v2.8.5 / v2.8.7および既存Maps改造との併用を検証。
Google Mapsのパッチ画面にも表示しますが、版番号だけで互換とは判断せず、
検索処理・応答モデル・描画経路が確認済みコードに一致するAPKだけを受け付けます。

更新方法
1. Morphe ManagerでHiro Morphe Patchesをv1.0.368へ更新します。
   単独版 Maps_Strict_Search_v1.0.1.mppを使う方法もあります。
2. 対応するmicroG MapsのAPKを選びます。
3. 「店名検索を厳密にする」を選択してパッチを適用します。
4. 作成されたAPKをインストールします。
更新ソースの更新だけでは、インストール済みアプリに修正は反映されません。

v1.0.0を適用したAPKからの更新
公開したv1.0.0とコードが一致する場合、そのAPKを入力にして更新できます。
既存の現在地表示・カテゴリ行非表示・戻る終了を適用したAPKでは、今回の
「店名検索を厳密にする」だけを選びます。既存3項目はそのまま保持します。
元のAPKから作る場合は、必要な既存3項目も一緒に選択できます。
統合版と単独版のどちらか一方を使ってください。
未知の改変や不完全な旧パッチ、v1.0.1の重ね掛けは受け付けません。
統合版には起動時現在地v1.0.4、カテゴリ行非表示、戻る終了と他アプリのパッチを保持。

判定の範囲
登録済み以外のブランド名を自動翻訳する機能ではありません。
未知の名称は文字で判定し、未登録のカテゴリ語・特殊な地域名は正しく判定できない
場合があります。名前が取得できない結果は誤って消さないため保持します。
全店舗が不一致と判定できた場合は空の検索結果になります。
Googleから取得できなかった店舗を追加して探す機能ではありません。
地名・駅名などの通常の地図ラベルは対象外です。

ピンIDを照合できない場合
店舗IDの不足や不一致によって一致する全店舗のピンを誤って消さないよう、
IDが不足する場合は確認できた不一致ピンだけを除きます。
店舗が残っているのにピンを1件も対応付けられない場合は、元の地図データを保持します。
その場合や未対応のデータでは、別店舗のピンが一部残る可能性があります。
描画に必要な不透明データ・未知フィールドは保持しており、native描画側の解釈まで
静的解析だけで保証するものではありません。
以前の失敗応答からすでに結合された履歴全体を再処理する機能ではありません。
検索をやり直すと、新しい検索条件と応答で処理します。

検証
店名判定・応答処理とピンデータ保持のホスト試験、実APKへの適用、
既存3項目との同時適用、v1.0.0適用済みAPKからの更新、元のコードとリソース保持、
Managerの選択項目を検証しています。
QA_Maps_Strict_Search_v1.0.1.jsonとソース内の検証資料に結果を記録します。
Android実機・エミュレーター上でのピン表示は未確認です。
APK適用やホスト試験の成功は、端末画面での表示成功とは区別しています。
