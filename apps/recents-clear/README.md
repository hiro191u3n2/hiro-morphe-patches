# 履歴クリア v1.7.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.7.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版へ同じ署名で上書き更新できます。

## 画面の取得と検索を減らす高速化

- 学習済みボタンIDの直接検索を最優先にします。ID未学習時も文字検索から対象ボタンを探し、完全一致ラベル・所属・表示・有効状態・正しいクリック先を検証します。
- ボタンの出現待ちに、画面全体を8msごとに読み直す重複を削減しました。直接検索は即時イベントと短い確認間隔で継続し、全体探索は同じ画面では32msを目安に再確認します。画面変更・検索エラー・不正な候補では通常探索へ即時復帰します。
- Android 13以降の学習済みID検索では、不要な子要素の先読みを抑えます。非対応時は通常処理へ戻します。
- 成功後に画面を読み直す処理を廃止。操作直後にボタンが消えても、操作前に検証したIDを保存して次回の高速検索へ使います。
- ルート取得、文字検索、クリック応答などの診断時間を追加しました。

v1.6.0の履歴表示要求直後の即時確認、8msの確認間隔、操作拒否時だけの限定再試行を維持しています。8msは処理の予約間隔で、削除完了時間ではありません。文字検索に対応しない特殊な画面では通常探索の周期分だけ検出が遅れる場合があります。

アイコン長押しの「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。「診断」で直近の結果を確認できます。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。

ビルド・署名・マニフェストと実際のサービスコードを動かすホストテスト112項目で検証しています。実機での削除・速度は未検証です。端末側の描画・削除アニメーションは残るため、これ以上高速化できないという保証や実機の何倍速という主張はしていません。
