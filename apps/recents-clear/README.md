# 履歴クリア v1.17.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.17.0.apk)

Android 10以降。Shizuku・root不要。旧版と同じ署名で上書き更新できます。

## 自動消去はv1.12の方式、毎回の自動起動は維持

指定されたv1.12の実際のコードを基準に、自動実行の履歴表示・消去の流れを戻しました。自動実行ではv1.16で追加した事前読み込み・予約方式・即時の追加確認を使いません。アイコンからの手動実行はv1.16の方式を維持します。

「再起動のたびに1回実行」をONにすると、その後もONのまま、端末を再起動するたびに1回ずつ自動操作します。ロック解除や画面の準備が遅れた場合の待機、未操作のまま止まった場合の再開、通知が重なっても重複実行しない処理は維持しました。

## 更新と確認

上書き更新後に端末を再起動してください。設定は引き継ぎます。アイコン長押し→「設定」で「再起動のたびに1回実行」を確認できます（初期OFF）。診断では現在と処理済みの起動番号、自動実行の方式、前回の実行結果を確認できます。

221項目の模擬テストを通過しました。3回連続の起動でそれぞれ1回実行し、2回目・3回目の準備遅延からの復帰と重複防止も確認しています。

端末での新しいAPKの動作は未検証です。Androidがユーザー補助サービスを停止した場合など、アプリから実行できない状態まで保証するものではありません。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。
