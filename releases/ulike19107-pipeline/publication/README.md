# ULike v1.9.107 / Hiro Morphe Patches v1.0.252

公開済み単体v1.9.106と総合版v1.0.251を固定ハッシュで取得する。他アプリの変更はバイト単位で保持する。

## 変更範囲

Strongの領域値補間をGPU整数演算で実装し、CPU基準のbinary32演算順と丸めを再現する。CPU画素処理は変更しない。通常Strongと固定入力のGPU診断で同じ修正補間を使用する。認定キャッシュは新しい処理識別に対応させ、旧シェーダーの認定をそのまま流用しない。

全画素一致と速度の採用条件を維持する。1階調差を許容して認定を通す変更、一律の最終RGB補正、診断結果だけでの認定書込は行わない。GPUプログラム60は引き続き保存後の診断専用である。

## 再構築と検証

Temurin21.0.8+9、Android NDK r27c、Morphe Desktop1.16.0、Android35/D8の固定ハッシュ、Python3.12系とNumPy2.3.5を使用する。

1. `src/declare19101.py`で本番ヘルパー、全ソース、公開スクリプトを固定する。
2. `src/build19101.py`で単体・総合MPPを構築する。完全DEX、既存ABI、他アプリ、ヘルパー参照、通常撮影への診断混入防止を確認する。GPU nativeは同一NDKによる正方向再構築と、領域補間および処理指紋を公開版へ戻す逆方向再構築で完全ELFを照合する。NR nativeはv1.9.106と同一バイトを継承する。
3. `src/host_audit19101.py`で既存55系統と領域補間・認定キャッシュの新規2系統を現在のソースに対して実行する。新規試験では独立した有理数・Java基準、GPU実行、丸め境界、座標取得、誤った演算を検出する負の対照を確認する。旧ソース一致試験は、今回の領域補間だけを厳密に元へ戻した比較と実行結果比較で維持する。
4. `src/apply_original19101.py`で私有の未改造ULike5.6.2(740)APKSへ完成MPPを新たに適用し、FULL DEXとリソース再構築、arm64、元native保持、適用後メソッドを確認する。前版MPPの適用証拠は再利用しない。
5. `src/finalize19101.py`と`src/validate19101.py`で今回の実行証拠を配布MPPのSHA-256へ結び付ける。
6. `publication/publish19101.py --local-only`、`--preflight-only`の後に公開する。既存互換のためスクリプト名とschema名に19101が残るが、版値は1.9.107/1.0.252で照合する。

Android実機での±1階調差解消・速度短縮は未確認。ホスト一致やAPK適用成功をGalaxyでの解消・保存2,000ms以下達成の証拠にしない。

## 公開

検証済みdraft資産を公開し、固定commitの配布ファイルを再取得して一致確認後、main/devの両HEADを照合して直接子commitをatomic pushする。他の変更を保持する。既存release/tag/配布branchを上書きしない。
原本APKS、生成APK、個人写真・診断ログ、ツールチェーンは公開しない。ソース・テスト・匿名化した構造証拠のみ公開する。
