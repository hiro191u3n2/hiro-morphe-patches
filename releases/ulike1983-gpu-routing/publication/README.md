# ULike v1.9.83 — GPU連結・振り分けの修正

公開済みULike v1.9.82／Hiro Morphe Patches v1.0.215を固定基準として、承認済みの3点を修正します。新規配布はULike v1.9.83／総合版v1.0.216です。

## 修正範囲

1. GPU生成領域と本当に転送する領域を区別したメモリ予算。事前判定と実際の予約を一致させ、出力解像度と固定予算上限を維持します。
2. GPU枠の予測超過に対する有限の再確認と、環境・経路条件を固定した短期実測。認定済みCPU併用、最大待機、取消を維持します。
3. 同じキュー判定結果から得る検証不成立理由。保存時の写真記録と現在の検証状態を分け、診断が採否を変更しません。

## 保持と検証

画素の計算・NR・美肌・シャープ・保護処理・解像度・保存形式・カメラ/プレビュー/保存フックを保持。全12 nativeペイロード、全GPU program、JNI、画質認定のキーと不一致記録は公開.82と同一です。新しいnativeバイナリは作りません。

production1983.jsonとdiagnostic_methods1983.jsonで今回の本体クラスと既存メソッドの修正を宣言し、対象外のバイトコードを比較します。既存.82のソースはtests1983/source-scope82.jsonに固定し、旧版の試験を残して新しい仕様の正負の回帰を追加します。認定・安全予算・取消・所有権・画素比較を削除することで試験を通しません。

固定JDK21.0.8+9、Morphe1.16.0、Android/D8、NDKr27cを使用。declare1983.py → build1983.py → validate1983.py → finalize1983.py → publication/publish1983.pyで再構築・公開します。原本APKSへの適用・完成APKの静的検査を行い、そのMPPとCIの再構築MPPを完全一致させます。

## 公開

GitHubの固定リポジトリhiro191u3n2/hiro-morphe-patchesを使用。新しいソースとCIを準備し、配布物・QA・ソースZIPを確認後、Releaseとmain/devのManager更新情報を更新します。HEADの照合により並行更新を保持します。利用者の画像・生ログ・原本APKS・生成APK・署名鍵は公開しません。

Android実機での撮影・最終画像・体感速度は未検証です。旧版約1.9秒への復帰を保証しません。
