# カレンダー 月間ウィジェット色分け v1.0.0

Fossify Calendar `org.fossify.calendar` 1.12.1 (24) 用。ホーム画面の1か月ウィジェットで土曜日の曜日・日付を青、祝日の日付を赤にします。祝日と土曜日が重なる日は赤を優先します。

- 青 `#2196F3`、赤 `#FF0000`。日曜日・通常の日付・予定の色は元の設定を維持します。
- 祝日はアプリ管理の祝日、祝日種別のカレンダー、または「祝日」「日本の祝日」等の明示的な祝日カレンダーにある終日イベントから判定します。通常予定の色だけでは判定しません。
- 前後月の日付の薄さ、今日を示す丸印とその文字のコントラストは元の処理を維持します。今日が土曜・祝日の場合は丸印が対応色になります。
- 対象はホーム画面の月間ウィジェットです。アプリ本体の月表示やウィジェット設定のプレビューは変更しません。

Morphe ManagerでHiro Morphe Patchesを更新し、元のカレンダー1.12.1に「月間ウィジェットの土曜を青・祝日を赤」を適用してください。単独版と統合版のどちらか一方を使用します。インストール後にウィジェットの月を切り替えると再描画されます。

添付された実APKへの適用・再構築、日付と祝日分類のホストテスト、既存統合パッチの保持を検証します。Android実機での表示は未確認です。APK本体、予定データ、アカウント情報は配布物に含みません。

`src/build.py --base baseline321.mpp --tools tools --work work --dist dist --apk original-base.apk` でローカル検証付きビルド。CIでは実APKを再配布せず、同一ソースからの再ビルドとホストテスト、公開前に検証済みMPPとのバイト一致を確認します。
