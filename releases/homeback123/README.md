# Instagram リールの戻る終了 v1.1.13

Hiro Morphe Patches v1.0.255。Instagram 447.0.0.55.81 のリールから Android の戻る操作で終了し、「最近使ったアプリ」のカードを削除するための修正です。

## 調査で確認したこと

今回提供された APK の OneBack ランタイム全 74 クラスは、配布した v1.1.12 と一致しました。更新漏れではありません。前回の終了処理は、アプリ自身がリールの戻る処理へ入った後も汎用的な画面判定を条件としており、そこで拒否されると Instagram 本来のホームへの遷移が実行される構造でした。端末上でどの条件が拒否したかはログがないため未確定です。

ホームへの遷移には、タブ履歴を戻す経路と、既定タブへ直接移る経路が存在します。今回は両方を確認し、次の境界に処理を合わせました。

- リールの `X.8Zv.onBackPressed` 内で、アプリ本来のポップアップ・シート処理が戻る操作を消費しなかった後に終了します。この専用の呼び出しでは、汎用の画面分類や古いジェスチャー判定で再び拒否しません。
- ナビゲーションの `X.2xZ.A0V` 内で、画面側が戻る操作を消費せずタブ履歴を取り出そうとする直前にも補完します。実際の現在タブが `CLIPS`、所有 Activity と現在 Fragment が一致する場合に終了します。成功時も本来のトレース終了処理を通ります。
- コメント欄などがネイティブ処理で閉じられた場合は、専用フックより前に戻ります。ホームなど他のタブは補完フックで終了扱いにしません。
- v1.1.10／v1.1.11／v1.1.12 の既知ランタイムを明示的に置き換えます。v1.1.12 の既存 AndroidX フックは検証して保持し、重複挿入しません。対象のネイティブ処理が一致しない入力は中止します。

## 適用

Morphe Manager に `OneBack_Exit_NoRecents_v1.1.13.mpp` を読み込み、今回送付した Instagram APK に **「戻る1回で終了・履歴削除」だけ**を選択して適用し、同じ署名鍵で更新インストールしてください。改造済み APK に他のパッチをまとめて再適用する手順ではありません。

総合版 `Hiro_Morphe_Patches_v1.0.255.mpp` にも同じ修正を収録します。基準の総合版は v1.0.253、対象外のパッチと同梱資源は保持します。

## 検証と制限

本番 Android SDK でのコンパイル、17 のホスト試験スイート、実際の提供 APK への単体／総合 MPP 適用を確認しました。出力された全 75 ランタイムクラスは配布内容と一致し、アプリ本体 200,688 クラス・826,366 メソッドを比較して、新しいタブ分岐以外の実行処理が保持されていることを確認しました。単体版と総合版の出力 APK は全 ZIP エントリの内容が一致します。確定した結果は QA JSON と `evidence` に収録しています。提供 APK と検証用の署名なし出力 APK は配布ソースへ含めません。

資源の再構築には、Morphe の aapt による形式変換と 1 つの寸法値の約 0.008dp の丸め差があります。これらを列挙した厳密な比較を通過し、それ以外の非コード 17,052 エントリは全バイト一致しています。

過去の模擬試験には、ネイティブ処理がコメント欄などを閉じて `return` した後に、同じ戻る操作から終了フックを直接呼ぶ仮定がありました。この仮定を実際の DEX に合わせて修正し、新しい 24 ケース・120 アサーションで、ネイティブの早期 return と次の独立した戻る操作を確認しています。

Android 実機でのリール操作と履歴カードの表示は未確認です。静的解析やホスト試験を端末上の動作確認としては扱いません。「履歴削除」の対象は Android の「最近使ったアプリ」のカードです。
