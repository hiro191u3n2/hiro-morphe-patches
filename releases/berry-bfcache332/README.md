# Berry Browser 戻る復元補正 v1.4.1

Hiro Morphe Patches v1.0.332に収録するBerry Browser用パッチです。
戻る操作の後に読み込みが終わらず、繰り返すと表示が崩れる症状への修正候補です。

キャッシュ復帰時の通知の欠落や順序の違い、JavaScriptの確認結果が返らない場合を扱うよう、復帰処理を見直します。
再確認には回数と時間の上限を設け、別のページへ移動した後に届く結果や子フレームの通知を復帰完了に使いません。
復帰後の読み込み状態、読み込み表示、ページ移動に関わる内部状態を整えます。

BFCacheの有効設定と最大ページ数、オートページャー設定、既存4改造を維持します。
強制リロード、履歴・キャッシュ削除、ユーザースクリプト全体の再実行は追加しません。
全バージョン表示と適用先の構造自動検出を引き継ぎますが、実装構造が一致する入力だけに適用します。

## 適用

Morphe Managerでソースを1.0.332へ更新し、未改造Berry Browserを入力として、
「バックフォワードキャッシュの復帰処理を補正」を含むBerry用5パッチを選択してください。
Berry専用ソースは1.4.1です。統合版と単独版を重複選択しません。
以前と同じ署名キーで更新インストールします。アンインストールやデータ消去は不要です。

## 検証と限界

`payload/QA_apply332.json`が配布MPPのハッシュと適用試験を記録します。
`payload/RUNTIME_BUILD_QA.json`が通知欠落・順序変更・古い結果などのJVM試験と埋め込みJavaScript試験を記録します。
ビルド時に他アプリの定義、既存の4つの拡張、compile-only stubの除外、ネイティブとの接続を確認します。
ユーザーの実機での表示崩れ解消、実通信の再開、Berry 3.84.12そのものの実行は未確認です。
JavaScriptが完全に応答しない状態からの復旧も未確認です。確認結果が得られないまま完了表示だけを強制する処理は追加しません。

## ソースと再現

`src/`はパッチ定義、`runtime/`は復帰補正本体と試験、`build/`はMPP構築・保持検証、`qa/`は適用検証、`publication/`は公開処理です。
元APK、署名キー、ユーザーデータは公開物に含めません。

公開ワークフローは固定したベースMPPとビルドツールを取得し、ランタイムとMPPをそれぞれ2回構築します。
2回の一致とレビュー済みハッシュ、候補固有の適用検証結果を確認してからリリースを作成し、Managerのmain/dev更新情報を一括更新します。
他アプリの更新履歴とULikeの現行設定を保持し、公開直前にブランチが進んでいた場合は上書きせず停止します。
