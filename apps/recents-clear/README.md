# 履歴クリア v1.14.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.14.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版と同じ署名で上書き更新できます。

## 画面取得中の中止で自動実行が失われる問題を修正

v1.13の実機診断で、画面情報の取得後に画面が使用できないと判定され、履歴を操作していないのに実行済みとなる経路を確認しました。実行済みの保存を、画面情報の取得開始時から最初の履歴操作の直前へ移しました。

準備中のロック・消灯では、実行権を確保する前なら使用可能な状態を待って再開します。画面を繰り返し起動せず、新しい画面情報を取得して共通の消去処理へ進みます。100ms間隔・最大15秒の再確認を使い、期限後は次の点灯・解除などの通知を待ちます。設定OFFと手動実行は自動待機を取り消します。

履歴操作を試みた後は、自動処理全体をやり直しません。通常のアイコン起動と削除ボタンの判定は維持しています。

## 更新・設定・診断

上書き更新で既存設定を引き継げます。更新後に端末を再起動してください。アイコン長押し→「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。有効なら再起動ごとに最初のロック解除後に自動実行します。

アイコン長押し→「診断」→「診断をコピー」で、今回の起動番号・待機状態・停止時の画面状態・UI操作を試みたかどうかを確認できます。自動実行が止まった場合は、手動消去する前に診断を確認するとその時の状態を残せます。

実際のActivity・サービスのコードを使う模擬テスト208項目と、ビルド・署名・マニフェストの検証を通過しました。旧v1.13と比較し、報告された2回の画面取得・合計1902ms・未操作での中止を再現しました。修正版では実行済みにせず待機し、使用可能になった後に1回だけ操作することを確認しています。修正版の実機での自動起動・削除・表示時間は未検証です。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。
