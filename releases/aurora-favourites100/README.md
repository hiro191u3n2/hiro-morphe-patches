# Aurora Store favourite startup v1.0.0

Targets Aurora Store 4.8.4 (76), package com.aurora.store, in both the official-signed and F-Droid builds. Matching DEX and resource contents are verified and both APKs receive standalone and combined application checks with both legacy and Patcher 2 toolchains (eight applications). The new tool is Desktop 1.19.0-dev.4 / Patcher 2.0.0-dev.12; Patcher dev.13 itself has not been executed. A Morphe patch to open Favourite Apps on each normal launcher entry. This release adds Aurora-only patch/runtime classes to Hiro Morphe Patches v1.0.264 and produces bundle v1.0.265 plus a standalone MPP.

The source, host/DEX/APK application evidence and exact file hashes accompany the release. No Aurora APK is published. Physical Android UI execution has not been performed.
