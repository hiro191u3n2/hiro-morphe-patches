# 履歴クリア v1.15.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.15.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版と同じ署名で上書き更新できます。

## アイコン時と共通の消去処理から重複確認を削減

履歴を開いた直後に新しい画面を取得し、保存済みボタンIDで検証して操作する流れを維持しました。v1.14で自動実行の削除直前に加わった重複の状態確認を省き、同じ確認の中でユーザー解除状態を二度問い合わせる処理も一度にまとめました。削除対象の判定と操作間隔は、前版のアイコン起動時と同じです。

画面情報の取得や探索で時間がかかった場合に備えたロック・消灯・設定OFFの確認、未操作で止まった時の再開、再起動ごとに1回だけ実行する仕組みは引き継ぎます。履歴画面を開いてからの固定待機はありません。

## 更新・設定・診断

上書き更新で既存設定を引き継げます。更新後に端末を再起動してください。アイコン長押し→「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。有効なら再起動ごとに最初のロック解除後に自動実行します。

アイコン長押し→「診断」→「診断をコピー」で、今回の起動番号・待機状態・停止時の画面状態・UI操作の有無と所要時間を確認できます。自動実行の記録は、アイコンから実行した後も別に保持します。

実際のActivity・サービスを使う模擬テスト212項目を通過しました。前版のアイコン起動と新版のアイコン・自動実行を同一の模擬環境で比較し、画面取得・検索・操作の順序と待機間隔が共通であることを確認しました。実機での表示時間は未検証で、履歴画面が目に見えなくなることは保証しません。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。
