# Amazon 商品検索の評価件数順 v1.0.3

対象は添付された Amazon ショッピング 32.19.0.100（versionCode 1243250306、Amazon v1.23.1 適用済み）です。
単独版は `Amazon_Review_Count_v1.0.3.mpp`、統合版は `Hiro_Morphe_Patches_v1.0.351.mpp` です。

検索直後に通常商品を約100件先読みし、取得できた商品を評価件数順へ1回だけ並べて、その後の閲覧順を固定します。閲覧中に件数の変化や追加読み込みを理由として何度も並べ替える方式から変更しています。

## 先読みと閲覧

先読みはAmazonアプリの既存の追加読み込みを使います。検索結果リストの範囲内を自動で下へ進み、接続済みの通常商品を、同じASINの重複分を除いて約100件集めます。画面下に「先読み中 N / 約100商品・画面操作で終了 v1.0.3」を表示し、終了後は「先読み N 商品で固定」の状態表示へ切り替えます。ページ全体の末尾やフッターへ移動する方式ではありません。読み込みがまとまって返る場合は100件を超えることがあります。

上限は20秒・30回のスクロールです。最初の商品が20秒間現れない場合は定期確認と自動スクロールを止め、検索結果の更新を待ちます。その後に商品が現れたら、追加先読みをせず取得済みの商品を1回だけ並べます。検索結果の末尾で一定回数商品が増えない場合も、取得できた範囲で終了します。100件が必ず取得できるものではありません。先頭から開始した通常の検索では、完了後に検索結果の先頭へ戻します。

画面へのタッチ、ポインター、ホイール、キー操作やページの非表示化を検出すると、先読みを止めます。操作が落ち着いてから取得済みの商品を1回だけ並べ、操作で中断したときは見ていた位置を保つ補正をします。途中位置や再利用された検索画面では、自動で先へスクロールせず、取得済みの商品を対象にします。「戻る・進む」で復元された画面も、先頭にいる場合を含めて自動先読みを行いません。

並べ替え後は最初の対象商品の順位を固定します。画像の読み込み、評価件数の一時消失・更新があっても件数で再順位変更しません。後から追加された商品は同じ表示領域内の最初の固定対象群の下へ置き、検索条件が変わった場合に新しく処理を始めます。

同じ表示形式でまとめられる通常商品を対象とします。異なる表示形式、独立してスクロールする領域、通常とは別の見出し付き区画はそれぞれ分け、件数順の並べ替えと固定後の追加商品も各範囲内で扱い、複数の独立した範囲がある場合は「表示形式ごと」と表示します。

評価件数はAmazonの表示値を使い、星だけの評価も含みます。文章付きレビューの件数とは一致しません。先読みで取得した商品の中での順位であり、全検索結果を取得した全体順位ではありません。

v1.0.2 と同じ6箇所のネイティブフックを保持します。読み込み・ページ完了に加え、`MShopWebViewClient.doUpdateVisitedHistory` と `InteractionWebFragment.onFragmentPostShown` を検証付きでフックします。元の広告非表示や価格履歴を含む既存処理を保持し、6メソッドへ合計8命令を追加します。

## 適用

元の添付APKを選び、「商品検索を評価件数の多い順に表示」だけを適用してください。v1.0.0〜v1.0.2を適用したAPKへの重ね掛けは受け付けません。単独版と統合版のどちらか一方を使用し、以前と同じ署名で作成したアプリを上書きインストールします。ソース更新だけではインストール済みアプリは変わりません。

## 再現ビルド

JDK 21.0.13、`publication/baseline.json` の固定された統合350、`src/build.py` のSHA-256と一致する4ツールを使用します。`morphe.jar` は旧JavaパッチAPIのコンパイル専用で、適用・検証には公式Patcher 2.2.0を含む `morphe-2.2.jar` を使います。

```sh
npm ci --ignore-scripts --no-audit --no-fund --prefix src/runtime-tests
python3 src/build.py --base baseline350.mpp --tools tools --work build-a --dist dist-a --apk supplied.apk
python3 src/build.py --base baseline350.mpp --tools tools --work build-b --dist dist-b
```

各ビルドは新しい作業ディレクトリと空の出力先を指定します。JDKを別途指定する場合は `--java-home /path/to/jdk-21.0.13` を追加します。配布MPPの全バイトが2回のビルドで一致することを確認します。

`--apk` を指定したビルドは、単独版と統合版をPatcher 2.2.0の `STRIP_FAST` で実際に適用します。生成したDEXのクラス一覧と変更箇所、既存メソッド、ランタイム、APKの全非DEX資源を照合します。Javaの起動条件、URL、ガード、二重適用拒否と、DOMの先読み上限・中断・1回の並べ替え・固定後の追加商品をホストテストで確認します。

レイアウト位置やスクロールはテスト用の矩形・値による合成ジオメトリで検証します。実ブラウザーでの描画試験やAndroid実機での操作試験を行ったものではありません。以前の表示乱れの端末上の原因を確定したものではなく、実機での改善確認は未実施です。

統合350から置換するのは `app/hiro/amazonreviews/patches/` と `extensions/amazon_review_sort.mpe` だけです。他パッチのクラスと資源は保持します。APK適用結果は `QA_Amazon_Review_Count_v1.0.3.json` に記録します。元APK、実機の検索内容、アカウント情報を公開物に含めません。
