microG Maps 戻る終了・履歴削除 v1.0.0
Hiro Morphe Patches v1.0.363

対象
microG Maps 26.36.04.973607363 / versionCode 1068763346
パッケージ: org.ungoogled.android.apps.maps.microg
以前提供されたグーグルマップ v2.8.5と、v2.8.7に含まれる対象コードを照合します。
ManagerのGoogle Maps側にも選択項目を表示しますが、対象コードが違うAPKには適用しません。

パッチ名
戻るで終了して履歴から削除

動作
検索結果・場所の詳細・経路設定など、Maps本来の戻る処理を先に処理する構成です。
その先でアプリを終了するときに、AndroidのfinishAndRemoveTaskを呼び、
アプリのタスクを終了して最近使ったアプリの履歴カードから削除します。
Androidの戻るボタンと予測型バックジェスチャーが使う内部ディスパッチャーに、
最も低い優先順位の有効なコールバックを初期化時から登録します。
Maps本体のコールバックが無効になる最終画面でも、終了処理が有効な状態を保ちます。
他のアプリ内Activityの戻る順序や、既存の検索・地図・位置情報処理は変更しません。
Google Mapsの検索履歴や訪問履歴を消す機能ではありません。

使い方
1. Morphe ManagerでHiro Morphe Patchesをv1.0.363へ更新するか、
   Maps_Back_Exit_v1.0.0.mppを読み込みます。
2. 対象のmicroG Maps APKを選びます。
3. 「戻るで終了して履歴から削除」を選び、パッチを適用します。
4. 作成したAPKをインストールします。

前のMapsパッチとの併用
現在地表示やカテゴリ行非表示が既に入った対応APKには、今回の新しい項目だけを選んで追加します。
既に適用済みの現在地表示などを再度選ぶと、その既存パッチ側の重ね掛け検査で停止する場合があります。
元APKから作り直す場合は、統合版で現在地表示・カテゴリ行非表示・戻る終了を同時に選べます。
今回の戻る終了パッチ自体の重ね掛けは拒否します。
単独版と統合版はどちらか一方を使います。ソース更新だけではインストール済みアプリに反映されません。

確認範囲
Morpheの旧SDKとパッチャー2.2.0で項目の読み込みと対象コード検査を確認済みです。
元v2.8.5、以前添付された改造済みv2.8.7への新項目の適用を確認済みです。
現在地表示・カテゴリ行非表示との3項目同時適用を確認し、
戻る終了だけを追加した分以外の実行コード、マニフェスト、リソース、ネイティブライブラリを比較済みです。
生成した終了コールバックと登録条件は、出力DEXの命令を使ったホスト試験で検証します。
Android実機・エミュレーター上での操作と履歴カード削除は未確認です。
ホストでの命令検査やAPK生成は、Android上での動作確認とは区別します。
