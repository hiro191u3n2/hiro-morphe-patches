# Fossify Gallery 戻る終了時の履歴削除 v1.0.1

Hiro Morphe Patches v1.0.258。公式 GitHub 版 Fossify Gallery 1.14.0（29）のパッチ適用時の誤判定を修正します。終了時の履歴削除の動作は v1.0.0 から変更しません。

v1.0.0 は元の戻る処理を一つの DEX に書き出した後、その全体の固定ハッシュで照合していました。新しい smali ライターでは同じコードの型リストの配置が変わり、実行命令が一致していても別のハッシュになりました。未改造の同一公式 APK に v1.0.0 を適用し、旧パッチャーで成功し、Patcher 2.0 系で MainActivity の検査が失敗することを再現しています。

v1.0.1 では、公式 APK の対象3メソッドから作成した照合用 DEX を同梱し、処理するパッチャー自身の同じライターで、照合用の元コードと入力コードの両方を比較します。デバッグ位置は判定から除き、実行命令・引数・分岐・例外処理・メソッドの属性と注釈を照合します。未知の処理や既に適用済みのコードには上書きしません。

検証は旧版 Desktop 1.16.0 と Desktop 1.19.0-dev.4（Patcher 2.0.0-dev.12）の両方で、単体・総合 MPP を公式 APK へ適用し、全クラス、元処理、元の資源、注入するランタイムの保持を監査します。ユーザーの Patcher 2.0.0-dev.13 と dev.12 の公式ソースは、問題に関わる DEX 読み書きの実装と smali 依存版が同一です。dev.13 自体の Android 実行を行ったという意味ではありません。

新旧の読み書きによる差と、命令・分岐・呼び出し先などを変更した場合に照合を拒否する試験を行います。独立した2回の公開側ビルドが、手元で固定した MPP・QA と一致する場合だけ公開します。実機での画面操作・履歴カード削除は未確認です。

Morphe Manager のソースを v1.0.258 に更新し、未適用の対応 APK で「戻る終了時に履歴を削除」を選択して再実行してください。更新インストールには従来と同じ署名キーを使います。ソースの更新だけではインストール済みアプリは変わりません。
