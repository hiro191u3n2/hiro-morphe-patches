microG Maps 起動時現在地 v1.0.4
Hiro Morphe Patches v1.0.466

今回の修正
前版v1.0.3で初回起動の現在地表示まで中止される不具合を修正しました。
保存済みの対象APKを調べたところ、Mapsの初回onCreate(null)内でも、
同じ起動IntentをonNewIntentへ仮想呼出しする経路がありました。
前版はこの内部通知も既存タスクへの復帰と扱い、最初の待機を取り消していました。
新版では、最初の画面再開前で、通常起動の未完了処理がある場合だけ、
この同じ起動通知を受けても元の待機を継続します。
待機時間や移動回数の上限はリセットせず、新しい処理も開始しません。
前版で追加した「ホームからタスクへ復帰しても自動移動しない」動作は維持します。

動作
・アプリを終了した後、アイコンから新しく起動した場合は現在地へ自動移動します。
・ホームや別アプリへ移った後、残っているタスクへ戻った場合は自動移動しません。
・ホームへ戻った時点で起動時の位置情報待ちや移動の再試行が残っていても中止します。
  復帰後に遅れて現在地が得られても、その起動処理を再開しません。
・既存画面へ起動アイコンから通知が届いた場合も自動移動を開始しません。
・保存状態や最近使ったアプリの履歴から画面を復元する場合は自動移動しません。
・一時的なダイアログによる一時停止だけなら、最初の未完了処理は継続できます。
・v1.0.2の「起動直後にタップしても最初の現在地移動を取り消さない」修正を維持します。
・現在地到達後の手動操作、住所リンク、経路表示、ナビゲーションを優先します。

対象
・microG Maps 26.36.04.973607363 / versionCode 1068763346
・パッケージ: org.ungoogled.android.apps.maps.microg
・以前添付されたグーグルマップ v2.8.5の元APK
・グーグルマップ v2.8.7も、検証済みの対象コードが一致する版に対応します。
・以前の「起動時に現在地を表示」を入れる前のAPKへ当て直してください。
  旧版の同じパッチが入ったAPKへの重ね掛けには対応しません。

パッチ名
起動時に現在地を表示

初回移動の制限
新規起動で画面が操作可能になってから約1秒の準備待ちを行います。
地図と現在地の準備を最大60秒待ち、Maps本来の処理で現在地へ移動します。
到着確認前のタップでは初回移動を取り消しません。
タップによって待機期限や移動要求の上限は増えません。
移動要求は初回と必要な場合の再試行1回までです。
通常は現在地追従・現在地から50m未満・ズーム13以上を2回確認して終了します。
移動要求後のタップ時は到達状態だけを読み取り、到達済みならその1回で終了します。
このパッチは独自の位置情報サービスや権限要求を追加しません。
標準の現在地ボタンやナビゲーションなどの位置情報機能は利用できます。

使い方
1. Morphe ManagerでHiro Morphe Patchesをv1.0.466へ更新するか、
   Maps_Startup_Location_v1.0.4.mppを読み込みます。
2. 旧版の起動時現在地パッチを入れる前のmicroG Maps APKを選択します。
3. 「起動時に現在地を表示」を選び、パッチを適用します。
4. 作成したAPKをインストールします。
5. 新規起動で現在地へ移動した後、別の場所を表示してホームに戻り、
   アイコンまたは最近使ったアプリから復帰した際の表示を確認してください。

既存の改造
統合版では「検索欄の下のカテゴリ行を非表示」および
「戻るで終了して履歴から削除」も同時に選択できます。
単体版と統合版はどちらか一方を使用してください。
ソースの更新だけではインストール済みアプリには反映されません。

検証と限界
対象APKの初回onCreateからonNewIntentへ内部配送する実コードと、
その仮想呼出しが改造したライフサイクル処理へ到達することを構造監査しました。
ホスト試験の新規起動手順も、実APKと同じ内部配送を含む順序へ修正しました。
exact前版v1.0.3で初回起動が中止されることと、新版で移動要求が実行されることを検証しました。
既存のホーム復帰・保存状態復元・位置情報待ち・タップ処理・再試行上限も同じ試験で確認しました。
元APKへの適用、元のコード・リソース保持、Maps3項目の同時適用、
統合版の他アプリの保持、Managerのパッチ選択をビルド時に検証しました。
初回通知・ホーム復帰・タップなど100ケース／937項目、生成DEX命令50ケース／848項目が成功しました。
実APKの初回起動構造を2 APK×2 SDKの4通りで確認しました。
具体的な結果はQA_Maps_Startup_Location_v1.0.4.jsonに記録しています。
Android実機・エミュレーターの画面上での改善は未確認です。
実APKの構造監査、ホスト上の模擬実行、パッチ適用検証を、Android画面での確認と区別しています。
現在の環境には接続済みAndroid端末、ADB、エミュレーター、AVD／システムイメージはありません。
版番号だけで互換性を判断せず、対象処理が一致しない場合は変更前に中止します。
verification内の102表記のツール取得記録は、前回取得して再利用した同一ツールの来歴です。
