SwiftKey Beta v1.8.6 / Hiro Morphe Patches v1.0.289

追加内容
SwiftKey の「レイアウトとキー」に、次の独立した設定を追加しました。
・絵文字の検索欄を非表示
・「AI の作成」ボタンを非表示
どちらも初期設定はオフです。オンにした項目だけ非表示になります。

絵文字の検索欄は、右側の矢印を含む行全体を非表示にします。GIF・画像・スタンプなどの検索欄は対象外です。「AI の作成」は該当ボタンだけを非表示にし、同じ場所に表示される別の Copilot ボタンは対象外です。表示言語に合わせたアプリ内の文言を照合します。
設定をオフにすると、今回の処理で非表示にした表示を戻します。アプリ側がもともと非表示にしている項目を強制表示しません。キーボードの再表示、タブの切替、画面の再生成でも設定を適用します。

保持した内容
日本語辞書、使用頻度による候補の並べ替え、Samsung 絵文字、キー入替、改行、貼り付け・削除保護、日本語 QWERTY グライド入力の既存改造を保持しています。v1.8.5 で復元した JVM 実行用コードも保持しました。ほかのアプリのパッチは変更していません。

検証範囲
既存の実行用コードと辞書を比較し、許可した拡張コードの追加以外が維持されることを検査します。非表示設定の組合せ、対象外の検索欄、Copilot、オン・オフの復元、画面の再生成をホスト試験で確認します。旧・現行 Morphe の実際の読み込み処理で、単体版と総合版の SwiftKey パッチおよび依存関係が一致することを検査します。公開前に独立した2回のビルドと公開ファイルのハッシュを照合します。
実機の画面表示・入力動作、および未改造 APK への全工程の適用は未確認です。解析に使用した APK は以前の改造済みの保存版です。

適用方法
1. Morphe Manager の Hiro Morphe Patches を 1.0.289 に更新します。
2. 未改造の Microsoft SwiftKey Beta 9.13.16.4 (1236271168) に、SwiftKey のパッチを適用します。
3. 以前と同じ署名でインストールし、SwiftKey の「レイアウトとキー」で必要な非表示設定をオンにします。
改造済み APK を入力として再パッチしないでください。Morphe のソース更新だけでは、インストール済みの SwiftKey は変更されません。
