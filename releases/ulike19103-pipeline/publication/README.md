# ULike v1.9.103 / Hiro Morphe Patches v1.0.242

公開済み単体 v1.9.101 と最新総合版 v1.0.241 を固定ハッシュで取得し、v1.9.102候補の修正と今回の修正を統合する。他アプリの変更はバイト単位で保持する。

## 変更範囲

撮影世代・所有者・画像時刻の対応が確認できた画像取得と結果通知を計測する。異なる時計の差分や未対応のシャッター時刻は使わない。
既存経路とCPU基準の不一致、連結候補の不一致、中断、比較未完了を区別し、画像を保持しない上限付きスカラー差分を記録する。
実行中の版表示は統一し、過去の履歴は記録時の版を維持する。
保護マスクの座標補間の重複を削減する。画像設定、出力サイズ、ノイズ処理の数値順序、速度・画質認定条件、失敗時の従来経路への復帰を保持する。

## 再構築と検証

Temurin 21.0.8+9、Android NDK r27c、Morphe Desktop 1.16.0、Android 35/D8の固定ハッシュを使用する。Python 3.12系とNumPy 2.3.5を使用する。

1. `src/declare19101.py` で本番ヘルパー、全ソース、公開スクリプトを固定する。
2. `src/build19101.py` で単体・総合MPPを構築する。完全DEXの変換・逆変換、既存ABI、未変更アプリ、全ヘルパー参照、同一NDKでのnative完全ELFの正方向・逆方向再構築を確認する。
3. `src/host_audit19101.py` で現在のソースに対する既存試験と今回追加した回帰試験を実行する。
4. `src/apply_original19101.py` で私有の未改造ULike 5.6.2(740) APKSへ完成MPPを実際に適用し、FULL DEXとリソース再構築、arm64、元native保持、適用後メソッドを確認する。
5. `src/finalize19101.py` と `src/validate19101.py` で今回の試験・適用証拠を配布MPPのSHA-256へ結び付ける。過去の証拠を今回の実行結果として流用しない。
6. `publication/publish19101.py --local-only`、`--preflight-only`の後に公開する。既存互換のためスクリプト名とschema名に19101が残るが、版値は1.9.103/1.0.242で照合する。

Android実機の速度・画質は未測定。ホスト一致試験やAPK適用成功をGalaxyの速度改善や2,000ms以下達成の証拠として扱わない。

## 公開

公開スクリプトは検証済みdraft資産を公開し、固定commitの配布ファイルを再取得して一致確認後、main/devの両HEADを照合して直接子commitをatomic pushする。他の変更を保持する。再試行時はreceiptを確認し、既存release/tag/配布branchを上書きしない。
原本APKS、生成APK、個人写真・診断ログ、ツールチェーンは公開しない。ソース・テスト・匿名化した構造証拠のみ公開する。
