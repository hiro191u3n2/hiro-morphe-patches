# ULike v1.9.37 / 総合 v1.0.170

ULike v1.9.36 を基準に、起動時に撮影領域の上側が黒帯で隠れ、表示範囲が狭まる経路を修正する再現ビルドです。

確認した問題を次の範囲で修正します。

- 途中で停止した表示切替アニメーションを管理し続け、現在の画面と世代が一致する場合に正常な位置へ確定する。
- 古い画面・縦横比・表示世代に属する遅延通知が、現在の画面を上書きしないようにする。
- 撮影画面の寸法には現在の表示領域を使い、同じ縦横比でも表示位置や描画先が変わった場合は再反映する。

正常画像の表示範囲は742×1536画面内で上端131px・下端1120px（高さ989px）、異常画像は上端309px・同じ下端1120px（高さ811px）でした。添付画像の撮影内容は異なるため、画角やズームの差は画像比較から断定しません。写真そのものは公開物に含めません。

画質処理・保存品質・解像度・合成枚数、S2・S3・S4・S5・S6・S7・S8・S16・T1、前版の前面カメラ復旧と倍率非表示、および他アプリの改造を維持します。保存写真を今回の不具合対策で強制クロップしません。

`src/build1937.py` は固定した元MPPとJavaツールで変更範囲を検証します。`src/validate1937.py` は単体・総合版を未改造ULike5.6.2(740) APKSへ適用し、再構築・DEX型解析・実APKの呼び出し契約を検証します。`src/finalize1937.py` は元APKSへの適用検証済みMPPとのSHA-256一致を要求します。

公開ワークフローは再現ビルド、公開資産の検証、main/dev両Managerフィードの更新まで行います。実機での現象再現・解消確認は未実施です。詳細はRELEASE_NOTES.txtとQA JSONに記録します。

撤回済み10bit経路や削除済み診断表示・原本保管機能は復活させません。元APKS、再構築APK、ユーザー写真、署名鍵は公開物に含めません。
