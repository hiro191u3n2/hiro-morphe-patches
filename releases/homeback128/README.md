# Instagram プロフィール動画から戻る修正 v1.1.18

Instagram プロフィール動画から戻る修正 v1.1.18 / Hiro Morphe Patches v1.0.277

プロフィールからそのアカウントの動画を開いた場合の戻る処理を修正します。Instagram 452には、プロフィールから別の動画画面（ModalActivity）を開く経路があります。前版ではこの画面を452版の階層確認から外してしまい、通常の動画画面として終了判定へ流れる余地がありました。同じ条件をホスト試験で再現し、誤って終了する判定を修正しました。これはソースと検証用画面状態に基づく原因確認であり、利用者の実機操作を記録して特定したという意味ではありません。

プロフィールなどから開いた動画では、Instagram本来の戻る処理を実行して元の画面へ戻します。強制終了は、実際のメイン画面でリールタブが選択され、手前の画面や戻り先の階層がないことを確認した場合だけに限定します。通常のリールタブは戻るで終了し、最近使ったアプリのカードを削除します。コメント欄やキーボード等は先に閉じます。同じ戻る操作が複数の処理を通る場合にも、最初に決めた「元の画面へ戻す」扱いを保持します。

公開済み総合版v1.0.276を基準にOneBackを更新します。ULike v1.9.114、Berry Browser、Yahoo!乗換案内等の他パッチと資源を保持します。Managerの更新対象はInstagramです。

本番Android SDKでのコンパイル、既存のホスト回帰試験と今回のプロフィール復帰試験、DEX構造、他パッチ保持を確認します。単体・総合MPPを3系統のMorphe Desktopで読み込み、5アプリの合成APKへ適用・再構築します。元Instagram 452.1.0.53.64への今回の適用、出力コードと資源、署名と整列を監査します。CIの2回のビルドはローカル確定MPPとQAとの完全一致を要求します。実行した対象と結果は同梱QAと検証記録に記載します。

Piko 3.11.0-dev.1のCloneを除く65パッチとOneBack v1.1.17を適用済みの452版APKへ、今回のOneBack v1.1.18だけを再適用して更新できることを検証しました。Pikoを含む既存のアプリコードと戻る境界を保持し、組み込む補助処理が今回の配布MPPと一致することを確認しました。既存のOneBackの方針に従い、Pikoが追加した7個のActivityへenableOnBackInvokedCallback=trueの明示を追加します。それ以外のマニフェスト内容と、他の非コード24,530エントリは保持されます。Piko各パッチを今回新たに同時適用した試験や、利用者の64項目の選択を再現した試験ではありません。

Android実機でのインストール、画面操作、プロフィール復帰、終了後のタスクカード表示は未確認です。元APK、端末データ、署名用秘密鍵は公開物・CIに含めません。

Morphe ManagerのソースをHiro Morphe Patches v1.0.277へ更新し、Instagramの「戻る1回で終了・履歴削除」を再適用してください。従来と同じ署名キーで更新インストールしてください。ソース更新だけではインストール済みInstagramへ反映されません。既知のv1.1.17適用済み452版は、組み込まれた処理と戻る境界が公開版に一致する場合に更新します。改造済みAPKの更新では、この戻るパッチだけを選択してください。パッチ一覧の対象バージョンは「すべて」を維持しますが、検証した内部構造に一致しない入力は適用を停止します。

## 原因と変更範囲

452版ではプロフィールから`ModalActivity`へ動画を開く実コード経路が確認できます。従来の452識別がMainActivityに限定されていたため、ModalActivityが447版の画面管理判定へ落ち、汎用動画判定により終了対象になる条件をホストで再現しました。今回の実機報告と同一の遷移だったかは端末ログで確認できていません。

終了を許可する入口を、実際のMainActivity、検証済みCLIPSタブ選択、手前の画面・祖先階層がない状態に限定します。通常の動画からの戻る処理と、同じ戻る操作を複数入口で処理する場合の非終了判断を保持します。プロフィール経由、直接リール、手前の画面、異なる戻る入口のケースを回帰試験に含めます。

## ビルドと検証

`src/build.py`は公開済み総合版1.0.276と固定ツールを入力に使用します。`publication/manifest-template.json`の固定情報と今回の実APK監査を確認した後、`publication/create_local_evidence.py`と`publication/freeze_local.py`でローカル検証物を確定します。GitHub Actionsは同じソースから2回再ビルドし、MPP・QAの一致、入力と結果の結び付け、他パッチ保持を検査してから公開します。過去の実APK証拠は本ディレクトリへ移していません。
