Instagramリール戻る動作の修正 v1.1.8 / Hiro Morphe Patches v1.0.245

Instagram 447.0.0.55.81のAPK内にあるレイアウトを調べ、通常のリール画面に表示される「コメントを追加」の案内欄を、開いているコメントパネルと誤認する条件を確認しました。前版ではこの条件でリールの終了処理を選ばず、アプリ本来の戻る操作へ進んでいました。この案内欄と、実際に開いているコメントパネル・入力欄を区別するよう修正します。

リールの説明文にある「コメント」などの文字を、開いているコメント欄と誤認する条件も修正します。画面上で非表示になっているフラグメントや、非表示の入力欄に残ったフォーカスが、表示中のリールの終了を妨げる条件も修正します。実際に開いているコメント欄・別パネル・キーボードでは、閉じる操作を優先する処理を保持します。パネル等のないリールで戻る操作を行うと、タスク終了と最近使ったアプリのカード削除を行います。

上記は実APKのレイアウトを根拠に模擬画面で再現できたコード上の条件です。ユーザー端末のその瞬間の画面階層や戻る経路を取得して確定した原因ではなく、Android実機での解消は未確認です。

最新総合版v1.0.244を基準とし、TikTokのホーム復帰、ULike v1.9.104を含む他アプリのパッチを保持します。今回の更新通知はInstagramのみを対象とします。

提供されたInstagramの2ファイルとTikTokの1ファイルに含まれる既存v1.1.6の終了処理、および配布版v1.1.7とのAPI互換性を修正版に対して照合します。提供APKは既にパッチ済みであり、未改造APKへの適用試験や実機操作試験とは異なります。入力と修正版のハッシュ、レイアウトの根拠、監査結果を同梱します。

検証条件：前版のAndroid API模擬テストを維持し、今回の条件の回帰テスト、DEX構造・元処理保持、単体版と総合版×5パッケージの模擬APK適用を実施します。ローカルの固定SDKビルドと公開CIの2回の再ビルドでMPP・QAが一致した場合だけ配信を更新します。実際の試験数と結果はQAに収録します。

適用：Morphe Managerでソースをv1.0.245へ更新し、Instagramを未改造の元APKから「戻る1回で終了・履歴削除」を含めて再パッチし、更新インストールしてください。ソース更新のみではインストール済みアプリは変わりません。旧パッチ済みAPKへの重ね掛けは避けてください。

「終了」はAndroidのタスク終了・最近使ったアプリのカード削除であり、設定画面の強制停止ではありません。
