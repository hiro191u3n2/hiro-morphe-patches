# 履歴クリア v1.10.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.10.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版へ同じ署名で上書き更新できます。

## 履歴が開いたままになる経路を修正

- 高速な画面取得でボタンが確認できない、情報が取得できない、例外が発生する場合は、すぐに通常の画面取得へ切り替えます。その実行中は通常方式を維持し、現在の画面を検証し直します。
- 軽量取得の空表示だけではホームに戻らず、通常取得でも空表示を確認します。
- 起動直後のアニメーションなどでクリックを拒否されても、約176msで早期終了しなくなりました。最初の短い再確認は維持し、その後は拒否された場合だけ再確認します。既存の5秒期限内・最大24回で終了します。
- 成功したクリックや、呼び出しが例外になって成否が不明なクリックは繰り返しません。最初から操作できる場合に追加の待ち時間はありません。

対象ボタンの所属・完全一致ラベル・表示状態と、ロック・消灯・設定OFFの確認を維持しています。画面を閉じただけで削除成功とは扱いません。

## 更新と診断

上書き更新で設定を引き継げます。アイコンを押すとそのまま消去します。アイコン長押しの「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。ロック解除前の接続準備と、履歴表示前のボタン情報の準備は維持しています。

まだ開いたままになる場合は、アイコン長押し→「診断」→「診断をコピー」の内容で、取得の切替・ボタン検出・クリック拒否のどこで止まったかを確認できます。自動実行とアイコン実行それぞれの直近の記録を保持します。

ビルド・署名・マニフェストと実際のサービスコードを動かすホストテスト149項目で検証しました。旧v1.9の実際のソースを用いた4つの失敗条件も、修正後のコードで復帰することを確認しています。実機での復旧・表示時間は未検証です。Android側の呼び出しがブロックする場合、厳密な実時間上限は保証できません。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。
