Instagram 452 profile-video ModalActivity navigation contracts

Input: supplied Instagram 452.1.0.53.64 arm64 APKM, locally merged original APK.
Input SHA-256: fbfeec57e2415478cbbd4941d33d0563bce071daba236539403790366903aa61
The input bytes were hashed again for this evidence. APK bytes and user data are not included.

Scope: static DEX inspection of an actual app navigation pathway. This is not a
physical observation of the user's failing execution, nor a device UI replay.

Findings:
- The ClipsProfileTabFragment class X.0BdU launches a video through FF0. Its
  source enum is PROFILE (A2j), SELF_PROFILE (A37), or GROUP_PROFILE (A28).
- FF0 calls X.0Xoc.A02. Under its native launch-mode conditions, A02 calls A05,
  which calls X.04kE.A0C with the modal-launch flag. A0C creates a launcher for
  com.instagram.modal.ModalActivity with the route clips_feed_viewer.
- ModalActivity extends BaseFragmentActivity, which extends IgFragmentActivity.
  IgFragmentActivity extends androidx.appcompat.app.AppCompatActivity, which
  extends androidx.fragment.app.FragmentActivity. ModalActivity does not inherit
  InstagramMainActivity and does not provide its A1f/A08 current-tab contract.
- The shared FragmentActivity manager getter in this actual version is public
  final A1Z():X.00fk. It applies to ModalActivity as well as MainActivity.
- ModalActivity.finish calls android.app.Activity.finish. It does not call
  finishAndRemoveTask from that method. Closing this secondary Activity can
  reveal the underlying profile without removing the application's task.
- The native in-Activity wrapper return X.00ZX.A03 first checks its current MAIN
  content, then invokes the selected fragment Back handler. If not consumed,
  its manager stack count A0L and native A0c/A16 pop routes handle the return.

Missed runtime assumption:
The prior helper chose the shared manager's version using Instagram452.supports,
which requires MainActivity A1f/A08. A 452 ModalActivity therefore fell through to
the older A1Y():X.0dj lookup and lost its fragment source. Generic full-screen
viewer evidence could then request task exit before the exact fragment hook
could observe PROFILE. A non-Main video host must retain native navigation;
only a verified main CLIPS root may authorize Reels task removal.
