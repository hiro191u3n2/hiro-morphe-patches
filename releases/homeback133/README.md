# OneBack 1.1.26 / Hiro Morphe Patches 1.0.317

Instagram 452.1.0.53.64で、ブラウザから開いたプロフィールの「戻る」が終了判定を通らない経路を修正します。AndroidXのBack処理から、登録済みの外部プロフィールの既存ネイティブ処理へ一度だけ接続します。動画・子画面からプロフィールへ戻る操作、入力欄・コメント・ダイアログの処理を優先する既存の判定を維持します。

配布MPPは、前の作業セッションでビルド・検証して保存したファイルをそのまま公開します。SHA-256は `4f190bc54c91effbfa778b62bf913e2b6509f82c8e8b4f1b99b5a59ccae3a466`、サイズは48,001,679バイトです。公開前に一時作業領域が失われたため、このディレクトリは公開済み `releases/homeback132` と保存されたMPPを基にソースを復元したものです。新しい検証記録は `verification/verified.json` にあり、元の失われたQAファイルと同一であるとは主張しません。

前のセッションではホスト回帰試験、未改造Instagram APKへの適用、Piko 3.11.0-dev.3の初期選択との併用を確認しました。この公開作業では同一MPPのハッシュ、復元ソースの一致、回帰試験、1.0.316からの変更範囲を再検証しています。以前の原本APK/Piko適用ログは再作成せず、履歴情報として区別します。Android実機での操作は未確認です。

## インストール

Morphe Managerでパッチソースを1.0.317へ更新し、未改造のInstagram 452.1.0.53.64に「戻る1回で終了・履歴削除」を再適用してください。アプリを更新する場合は前回と同じ署名を使用してください。パッチソースの更新だけではインストール済みアプリは変わりません。

## ソースと検証

復元ソースは `src/runtime` と `src/patch`、ホスト試験は `src/test-runtime` と `src/test-stubs*` にあります。既存のパッチ適用時契約・補助資産・監査の基準ソースは同じリポジトリの `releases/homeback132/src` です。配布するソースZIPには、その基準リリースも含めます。旧リリースのビルド・公開ゲートは変更しません。

`publication/check.py` は配布MPP、復元したソース、今回の検証記録のハッシュを確認します。`publication/publish.py` はその検査後に配布資産を公開し、main/devのManagerフィードをlease付きの原子的pushで更新します。復元したソースを元の完全な再現ビルドと同一視せず、配布ファイルのバイトは変更しません。
