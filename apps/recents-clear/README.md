# 履歴クリア v1.9.0

[APKをダウンロード](https://raw.githubusercontent.com/hiro191u3n2/hiro-morphe-patches/main/apps/recents-clear/Hiro_RecentsClear_v1.9.0.apk)

ホームのアイコンから「最近使ったアプリ」の「すべて閉じる」を自動で操作するAndroidアプリ。Android 10以降。Shizuku・root不要。初回のみユーザー補助の「履歴クリア」をONにしてください。旧版へ同じ署名で上書き更新できます。

## 自動起動で履歴が見えている間の処理を削減

アイコン起動と違い、再起動後にSystemUIから自動実行が始まると、旧版では履歴を開いてから保存済みの削除ボタン情報を読み、最初の画面取得も通常方式になる場合がありました。

- 保存済みのボタン情報をロック解除後・履歴表示前に準備します。読み込み時間を表示前へ移し、表示中の処理を減らします。
- 保存済み情報がある場合、Android 13以降では履歴表示要求後の最初の画面取得から軽量方式を利用できます。この特例は1回限りで、その後は現在の画面に基づいて方式を選びます。
- 自動実行の重複したキーロック判定を1回削減しました。画面取得前後・操作前の確認は維持しています。
- 自動実行とアイコン実行の診断を別々に保持します。アイコン長押し→「診断」→「診断をコピー」で両方を比較できます。

保存済みIDだけで操作することはなく、対象の所属・ラベル・表示・有効状態などを毎回確認します。情報未保存・取得失敗時は通常の検索へ戻ります。SystemUIの通知欄と履歴画面の区別も維持しています。

## 使い方と検証範囲

アイコンを押すとそのまま消去します。アイコン長押しの「設定」で「再起動のたびに1回実行」を変更できます（初期OFF）。1.8.0のロック解除前のサービス接続準備も維持しています。設定と実行済み記録は引き継ぎます。

常駐・保護アプリへの追加終了処理、クイック設定タイル、覆い表示、端末全体のアニメーション設定変更はありません。APKにはネット通信権限がありません。

ビルド・署名・マニフェストと、実際のサービスコードを動かすホストテスト137項目で検証しています。実機での再起動後の復帰・削除・表示時間は未検証です。端末側のランチャー初期化・削除アニメーションにも時間がかかるため、アイコン操作と同じ見え方や完全な非表示は保証しません。
