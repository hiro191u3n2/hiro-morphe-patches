# ULike v1.9.38 / 総合 v1.0.171

ULike v1.9.37を基準に、インカメラ選択状態から再起動した際の黒いプレビューを修正する再現ビルドです。起動・復帰状態、カメラと描画面の準備順序、終了後に届く遅延処理を確認します。詳細な修正と検証結果はRELEASE_NOTES.txtとQA JSONへ記録します。

前版の撮影画面の表示範囲、画質処理・保存品質・解像度・合成枚数、S2・S3・S4・S5・S6・S7・S8・S16・T1、および他アプリの改造を保持します。

`src/build1938.py`は固定した元MPPとJavaツールで変更範囲を検証します。`src/validate1938.py`は単体・総合版を未改造ULike5.6.2(740) APKSへ適用し、再構築・DEX型解析・実APKの呼び出し契約を検証します。`src/finalize1938.py`は元APKSへの適用検証済みMPPとのSHA-256一致を要求します。

公開ワークフローは再現ビルド、公開資産の検証、main/dev両Managerフィードの更新まで行います。Galaxy実機での現象再現・解消確認は未実施です。元APKS、再構築APK、ユーザー写真、署名鍵は公開物に含めません。
