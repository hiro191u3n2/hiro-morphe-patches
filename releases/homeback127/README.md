# Instagram 452対応・プロフィールから戻る修正 v1.1.17

Hiro Morphe Patches v1.0.275。Instagram 452.1.0.53.64で「Instagram main Back guard fingerprint changed」となり、戻るパッチの適用が停止する問題に対応します。447.0.0.55.81向けの既存処理を保持し、452の戻る処理、AndroidX dispatcher、タブ状態、画面階層を確認してから接続します。

プロフィールから開いた動画はInstagram本来の戻る処理へ渡し、元のプロフィールへ戻します。リールタブを直接選んでいる場合は、戻るでアプリを終了し、最近使ったアプリのカードを削除します。コメント等の手前に開いた画面は、本来の閉じる処理を優先します。

基準は公開済み総合版v1.0.274です。同版のOneBack runtimeはv1.1.15相当であり、未公開作業のプロフィール復帰修正を本版へ統合します。ULike v1.9.113、Berry、Yahoo!乗換案内等の他パッチ・資源は基準版から保持します。Managerの更新対象はInstagramのみです。

## 検証

本番Android SDKコンパイル、既存のホスト試験と452・プロフィール遷移の回帰試験、DEX構造・他パッチ保持を確認します。単体と総合MPPを5アプリの合成APKへ適用し、Desktop1.16.0、1.19.0-dev.19、1.19.0（patcher2.0.0）の3系統で再構築します。配布MPPを公式JVM loaderで読み込み、対応パッケージ・全バージョン表示・実行クラスの出所も検証します。

実Instagram452へのローカル適用では、元入力、配布MPP、runtime、出力APKのSHA-256を保存し、戻る境界、他コードと資源の保持、署名、整列を監査します。CIでは同じソースから2回ビルドし、ローカル確定MPPとQAの完全一致を要求します。試験範囲は`QA_HomeBack_v1.1.17.json`と`publication/local-apk-validation.json`に記録します。

APK本体、端末データ、署名用の秘密鍵は公開ソース・CI・配布物に含めません。Piko 3.11.0-dev.1との同時適用は、標準の54パッチ＋OneBackと、Cloneを除く65パッチ＋OneBackで適用・再構築を確認します。個別の全選択・オプションの組合せは検証範囲外です。APK資源の数値ID・値・設定を比較し、再構築による114件のdrawable名変更と576件の無名stringへの名称付与を記録します。旧名称を文字列指定する動的検索の同等性までは確認していません。

Android実機でのインストール、画面操作、プロフィール復帰、タスクカード表示は未確認です。

## 適用

パッチ一覧では対象バージョンを「すべて」と表示します。今回の新規対応で実APKを使って確認する版は452.1.0.53.64です。表示上の対象範囲と実際の検証範囲は別で、未知の内部構造は適用時の検査で停止します。旧447版の処理と回帰試験も保持します。

Morphe ManagerのソースをHiro Morphe Patches v1.0.275へ更新し、Instagramの「戻る1回で終了・履歴削除」を再適用してください。更新インストールには従来と同じ署名キーを使います。ソースの更新だけでは、インストール済みアプリに反映されません。

単体は`OneBack_Exit_NoRecents_v1.1.17.mpp`、総合版は`Hiro_Morphe_Patches_v1.0.275.mpp`です。既知の旧OneBack適用済みAPKは、runtimeとフックが既知の内容と一致した場合に更新します。未知のコード構造は誤った位置へ書き込まず、適用を停止します。
