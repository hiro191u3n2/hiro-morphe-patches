OneBack Exit No Recents v1.1.15 / Hiro Morphe Patches v1.0.259

X（旧 Twitter）のホーム・検索・通知・チャットのトップ画面からの戻る終了と、通常の次回起動でホームを表示する処理を再修正します。

v1.1.14 は X 本来の戻る処理に終了判定を入れていましたが、対象の MainActivity に Android 13 以降のシステム戻る処理を登録しない条件が残っていました。そのため Android 自身の終了経路へ進み、タスク削除と次回ホーム起動の情報保存まで届かない経路がありました。今回、その入口に処理を登録します。

アプリ自身の戻る処理が登録されている間はそれを優先し、予測型ジェスチャーの開始・進捗・取消も保持します。登録がない場合だけ補助の処理を置き、未処理のシステム戻るを X 本来の処理へ渡します。同じ戻る操作が再帰的に呼ばれることも防ぎます。また、戻るキーの配送中に Android が呼ぶ onUserInteraction を別の操作として扱い、実行中の戻る判定を無効にしていた問題も修正します。X 自身が明示的に終了を選んだ場合は、入力欄の事前判定だけでタスク削除を取り消さないようにします。

正常に終了したときはホーム復帰の情報を保存し、通常の次回起動で前回のタブを復元する前にホームを指定します。通知やリンクで指定された移動先は保持します。

対象は提供された X 12.19.1-release.0（com.twitter.android）です。総合版 v1.0.258 を基準とし、Fossify Gallery の並行公開済み修正、ULike v1.9.108、Instagram のリール戻る修正、その他アプリのパッチと資源を保持します。Morphe Manager の更新対象は X／Twitter です。

公開前に、旧版で失敗するキー配送・システム戻る経路の再現試験と、修正版での終了・タスク削除・次回ホーム起動を確認します。本番 Android SDK コンパイル、既存と追加のホスト試験、DEX の構造・保持検証、合成 APK 適用、実際の X APK への単体／総合 MPP 適用、既知の v1.1.13／v1.1.14 からの更新を監査します。2回の CI ビルドとローカルで固定した MPP／QA の完全一致も公開条件です。ユーザーの APK と検証用 APK 本体は公開ソースや CI に含めません。
Android 実機での画面操作・終了・タスクカードの削除・次回起動は未確認です。

Morphe Manager のソース更新後、X の「戻る1回で終了・履歴削除」を再適用し、従来と同じ署名キーで更新インストールしてください。ソース更新だけではインストール済み X の処理は変わりません。OneBack 未適用の対応 APK と、コードが完全一致する v1.1.13／v1.1.14 からの更新に対応します。不明な旧版や変更済みコードへの上書きは中止します。
削除対象は Android の「最近使ったアプリ」のタスクカードです。X 内の検索・閲覧履歴やサーバー上のデータは削除しません。
